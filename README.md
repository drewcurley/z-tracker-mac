# Z-Tracker Mac

A from-scratch, feature-by-feature, near pixel-perfect clone of [Z-Tracker](https://github.com/brianmcn/Zelda1RandoTools) (the Zelda 1 Randomizer tracker by Dr. Brian Lorgon111), built as a **native Apple Silicon macOS app**.

This project follows the conventions in the shared [`playbook`](../playbook) (see its `AGENTS.md`), scaled down for solo development per `AGENTS.md` §12.

Status: bootstrapping — see `/docs` and `/tasks`.
