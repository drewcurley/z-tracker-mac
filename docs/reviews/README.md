# `/docs/reviews/` — Review Artifacts

One folder per branch. One file per round: `round-1-analysis.md`, `round-2-implementation.md`,
`round-3-verification.md`, and `final.md` (the consolidated verdict + sign-offs).

See `../../playbook/AGENTS.md` § 9 for the artifact template and § 2 for the round
definitions. Artifacts are **never edited after merge** — they are a historical
record of what was reviewed and by whom (or, for this solo project, which agent
hat was worn when — see `AGENTS.md` §12).

Convention: use `_TEMPLATE.md` in this folder as the starting point for `final.md`.
