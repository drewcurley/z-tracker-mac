## Update-this-doc-when

Update this file (and `.github/CODEOWNERS`) the moment a second contributor joins —
that also triggers raising GitHub branch-protection required approvals from 0 to
≥1 and turning on "Require review from Code Owners" (`playbook/ADOPTING.md`
"Solo vs. team").
