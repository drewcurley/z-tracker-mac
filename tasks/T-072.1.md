# T-072.1 — Fix ⌥-drag circling the first room

## Description
User-reported after T-072: ⌥-drag painted default rooms but left a **circle on
the first tile**. Cause — `⌥+left` is the *left* button, and the catcher fired
left presses on mouse-**down**, so the ⌥-click (middle-click = toggle
circle/brightness) fired on the start room before the drag began.

Fix: only a **plain** left press (no modifiers) fires on mouse-down. Every
modified/other press (⌥-left, shift-left, right, middle) now defers to
mouse-**up**, firing its click only when the press wasn't a drag. So ⌥-drag paints
cleanly (no stray circle), while ⌥-click (no drag) still toggles circle/brightness
on release, and the plain left-click stays on mouse-down (unchanged).
