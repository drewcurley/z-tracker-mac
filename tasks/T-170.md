# T-170 — Hotkey editor navigation

## Description
Last of the hotkeys epic. The reference's "Show HotKeys" cheat-sheet window was
considered and **dropped** (user, 2026-07-24): unlike the reference (whose editor is an
external text file), this clone already has a full in-app editor that lists every binding
grouped by context, and its deliberate click-in / press-key / confirm-overwrite flow makes
glancing at it safe — a second read-only window would be ~redundant.

Instead, make the (long) editor list navigable:
- **Bound / Unbound / All** segmented filter — one click to "what did I bind" or "what's
  left to bind".
- **Collapsible section headers** — click a context header to fold/unfold it; each shows a
  live count of its visible rows. Plus Expand all / Collapse all.
- Stacks with the existing text filter.

## Acceptance criteria
- [x] Bound/Unbound/All filter narrows every context's rows.
- [x] Section headers collapse/expand; counts reflect the active filters; expand/collapse
      all work.
- [x] Text filter still applies on top.
