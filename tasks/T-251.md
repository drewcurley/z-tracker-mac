# T-251 — Voice "make a note …" dictates into Notes

## Description
Promised in docs/reference-coverage.md §6 (beyond the reference). User-requested 2026-11-14.

## Acceptance criteria
- [x] Saying a Notes_Append trigger (default: make a note / take a note / add a note / note that) followed by text appends that text, as spoken, on its own line at the end of Notes.
- [x] The trigger is matched only at the start and before every other rule, so command words inside a note stay text.
- [x] A bare trigger with nothing after it does nothing.
- [x] While a note is being dictated, the end-of-phrase wait is 2 s instead of 0.7 s.
- [x] Trigger phrases are editable in the voice-command editor like every other action.
