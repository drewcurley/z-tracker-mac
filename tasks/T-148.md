# T-148 — Row-letter homophones

## Description
Live QA: the **H** row ("aitch") is by far the worst-recognised coordinate letter
("H4" → "each four", "H8" → "eight …"). `rowLetter` now also matches speech-to-text
homophones (each/aitch/itch/age → H, plus safe ones for A/B/C/D/G). Only consulted
when the token sits immediately before a number (`coordinate`), so ordinary words
don't misfire. NATO "hotel" for H still works and remains the recommended form.

## Acceptance criteria
- [x] "each four"→H4, "each 8"→H8, "aitch 2"→H2, "gee 3"→G3.
- [x] "each" alone (no number) is not a coordinate. 593 tests.
