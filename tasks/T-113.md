# T-113 — Timeline actual pickups + hearts + bait

## Description
The timeline derived tiered items (sword/candle/ring/arrow/boomerang) from
cumulative *levels*, so getting the higher tier lit up the lower one too — e.g.
getting the silver arrow stamped a "wood arrow" pickup that never happened. The
reference tracks each specific item as its own boolean (`TrackerModel.fs` `MakeAll`,
`PlayerHasWoodArrow` vs `PlayerHasSilverArrow`, …).

`TimelineEvents.current` now derives each tier from actual per-item presence (the
matching progress/starting-item flag or a collected box holding that exact item),
so only items you truly picked up appear. Singletons already used presence flags
and are unchanged.

Also added, per the user request:
- **Bait** (`progress.hasMeat`) as a timeline event.
- **Heart containers from dungeon boxes** (`dungeonHeart(1…9)`) and **the coast**
  (`coastHeart`) — previously only take-any hearts appeared.

`current` now takes `startingItems` + `isWSMSReplacedByBU` (the BU guard keeps a
bomb-upgraded white/magical sword cave from registering as a sword pickup).

## Acceptance criteria
- [x] Tiered items reflect actual pickups; no phantom lower tier.
- [x] Bait appears when the player has meat.
- [x] Dungeon and coast heart containers appear (keyed by dungeon slot / coast).
- [x] BU-replaced sword caves don't register as sword pickups.
- [x] Unit-tested; build + full suite clean.
