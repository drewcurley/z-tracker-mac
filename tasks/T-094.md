# T-094 — Visit-hints fix: boomstick book counts as the book

## Description
Bug (user): the visit-hints reminder fired when the Book was a dungeon item, but
not when the Book was bought from a shop (marked "Purchased the boomstick book").

Cause: I treated the boomstick book as a separate item. Per the user, **there is
only one book** — the "boomstick book" is the same Book of Magic, just moved out
of the dungeon/armos/coast/white-sword rotation into a shop (with extra wand
functionality). So it grants hints exactly the same.

Fix: the reminder's "hold the book" test now includes the boomstick book —
`(haveBookOrShield && isCurrentlyBook) || progress.hasBoomBook`. The engine already
has `progress`, so no new plumbing.

## Acceptance criteria
- [x] Visit-hints fires whether the Book came from a dungeon or the shop (boomstick).
- [x] Shield seed (item 0 = shield, no boomstick) still does NOT fire.
- [x] Unit-tested (boomstick-book path added).
