# T-139 — Voice command editor

## Description
Makes the voice vocabulary **user-editable**, mirroring the hotkey editor.

- **`VoiceCatalog`** — the catalog of voice actions (cursor / navigation / dungeon /
  overworld shops / overworld marks / take-any) with a display name, category, and
  **default phrases**; parametric actions marked (`takesNumber`).
- **`VoiceConfig`** (`@Observable`, persisted) — action id → phrases, seeded from
  defaults; add/edit/remove/reset; longest-phrase-wins `match()` across all actions
  (so "take any potion" beats "take any", "set level" beats "level").
- **Grammar is now config-driven** — `parse`/`overworldAction` consult the config;
  action id → meaning stays in code (only phrases are editable). `contextualStrings`
  is built from the user's phrases.
- **`VoiceCommandEditorView`** — Settings ▸ Voice ▸ "Edit voice commands…". One row per
  action (single-line: name + comma-separated phrases + reset), grouped by category,
  with a filter and global "Reset all".

## Acceptance criteria
- [x] Catalog + config are pure & tested (seed, longest-match, parametric number, user phrase).
- [x] Grammar resolves via the config; a user-added phrase triggers the action.
- [x] Editor lists all actions, edits persist, per-action + global reset. 562 tests.
