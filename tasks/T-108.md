# T-108 — Secret picker cap

## Description
Follow-up to the secret reminders (T-105): the overworld picker still let you mark
more than the quest's total of each sized secret. Now `OverworldTileLimits.maxUses`
returns the real per-quest per-size totals (1Q large 3 / medium 7 / small 4; 2Q
large 1 / medium 7 / small 6), and the Secret menu disables a size once exhausted
(like the other capped marks). Unsized (unknown) secrets stay unlimited.

- [x] Secret menu disables an exhausted size.
