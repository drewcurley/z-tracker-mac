# T-046 — Paused-timer reset hub

## Description
The Windows app's Pause button opens a 4-option dialog: resume, close & restart
the app (discard all work), reset the timer to 0:00:00, and the groundhog-day
reset. Per the user, the "close & restart the app" option is pointless — but a
way to **start over from the startup screen** (without literally quitting) is
wanted. So the Mac pause reveals a reset hub with **Resume** plus three reset
buttons:

- **Reset App** — discard the whole run and return to the startup / quest-
  selection screen, as if the app were reopened (user settings kept).
- **Reset Timer** — set the timer back to 0:00:00.
- **Reset (keep maps)** — the groundhog/routers reset (clear inventory, keep
  maps), which also restarts the lap and resumes the run. Moved here out of the
  Info group so all resets live in one place.

## Acceptance criteria
- [x] Running timer shows only **Pause**; pausing reveals Resume + the three
      resets.
- [x] **Reset App** confirms, then returns to the startup screen with a fresh
      model (all marks/items/hints/timer discarded); settings preserved.
- [x] **Reset Timer** zeroes the clock (immediate).
- [x] **Reset (keep maps)** confirms, then groundhog-resets + restarts the lap +
      resumes; removed from the Info group.
- [x] No "close & restart the app" option.
- [x] On-device verified (pause hub renders; Reset App → startup screen).
