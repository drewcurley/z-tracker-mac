# T-032 — Sword-cave labels wrongly BU-annotated

## Description
T-025.4 annotated the overworld tile-selector's "White Sword Item" and
"Magical Sword" cave labels with "(Bomb Upgrade)" under swordless. That was
wrong, per the user's clarification:

- **"White Sword Item"** is a *cave location* holding a **random** item — not
  the white sword. It is never itself a bomb upgrade.
- **The white sword *itself*** (the weapon, `ITEMS.whiteSword`) is shuffled into
  some item spot (dungeon box, coast item, armos item, or the white-sword-item
  slot). Swordless replaces **the weapon** with a bomb upgrade — rendered on the
  item boxes/picker (which T-025.4 already did correctly), not on the cave mark.

Fix: drop the "(Bomb Upgrade)" annotation; the sword-cave labels are plain
location names ("Wood Sword" / "White Sword Item" / "Magical Sword"). The
white-sword-weapon → bomb-upgrade icon swap (T-025.4) is correct and untouched.

## Acceptance criteria
- [x] `swordCaveLabel(_:)` returns plain labels regardless of the BU flag;
      the now-unused `isWSMSReplacedByBU` param is removed from `OverworldMapView`.
- [x] The item-box/picker white-sword→BU swap is unchanged (still correct).
- [x] Tests updated to assert plain labels.
