# T-076 — Spot Summary Non-Unique Locations

## Description
User-reported: the Spot Summary was missing the multi-count location types. Adds
the reference's "Non-Unique Locations" section
(`OverworldMapTileCustomization.fs:575-584`, indices 28/29/32/33/34): **Door
Repair, Money-Making Game, Hint Shop, Take Any, Potion Shop** — each with its
per-quest total and a "still to find" count.

- `SpotSummary.NonUniqueCount` (mark, marked, total, remaining) + `nonUniques`,
  using the reference `maxUses` totals (`TrackerModel.fs:290-298`): door 9/10,
  MMG 5/6, hint 4, take-any 4, potion 7/9 (1Q/2Q).
- `SpotSummaryView` renders a "Non-unique locations" section (number + name +
  icon row, bright = remaining), matching the Secrets section style.

Shops (bomb/candle/ring/meat/…) are **not** included: the reference tracks them as
unbounded (max 999), so a "remaining" count isn't defined. Flagged to the user.
