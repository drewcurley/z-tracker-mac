# T-025.4 — Swordless (WSMS→BU) support + sword-cave relabel

## Description
The item-grid chrome starts with the **swordless** control the user asked for.
In swordless seeds the White Sword and Magical Sword are replaced by **Bomb
Upgrades** (wiki: *Items*; reference `IsWSMSReplacedByBU`,
`CustomComboBoxes.fs:48`). This adds:

1. **BU toggle** — a chrome control (the swords→bombs `ws_ms_bomb_upgrade`
   icon) bound to `TrackerModel.isWSMSReplacedByBU`.
2. **Sword-cave relabel** — the overworld tile selector's sword-cave marks are
   relabeled from "Sword cave 1/2/3" to **"Wood Sword" / "White Sword Item" /
   "Magical Sword"** (user request). Under BU, the White Sword Item and
   Magical Sword entries indicate they're now Bomb Upgrades.
3. **Item-selector swap** — the white-sword item (`ITEMS.whiteSword`, box-item
   domain index 13) renders as the bomb-upgrade sprite when BU is on, in both
   the box picker and placed boxes. (The magical-sword item-grid box already
   swaps, T-025.1.) The **wood sword is untouched** by this toggle.

**Scope note:** the reference only swaps the box-item domain + the magical-
sword box, not the OW map tiles; matched here (the tile *selector menu* conveys
BU via its labels, the map marks keep their sword-cave icons).

## Out of scope
- **Extra Candles** (a *separate* option: blue candle in the wood sword cave +
  take-any caves = {red potion, blue candle, heart}) — filed as **T-031**.
- The rest of the item-grid chrome (book/shield, book-is-atlas,
  highlight-open-caves, max-hearts) — their model flags/consumers aren't built;
  a later T-025.5.
