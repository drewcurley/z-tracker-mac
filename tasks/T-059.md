# T-059 — Disable exhausted parent submenus

## Description
Follow-on to T-058: individual picker options disable at their max, but the
parent **submenu** stayed enabled even when every child was exhausted. Now the
parent disables too — "Dungeon" once all nine are placed, "Any road" once all
four, "Sword cave" once all three. ("Take any" already disabled via its single
`.takeAny` limit; shops/secrets are unbounded so never disable.)

## Acceptance criteria
- [x] A submenu disables when all its options are exhausted.
- [x] Individual options still disable independently.
- [x] On-device verified (Sword cave greys after all 3 placed).
