# T-088 — Door-repair count reminder

## Description
User: marking a door repair didn't announce anything — normally the tracker says
"you have found 1 of X door repairs". That reminder was never ported. Added it
(reference `Z1R_WPF/Reminders.fs:244-250`):

- `ReminderAnnouncement.doorRepairCount(found:max:)`, category `.doorRepair`
  (toggle already existed), text `"You found [all ]N of X door repairs"`.
- Edge-triggered in `ReminderEngine.poll` on each increase of the door-repair
  count; **not** reset on groundhog (door-repair marks are permanent).
- `pollReminders` counts `.doorRepair` overworld marks and passes the quest max
  (9 FQ / 10 SQ).

An audit of the reference's reminders surfaced four more that are still unported
(coast item, recorder spots, power-bracelet spots, boomstick book) — logged for
follow-up (T-089).

## Acceptance criteria
- [x] Marking a new door repair announces "You found N of X door repairs".
- [x] "all N of X" once every door repair is marked.
- [x] Fires once per increase; silent otherwise; survives groundhog.
- [x] Model logic unit-tested; end-to-end verified on-device (toast fired).
