# T-125 — Log polish

## Description
Three tweaks to the reminder log (T-122):
- **Inline icons** — icons now sit on the same line as the text (timestamp · icons ·
  text), instead of a separate row above it.
- **Dungeon-number tile** — a `.dungeon(n)` icon renders as a numbered tile (the
  number the player reads in "consider dungeon 3"), not the overworld cave marker.
- **Font zoom** — ⌘+ / ⌘- / ⌘0 (and A+ / A / A− buttons) scale every row's text and
  icons, clamped 0.7×…2.6×.
