# T-015.4 — True GYR rendering

## Description
Replaces T-011's flat single-color "reachable" overlay
(`OverworldMapView.swift:82-88`) with the reference's true green/yellow/red
cascade from `doComputedDrawing` (`Z1R_WPF/OverworldRouteDrawing.fs:40-70`):

1. tile marked as dungeon 1–8 -> green;
2. else if `not OwGettableLocations[i,j]` -> red;
3. else if `owInstance.SometimesEmpty(i,j)` -> yellow;
4. else -> green.

Bold vs. pale is the existing `isBold` axis (already carried by
`OverworldRouteHighlightEntry`, T-011). Cyan overrides everything for the
currently-selected route target (`whatToCyan`, `:64-68`) — the cyan hookup
can be stubbed until T-015.6 provides a selected target.
