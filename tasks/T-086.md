# T-086 — Reminder pronunciation fixups

## Description
User: the voice engine mispronounces "triforce". Send "try force" / "try forces"
to the synthesizer so it says them correctly — while the on-screen text keeps the
real spelling.

`SpeechText.spoken(_:)` rewrites the spoken form (plural before singular,
case-insensitive); applied wherever we hand text to TTS. Shipped together with the
live-TTS migration (T-069), so it's the single spoken path.

## Acceptance criteria
- [x] "triforce"/"triforces" → "try force"/"try forces" for the voice engine.
- [x] Visual toast keeps the real spelling.
- [x] Pure helper, unit-tested (singular/plural/case/passthrough).
