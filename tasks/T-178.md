# T-178 — Broadcast mirror window (+ related window/UI work)

## Description
Reinstates a synced full-tracker second window (the "broadcast window"), re-scoped from
the reference's fixed-layout auto-switching mode to a mirror that fits this app's
responsive/breakout architecture ([[broadcast-window-rethink]]).

- **Broadcast mirror window** (Window menu → Broadcast): a second full tracker over the
  same shared `@Observable` state, so it stays in sync and is mouse-editable from either
  window. `isMirror` keeps the app-global singletons single-instance on the primary — the
  hotkey dispatcher, voice, and the reminder/timeline poll loop — so nothing double-fires;
  the mirror is titled "Broadcast" (not "Z-Tracker") so the primary's key monitor ignores
  keystrokes there. Shows a placeholder when no run is in progress.
- **Per-window breakout**: the pop-out controls now flag *their own* window's breakout
  state (main via `breakout`, mirror via its own `mirrorBreakout`), so breaking out the
  timeline/dungeon/overworld from the broadcast window affects only the broadcast. Closing
  a shared breakout window brings that section back inline in both.
- **Show Info panel** toggle (global, default on) — hide the top Info group for a tighter
  layout / cleaner broadcast.
- **App-icon choice**: the **simple** icon is now the default bundle icon (built into the
  `.icns` via `scripts/make-simple-icon.swift`, pre-rounded to the standard macOS shape),
  so it shows reliably open or closed. A **"Use detailed app icon"** toggle (default off)
  swaps the *running* app's dock icon to the original design.
- Removed the obsolete reference-style "Broadcast window" Settings section and its dead
  backing options (`showBroadcastWindow`, `broadcastWindowSize`, the `BroadcastWindowSize`
  enum, `broadcastWindowIncludesOverworldMagnifier`).

## Decisions / caveats (surfaced with the user)
- Keyboard hotkeys/voice stay on the **primary** window; the mirror is mouse-editable.
- The Window menu is SwiftUI's auto per-scene list (can't be cleanly relabeled/grouped);
  per-window breakout lives on the in-window pop-out buttons.
- Icon **default** is the bundle `.icns` (reliable open/closed); the persistent
  custom-icon approach was dropped because it only worked in a user-writable location.

## Acceptance criteria
- [x] Broadcast window mirrors + edits in sync; no double-fired hotkeys/voice/reminders.
- [x] Break out from broadcast affects only the broadcast; close brings back in both.
- [x] Info panel hides via a durable global toggle.
- [x] Simple icon is the default (open + closed); detailed is an optional running override.
- [x] Old broadcast Settings section + options removed; 686 tests green.
