# T-176 — Untrack the committed .dmg

## Description
`dist/ZTrackerMac-0.8.0.dmg` (a 5 MB build artifact) was committed in T-174 even though
`dist/` is in `.gitignore` — `.gitignore` doesn't untrack a path that got staged. Remove
it from tracking so future checkouts don't carry it; `.gitignore` already prevents
re-adding it. History isn't rewritten (main is published) — the practical fix is to stop
tracking it going forward. Release `.dmg`s belong on GitHub Releases, not in the repo.

## Acceptance criteria
- [x] `dist/ZTrackerMac-0.8.0.dmg` no longer tracked.
- [x] `dist/` stays gitignored so `make-dmg.sh` output isn't re-committed.
