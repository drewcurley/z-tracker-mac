# T-079 — Dungeon minimap hover-reveal

## Description
A faux in-game HUD dungeon map of your marked rooms, so you can eyeball whether
what you've built matches the map you see in-game (user request; reference
`MakeLoZMinimapDisplayBmp` / `showMinimaps`, `Dungeon.fs:774+`,
`DungeonUI.fs:890-937`).

- `DungeonMinimapHoverIcon`: a small thumbnail in the info strip (black tile with
  two blue bars, per `MakeMiniMiniMapBmp`); on **hover** it reveals a popover.
- `DungeonMinimapView`: a `LEVEL-N`/`BOARD-N` header over an 8×8 grid of blue
  room-blocks (reference blue RGB 71,47,228; lit = a marked room). When any room
  is painted off-the-map, it also shows the **inverse** ("Full map, minus your
  Off-The-Map marks") — the shape the game actually reveals — above "Your room
  marks".

## Acceptance criteria
- [x] Thumbnail in the info strip; hover reveals the minimap.
- [x] Minimap shows LEVEL-N header + blue blocks for marked rooms.
- [x] Off-map rooms present → also shows the inverse view with labels.
- [x] Build clean; on-device verified (forced open + seed): both boards render.
- [ ] Live hover confirmed by the user.
