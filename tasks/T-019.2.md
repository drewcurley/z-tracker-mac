# T-019.2 — Blockers UI

## Description
Second dungeon-band slice (frame-first): the reference's Blockers grid
(`MakeBlockers`, `UIComponents.fs:955-997`) over the already-built, already-
tested `DungeonBlockersContainer` model. A 3×3 grid — a "Blockers" title cell +
dungeons 1–8 (D9 has none), each a row of three blocker boxes with a slot label
that lights white once the dungeon is located on the overworld.

- **`BlockersView`** — the 3×3 grid; `DungeonTrackerView.locatedDungeonIndices`
  drives the label color.
- **`BlockerBoxView`** — state border (gray = empty, light-gray = definite,
  green→red gradient = "maybe") + kind icon. Left- **or** right-click opens the
  kind picker (the reference treats them the same); the picker has a Clear.
- **`BlockerKindPicker`** — the eight kinds (bow+arrow, recorder, ladder, key,
  bait, money, bomb, combat) with icons, dimmed when the player can no longer be
  blocked by them (`playerCouldBeBlockedByThis`), + Clear.
- **Model:** added `DungeonBlocker.isMaybe` (`hardCanonical != self`) for the
  gradient border.
- **VoiceOver-native** from the start (per `docs/ux.md` § Accessibility): each
  box is an accessibility element (label + current-blocker value + button + action).
- Placed beside Notes in the dungeon band; the per-dungeon room grid lands next.

## Deferred (own slice)
"Applies to" (map / compass / triforce / item box the blocker sits behind) — the
reference sets it via a middle-click popup and draws chips on the dungeon widgets.
Deferred until that chip rendering exists, so it doesn't silently store invisible
state. (Removed an early right-click menu for it — the reference treats left/right
the same, per user feedback.)

## Acceptance criteria
- [x] 3×3 grid: title cell + dungeons 1–8, three boxes each; slot label white
      when the dungeon is located (else orange).
- [x] Click a box → picker of the eight kinds (dimmed when non-blocking) + Clear;
      selecting sets the blocker; the box shows its icon + state border.
- [x] `DungeonBlocker.isMaybe` unit-tested; build clean (debug + release); suite
      passes (341).
- [x] On-device: layout matches the reference; the picker sets kinds and renders
      icons/borders (user-verified).
