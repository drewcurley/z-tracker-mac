# T-018.3 — Announcement rendering

## Description
The presentation half of T-018: take the `[ReminderAnnouncement]` produced by
`ReminderEngine.poll` (T-018.2) and actually surface them — spoken
(`AVSpeechSynthesizer`, honoring the reminder voice/volume options and the
per-category Voice/Visual matrix already in `TrackerOptions`) and/or shown in
a visual reminder overlay. Also drive the poll loop (a ~1 Hz timer, matching
the reference's poll cadence) and map each `ReminderAnnouncement` to its
reference text/icons (`SendReminder` call sites in `Z1R_Avalonia/UI.fs`).

## Acceptance criteria
- [x] A reminder surface (`ReminderOverlayView` — transient "toasts") +
      speech (`AVSpeechSynthesizer`) in `ReminderController`.
- [x] Poll `ReminderEngine` on a ~1 Hz timer (`.task` loop in
      `MainTrackerPlaceholderView`), rendering per the per-category
      Voice/Visual reminder options + volume. Engine owned by
      `TrackerModel.reminderEngine`; `TrackerModel.pollReminders()` assembles
      the inputs.
- [x] Announcement → category + text mapping ported from `SendReminder`
      (`Z1R_Avalonia/UI.fs:1399-1615`) as `ReminderAnnouncement.category`/
      `.displayText`; tested. (Icons + the HDN lettered dungeon-complete
      variant are a later refinement.)

## Out of scope
- The engine itself (T-018.2, done). Reminder icons; HDN lettered variant.

## Risks / dependencies
- Depends on T-018.2 + the reminder options (`TrackerOptions`) +
  `AVSpeechSynthesizer`. Visual/audible confirmation needs an interactive
  session (screen/assistive permissions) — see the review artifact.
