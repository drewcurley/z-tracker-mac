# T-123 — Dungeon-band break-out window

## Description
Following the timeline pop-out pattern (T-100), the dungeon band — the per-dungeon
room-map grid + blockers + notes — can now open in its own window. Extracted the band
into a reusable `DungeonBandView(model:options:)`; the inline section gained a
pop-out header (label + button) and shows a "in a separate window / Bring back"
placeholder while popped out. New `Window(id: DungeonBandWindowID)` renders the same
`DungeonBandView`, sharing the model so edits stay in sync.

Also added a shared `breakoutHeader` helper and the `overworldPoppedOut` flag +
window ids for the follow-up overworld window (T-124).
