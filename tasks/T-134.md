# T-134 — Keyboard cursor foundation

## Description
A movable keyboard cursor (a cyan ring) that the `MoveCursor*` Global hotkeys drive,
and that **follows the mouse** so keyboard nudges continue from wherever the pointer
is (user's choice). Rendered on the overworld tiles and the dungeon room grid; each
grid remembers its own cell. State lives on `TrackerFocusState` (app-level, reachable
by the dispatcher).

Deviation from the Windows reference — deliberate, "in spirit not implementation":
the reference warps the physical OS mouse pointer (`SetCursorPos`) and its region
hotkeys act on `Mouse.DirectlyOver`. We render a decoupled ring instead, so the
hardware pointer never jumps; region keys act on the ring's cell (T-135).

## Acceptance criteria
- [x] `MoveCursorLeft/Right/Up/Down` move the ring, clamped to grid bounds.
- [x] Cursor renders on the overworld and dungeon-map grids; each keeps its own cell.
- [x] Hovering a tile/room moves the cursor there (mouse-follow).
- [x] Build + full suite clean; user-QA'd on-screen.
