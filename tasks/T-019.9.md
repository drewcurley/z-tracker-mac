# T-019.9 — Dungeon Summary tab

## Description
Fills the "S" tab (previously a placeholder) with a bounded take on the reference
summary (`DungeonUI.fs:1552+`): a 3×3 grid of all nine dungeons' room maps at a
glance, each a read-only mini render, labeled `LEVEL-N`/`BOARD-N`, showing a
completion seal and a "not yet found" state for untouched dungeons, and clickable
to jump to that dungeon's tab.

`DungeonMiniMapView` renders the 8×8 room-type sprites (+ completion variant) at a
small scale; off-map rooms are blank and doors are omitted at this size, matching
the reference tiny map (`:1621-1628`). "Found" is driven by the room map's
`firstInteractionDone`; "complete" by `dungeonTracker.dungeon(i).isComplete`.

The reference's richer summary extras — the hover-preview into the notes area and
the per-dungeon monster-priority list — are deliberately left as follow-ups
(noted in the review) to keep this slice focused and low-risk.

## Acceptance criteria
- [x] "S" tab shows a 3×3 grid of all nine dungeons.
- [x] Each panel: label (LEVEL/BOARD per flag), mini room map, completion seal,
      and "not yet found" for an untouched dungeon.
- [x] Clicking a panel switches the map area to that dungeon.
- [x] Read-only (no editing in the summary); build clean; on-device verified.
