# T-050 — HDN dungeon-number chooser + triforce reference

## Description
Completes Hidden Dungeon Numbers (T-049 did the toggles + A–H labels). In HDN,
the slot above each A–H dungeon (where the location hint sits in default mode)
is a **dungeon-number chooser**: pick "?" or 1–8 to assign the slot's real
number (`Dungeon.labelChar`). That assignment already drives the model's
triforce-piece placement (`getTriforceHaves`) and two-boxer completion (the
`"234567"` / `"123567"` whitelist), so identifying a dungeon makes those work.

The popover also carries the reference's **triforce reference diagram** — the
1Q/Shapes and 2Q layouts showing which number sits in each triforce position —
because for newer runners it's often the only way to tell which dungeon is which
(and thus whether it's a two- or three-item dungeon). Layouts are transcribed
exactly from the F# `DrawTriforceMapCore` (orderings `"12345678"` / `"13254687"`
and the 8 label positions); the currently-selected number is highlighted in both.

Stylistic liberties vs. the reference popup: the per-dungeon **color** picker is
omitted, and the diagram is redrawn cleanly (outer triangle + positioned
numbers) rather than pixel-matched.

## Acceptance criteria
- [x] HDN slots A–H show a number label ("?" until assigned); Level 9 has none.
- [x] Tapping opens a chooser (? · 1–8) that sets `labelChar`; the label
      updates.
- [x] "Don't assign unless you're certain" warning + the Mixed-Quest 7/8 note.
- [x] Triforce reference: the 1Q/Shapes + 2Q diagrams drawn as proper triforce
      sub-triangles (like the original), stacked vertically; the selected
      number's triangle fills orange in both.
- [x] **Third-box disable (beyond the reference):** once a dungeon is identified
      as a two-item ("two-boxer") number for the quest, its third box is
      disabled (dimmed, non-interactive) so you don't hunt for a nonexistent
      item. Completion still works (a two-boxer completes at 2/3).
- [x] Reference layout data + the two-boxer rule unit-tested.
- [x] On-device verified (assign 5 → label "5", highlighted in both diagrams,
      C's third box disabled).
