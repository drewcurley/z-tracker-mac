# T-138 — Cursor-driven, region-aware voice

## Description
Rebuilds the voice grammar around the **keyboard cursor**, so voice mirrors the
hotkey-cursor model instead of always meaning "overworld mark".

- **Coordinate → move cursor** (`"E7"`), in whatever region is active; **action → apply
  at cursor** (`"potion"` — "shop" optional); **both** (`"E7 bomb shop"`).
- **Region-aware:** a coordinate moves the *active* region's cursor (overworld or the
  dungeon-room grid), clamped.
- **NATO row letters** ("echo seven" = E7) to dodge the "E"/"east" homophone; the
  **compass words were dropped** (only up/down/left/right) at user request.
- **Contextual navigation:** `"start"`/`"restart"` → overworld start tile, or (in a
  dungeon) the **entrance room**; `"overworld"`/`"leave dungeon"` → that dungeon's
  **overworld marker**; `"enter level N"` auto-jumps to the entrance if one is marked.
- **`"set/mark level N"`** marks the cursor tile as that dungeon; bare/`"enter level N"`
  switches the tab — so cursor-nav users don't need a coordinate.
- Take-any claimed item routes through the model linkage (from T-137); `set start` /
  `clear start` supported.
