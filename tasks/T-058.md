# T-058 — Overworld claiming correctness

## Description
Three overworld-tile-claiming fixes:
1. **Bug — placement over-count.** The picker let you place more than the real
   number of a type (a 2nd Dungeon 1, a 5th take-any, a 2nd letter…). Each
   picker option is now **disabled once its per-quest max is reached**, ported
   from the reference's map-square choice domain (`overworldTiles`): dungeons /
   any-roads / sword caves / letter / armos = 1; hint shop / take-any = 4;
   door repair 9/10; money-making game 5/6; potion shop 7/9; shops & secrets
   unbounded.
2. **Unknown secret is always unclaimed** — an unidentified secret can't be
   "collected", so `.secret(.unknown)` is no longer used-toggleable.
3. **Groundhog reset clears the overworld claimed state** — a replay re-collects
   everything, so `resetForGroundhogOrRouters` now clears every tile's used
   flag (keeping the marks).

## Acceptance criteria
- [x] `OverworldTileLimits.maxUses` matches the reference; exhausted picker
      options are disabled (the current tile's own mark doesn't count).
- [x] `.secret(.unknown)` is never claimable; marking it stays unclaimed.
- [x] Groundhog reset clears claimed state but keeps marks.
- [x] All three unit-tested; the disable verified on-device.
