# T-091 — Mid-game Settings window

## Description
The preference panel (`SettingsPanelView`) was only reachable on the startup
screen. Make it reachable during play (user request), as a **single resizable
window** sharing the live `options`, opened two ways:
- a **gear button** ("Settings…") in the Info group, and
- the app menu / **⌘,** (a `CommandGroup(replacing: .appSettings)`).

This is the first slice of the mid-game-settings work; seed-specific flags move to
the Flags section separately (Book-for-Hints → T-092), and the recorder
new/unbeaten toggles land by the recorder widget (T-093). Custom level naming
(replacing BOARD-vs-LEVEL) is deferred.

## Acceptance criteria
- [x] `Window("Settings", id:)` scene reuses `SettingsPanelView`, scrollable + resizable.
- [x] Gear button in the Info group opens it; ⌘, / app menu opens it.
- [x] Shares the running `options` (changes apply live).
- [x] Build clean.
