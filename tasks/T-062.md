# T-062 — "Hide tile icons" view toggle

## Description
A toggle/hover under **Flags** that temporarily suppresses the overworld map's
tile-selection glyphs so the underlying terrain art is legible. Follows the
established map-overlay model (hover previews, click locks) via a new
`OverworldOverlayState.Overlay.hideMarks` case. When active, `TileView`
suppresses every user-placed layer — dungeon/any-road digit badges, interior
and shop icons, the `.dontCare` dark shading, and the used/claimed dim — while
still drawing the terrain and the always-empty / fairy truth beneath.

It is a **view** control, not a seed flag: it changes nothing in the model,
only what is rendered.

## Acceptance criteria
- [x] A "Hide tile icons" control sits in the Flags group.
- [x] Hovering it previews the suppression on the map; clicking locks it on.
- [x] While active, no dungeon numbers, interior/shop icons, dark, or used-dim
      draw on any tile.
- [x] Terrain, always-empty darkening, and the fairy icon still render.
- [x] Overlay highlights (GYR / open caves / zones / coords) are unaffected.
- [x] Unit test covers the new overlay state's hover/lock/independence.
