# T-153 — Item box without qualifier

## Description
Live QA: "armos ladder" *silently marked the overworld armos cave* instead of
filling the box — the box required an "item"/"box" qualifier. Bare "armos" /
"armor" / "white sword" are now Box_* phrases too; because `itemBoxCommand`
requires a **following item**, the item word disambiguates: "armos ladder" → box,
bare "armos" (no item) → still the cave mark (falls through to OW_Armos).
`itemBoxCommand` is already parsed before the overworld region match, and it strips
the longest box phrase, so "white sword item bow" still holds a *bow* not the sword.

## Acceptance criteria
- [x] "armos ladder", "white sword bow", "armor recorder" fill the box.
- [x] Bare "armos" / "white sword" still mark the overworld cave. 601 tests.
