# T-035.6 — Completed-dungeon overworld marker

## Description
When a dungeon is 100% complete (`Dungeon.isComplete` — all items + triforce),
its overworld map badge dims. Two parts:
- **Dark-yellow badge** (reference-faithful): the digit/letter badge switches
  from bright yellow to `RGB(153,153,0)`
  (`OverworldMapTileCustomization.fs:274-294`, `Graphics.fs:874-884`).
- **Full-tile dim** (user request, beyond the reference): the completed tile
  also gets the same full-tile darkening overlay that claimed "used" tiles
  carry, so it reads as done consistently across the map.

The `DungeonTrackerInstance` is threaded into `OverworldMapView`/`TileView` via a
`dungeonComplete: (Int) -> Bool` slot lookup.

## Acceptance criteria
- [x] A 100%-complete dungeon's overworld badge renders dark yellow.
- [x] The completed dungeon tile also gets the full-tile "used" dim overlay.
- [x] Applies in both default and HDN modes; slot 9 uses its own completion.
- [x] Suppressed by "Hide tile icons" like the other mark layers.
