# T-155 — Stop-listening voice command

## Description
Voice could be turned on hands-free but not off. New `Nav_StopVoice` action
("stop listening", "pause voice", "stop voice", "mute voice", "go to sleep",
"stop recording") → `VoiceCommand.stopListening` → `VoiceController.stop()`. Resume
via the FLAGS mic icon / the Global_ToggleVoice hotkey (voice isn't listening once
stopped).

## Acceptance criteria
- [x] "stop listening"/"pause voice"/"go to sleep" stop the recogniser; "restart" still = go-to-start.
- [x] 603 tests.
