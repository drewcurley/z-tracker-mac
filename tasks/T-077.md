# T-077 — Door-repair permanent dim

## Description
User-requested: a door-repair charge is a one-shot spot you never revisit, so
marking one should dim its overworld tile (like a collected "used" spot) — and
that dim must persist across a groundhog-day reset. Matches the reference, where
door-repair is "always dark" (`OverworldMapTileCustomization.fs:218-220`).

- `OverworldTileMark.dimsPermanentlyWhenMarked` (only `doorRepair`) — a
  knowledge-derived dim, independent of the claimable `used` state.
- The overworld tile's dim = `grid.isUsed(...) || mark.dimsPermanentlyWhenMarked`.
  Because it derives from the **mark** (which a groundhog reset keeps —
  `resetForGroundhogOrRouters` only `clearAllUsed()`), the dim persists across the
  reset automatically.

## Acceptance criteria
- [x] A marked door-repair tile renders dimmed; MMG/hint/etc. stay bright.
- [x] Only `doorRepair` dims permanently (unit-tested).
- [x] After a groundhog reset the door-repair mark (and thus its dim) remains
      (unit-tested).
- [x] Build clean; on-device door-repair tiles are dark next to a bright MMG.
