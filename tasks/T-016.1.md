# T-016.1 — HDN model core

## Description
Makes the `DungeonTrackerInstance` honor `.hideDungeonNumbers` mode at the
model level (T-013 built DEFAULT only and guarded HDN off). Ports the HDN
branches of `TrackerModel.fs:682-836`:
- HDN box-count table (dungeons 1–8 get 3 boxes, dungeon 9 gets 2) and no
  shared `finalBoxOf1Or4`.
- `Dungeon.isComplete` HDN branch: triforce + (3 boxes done OR 2 done when
  `labelChar` is a quest-dependent "two-boxer" — `"123567"` 2nd quest /
  `"234567"` 1st quest).
- `color`/`labelChar` per-dungeon state (`"?"`/`"1"…"8"`).
- `getTriforceHaves` HDN indexing: identified `labelChar` → piece index, plus
  HDN starting triforce pieces.

## Acceptance criteria
- [x] HDN construction no longer guarded; box counts `[3,3,3,3,3,3,3,3,2]`,
      `allBoxes()` = 29.
- [x] HDN `isComplete` (3-box and quest-dependent 2-boxer) ported + tested
      against both quests.
- [x] `color`/`labelChar` state added.
- [x] `getTriforceHaves(hdnStartingTriforcePieces:)` HDN indexing ported;
      DEFAULT ignores the argument. Tested.
