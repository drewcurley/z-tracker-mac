# T-025 — Overworld item grid UI (umbrella)

## Description
Renders the reference app's **top-right item grid** (`owItemGrid`,
`Z1R_WPF/OverworldItemGridUI.fs:193+`, laid out by
`OW_ITEM_GRID_LOCATIONS`, `Z1R_Avalonia/OverworldMapTileCustomization.fs:17-42`)
— a 6×4 grid of item boxes the player clicks to record progress. The whole
underlying model already exists (`PlayerProgressAndTakeAnyHearts` item flags +
tri-state take-any hearts, `ladderBox`/`armosBox`/`sword2Box`); this epic is
**pure render** over it. It is the biggest remaining main-tracker gap: today
the player has no way to mark the wood sword, blue candle/ring, magical sword,
bombs, boomstick book, Ganon, or Zelda — even though
`PlayerComputedStateSummary` (T-014) already reads those flags.

Aesthetic license (per project): the reference's cramped 30px canvas grid is
re-laid-out as a clean panel; the Zelda item sprites are kept.

## Sub-tasks
- **T-025.1** — grid scaffold + the 9 toggle item boxes (wood sword/arrow,
  blue candle/ring, magical sword, boomstick book, bomb, Ganon, Zelda) +
  relocate the 3 coast/armos/white-sword picker boxes into the grid.
- **T-025.2** — take-any hearts row (4 tri-state boxes; needs the overworld
  heart sprite from `ow_icons5x9.png`).
- **T-025.3** — located (yellow) / superseded (gray-X) box highlighting,
  driven by `mapStateSummary` shop/cave-found + sword-level supersede logic
  (`yellowWoodSwordLogic`, `blueCandleSuperseded`, …).
- **T-025.4** — surrounding chrome: book/shield toggle, book-is-atlas,
  highlight-open-caves checkboxes; rupee icon + bomb-shop link; max-hearts
  panel; timer reset; spot summary; mirror-OW button.

## Risks / dependencies
- Model complete (T-012/T-013/T-014). T-025.3 depends on `mapStateSummary`
  (T-015.3) located flags. Otherwise independent.
