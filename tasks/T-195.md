# T-195 — Notes.txt auto-population

## Ask (reference parity, coverage §1 #20)
Pre-fill the Notes box at startup from a user-provided `Notes.txt` template, for external
note templates. Reference: `WPFUI.fs:1223` (reads `Notes.txt` from the app dir; if present,
uses its contents as the initial notes).

## Implementation
- `GameSave.notesTemplateURL` = `~/Documents/ztracker/Notes.txt` (alongside the saves, per
  our default-file-location convention).
- `GameSave.seedNotesFromTemplate(into:at:)` fills `model.notes` from the file **only when
  notes are empty** (so it never clobbers a resumed save or typed notes) and the file exists.
- Called at quest start in `ContentView.onQuestSelected` (covers the quest buttons and the
  custom-map start path). The resume path never calls it, so restored notes win.

## Tests
`GameSaveTests`: seeds empty notes; leaves existing notes untouched; missing file is a no-op.
727 tests pass.
