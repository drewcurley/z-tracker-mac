# T-020 — Item + dungeon-cell sprite atlases

## Description
The visual foundation for the main-tracker UI epic (dungeon item-tracker,
item-progress grid, etc.), scoped after driving the reference app to
understand its layout/interactions. Ports two MIT-licensed sprite sheets and
builds slicing atlases matching the existing `Overworld*Atlas` pattern:
- **`icons7x7.png`** (224×7 = 32 item icons) → `ItemIconAtlas`, with the
  `ITEMS` index → icon mapping transcribed from the reference's
  `allItemBMPsWithHeartShuffle` (`Graphics.fs:530-548,778-779`). These render
  the dungeon item boxes and the item grid.
- **`zelda_items16x16.png`** (208×16 = 13 dungeon-cell icons: triforce/heart/
  map/compass/… and `staircase`) → `DungeonCellIconAtlas`. `staircase` is the
  basement-stair glyph that renders `currentlyHasBasementStair` (T-016.2).

Shared `AtlasLoader` (black→transparent masking) + an `Image(atlasIcon:)`
convenience.

## Context: the main-tracker UI epic
Driving the Windows reference (via Wineskin) established the full main-tracker
layout + interactions: dungeon item-tracker (boxes + 3-way-mouse picker +
basement stairs + located numerals), item grid, blockers grid, overworld
(done), dungeon room-grid view, timeline. The user granted **aesthetic
license** — keep all functionality but the Mac UI may look nicer than the
cramped Windows original. This task is step 1 (assets); the UI pieces follow.
