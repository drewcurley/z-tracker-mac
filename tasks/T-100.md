# T-100 — Break-out windows: Timeline

## Description
The first of the user's "break each major area out into its own window" idea. The
Timeline gets a pop-out button that opens it in a separate window; closing the
window restores it inline. Works because the timeline's data (`model.timeline`) is
already app-level, so the window just mirrors the same model.

- `BreakoutWindows` (`@Observable`, app-level): `timelinePoppedOut` flag shared
  between the inline section and the window scene.
- `Window("Timeline", id: TimelineWindowID)` renders `GameTimelineView`; its
  appear/disappear toggles the flag.
- Timeline section: a pop-out button (`openWindow`); while popped, the inline area
  shows a "Timeline is in a separate window · Bring back" placeholder
  (`dismissWindow`). Collapse + pop-out buttons both present (on by default).

The pattern extends to the other three major areas (overworld, dungeon band, top
section) and the timer later.

## Acceptance criteria
- [x] Pop-out opens the timeline in its own window; closing restores it inline.
- [x] Inline shows a placeholder + "Bring back" while popped.
- [x] Window mirrors the same live model; collapse still works.
- [x] Build clean; launches without crash.
