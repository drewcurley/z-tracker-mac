# T-130 — Hotkey config model

## Description
The pure, testable core of the hotkey feature (Part A). No key *fires* yet — that's
Part B (runtime dispatch).

- `HotkeyContext` (7): items, overworld, blockers, dungeonRoom, hintZones, contextual,
  global (with an editor order that puts Global first, contextual last).
- `HotkeyCatalog` — the full selector list transcribed from the reference `HotKeys.txt`
  (exact ids) so files round-trip; + two Mac-only Global selectors (`Global_StartTimer`,
  `Global_GroundhogReset`).
- `HotkeyChord` — key + optional Shift/Ctrl/Alt; `HotKeys.txt` token + display forms.
- `HotkeyConfig` — bindings store, `parse`/`exportText` (Windows format), persistence,
  and the conflict model: unique within a context, Global unique across all
  non-contextual contexts, contextual per-menu (Take-Any vs Take-This). `reassign`
  **moves** a key (removes it from anything it conflicts with) — no duplicates.

## Acceptance criteria
- [x] Catalog covers all 7 contexts with unique ids; round-trips via export→parse.
- [x] Conflict rules match the reference; `reassign` displaces conflicts.
- [x] Chord parsing handles keys, modifiers, and `\nnn`; bindings persist.
- [x] Unit-tested (11 assertions across catalog/parse/conflict/reassign/round-trip).
