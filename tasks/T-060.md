# T-060 — Two-item shops

## Description
Zelda shops carry two items. The tracker only let you set one (the `.shop(kind)`
mark); the second-item slot existed in `extraData` (read by `MapStateSummary`)
but wasn't settable or shown. Now the picker has a **"Shop — 2nd item"** submenu
(None + 8 items, the primary disabled to prevent a duplicate), and the tile
renders **both** icons in `ShopKind` listing order — stable left→right
regardless of which was chosen first.

(The reference records two items — the original creator judged that sufficient
even though shops technically hold three; matched here.)

## Acceptance criteria
- [x] "Shop — 2nd item" submenu appears only for shop tiles; picks/clears the
      second item (`shopExtraDataKey`, toItem encoding).
- [x] The primary item is disabled in the 2nd-item list (no duplicates).
- [x] The tile shows both items in `ShopKind` order, not selection order.
- [x] Model unit-tested; on-device verified.
