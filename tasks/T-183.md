# T-183 — Spoiler-log dungeon room-map importer

Completes the one section T-181 deferred: parse each `LEVEL N MAP` ASCII block and
populate the dungeon's `DungeonRoomMap`.

## Format (user-verified against the real seed's 9 maps)
Block = header, 1 blank, 15 grid lines (8 room rows interleaved with 7 door rows),
optional 16th arrow line. CRLF (strip `\r`); parsed from raw whitespace-significant
lines. Rooms at even char cols (`rawCol = (charPos-2)/2`, 0–15), `row = line/2` (0–7).
`*` room · `-`/`|` open doors · `< > v ^` entrance wall · **A–H = transport pairs 1–8**
(each letter appears twice). No monster/item/room-type content is in the map.

## Apply (normalize 16→8)
A dungeon's connected cluster always fits an 8-wide column window. Pick the window
capturing the most rooms, map in-window rooms directly, **off-map every non-room cell**
so the shape reads, place transports + the entrance, open the doors. The few outliers
(always transport ends, verified) are **relocated to the nearest free cell** — their
column is cosmetic since they teleport. Overwrites the map (spoiling is the point).

## Validation
Swift smoke over the real log matched the Python decode exactly: L1–9 =
15/16/19/22/23/29/34/38/47 rooms, every transport pair complete, 1 entrance each,
5 relocations total (L7:1, L8:2, L9:2).

## Tests
`SpoilerLogTests`: crafted map fixture — raw-coord parse (rooms/transports/doors/
entrance) + apply (windowing, off-map shape, transports, outlier relocation, entrance,
doors, summary counts). 708 tests pass.

## Known limitation
Walls between two known rooms import as **unknown** (only open doors are set `.yes`).
Transport columns are approximate for the ≤2/dungeon outliers (pairs are exact). The
drag-to-swap (T-182) is item boxes, not rooms — room mis-imports are corrected with the
existing room paint/GRAB tools.

## QA checklist
- [ ] Import a spoiler → each dungeon shows its outline (off-map surround), the entrance
      icon, transport-stair pairs, and open doors.
- [ ] L9 shows a large map with all 8 transport pairs.
- [ ] Result summary reports "9 room maps (5 transports moved to fit)".
- [ ] Re-import overwrites cleanly (no stale rooms/doors from a prior import).
