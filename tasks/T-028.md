# T-028 — Coast item can never be the ladder

## Description
The coast item (found off the coast at F16) is reached **using the ladder**, so
it can never itself be the ladder — you'd need the ladder to obtain the ladder.
The item picker for the coast box (`ladderBox`) must therefore disallow the
ladder item. The armos and white-sword item boxes have no analogous
dependency and keep every option.

**Deliberate deviation:** the reference app imposes no such restriction (a
user-requested improvement). Recorded so it isn't later "corrected" back toward
1:1 parity. See memory `[[project_coast-item-not-ladder-rule]]`.

## Acceptance criteria
- [x] `DungeonTrackerInstance.canSelectItem` returns `false` for the ladder
      item in the coast box (`ladderBox`), and is unchanged for every other
      box/item combination (incl. armos/white-sword boxes and the ladder in
      dungeon boxes).
- [x] The picker UI greys out / blocks the ladder for the coast box (flows
      automatically from `canSelectItem`). On-device verified: ladder dimmed in
      the coast picker, full-opacity elsewhere.
- [x] Tests: ladder disallowed in `ladderBox`; ladder still allowed in a
      dungeon box and unaffected in armos/white-sword boxes; the rule composes
      with the uniqueness rule.

## Out of scope
- Any other cross-box logical constraints (none requested).
