# T-216 — Spot Summary breakout: scale + current icons

Two drift/polish fixes on the Spot Summary, surfaced during the Commentary-Mode session. Ships in
**v1.2.0** alongside Commentary (T-215), on its own branch.

## Behavior
- **Scale on resize.** The Spot Summary breakout window was resizable but its content stayed a fixed
  340-wide view, leaving dead space. It now scales the whole summary by (window width ÷ natural
  width), clamped to ~0.8×–3×, so it fills a resized window (both larger and smaller).
- **Current icons.** `OverworldMarkIcon` (used by both the inline popover and the breakout) still
  drew the *old* atlas glyphs and kept the orange shop plate we removed from the map. It now prefers
  the real `GameSprite` art like the overworld map: shops with **no orange plate** (T-212), real
  sword sprites (T-213), interior game sprites, and 1/2/3 five-rupee clusters for
  small/medium/large secrets. The old atlas glyphs remain only as a fallback when no sprite is mapped.

## Implementation
- `SpotSummaryView.naturalWidth` (static 340) replaces the hardcoded frame width and drives scaling.
- `SpotSummaryWindowView` wraps the summary in a `GeometryReader`, computes the fill-scale, and
  applies the existing `scaledFootprint(_:naturalWidth:)` modifier (the same footprint-collapsing
  helper the dungeon-map zoom uses). Both-axis `ScrollView` handles any overflow.
- `OverworldMarkIcon` gains `interiorSprite` / `swordCave` / `shopSprite` / `secretRupees` helpers
  that prefer `GameSprite.overworldFile` / `.itemFile` / `.shopFile` (+ the `5 Rupees` sprite),
  mirroring `OverworldMapView`. `shopBg` removed.

## Tests
No new logic (view/derivation only); the change is rendering + layout. **758 tests pass** (unchanged
from T-215).
