# T-052 — Confirm destructive toggles after Go, even when paused

## Description
T-051 gated the Heart Shuffle / Hidden Dungeon Numbers confirmations on
`timer.isRunning`, so a paused run skipped the warning. Misclicks happen while
paused too, so the gate now uses `timer.hasStarted` — the confirmation shows
anytime after Go, whether the timer is running **or paused**. Before the run
starts (setup), the toggles still apply directly.

Reset Timer / Reset App / Reset (keep maps) are unaffected — they already
confirm unconditionally.

## Acceptance criteria
- [x] After Go, toggling Heart Shuffle / Hidden Dungeon Numbers confirms
      whether the timer is running or paused.
- [x] Before Go, they still apply directly (no confirmation).
- [x] The guard helper's parameter is caller-driven (`confirmFirst`), not
      timer-specific.
- [x] On-device verified (paused run → HDN toggle shows the confirmation).
