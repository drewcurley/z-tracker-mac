# T-019.5 — Dungeon room-map grid (D1)

## Description
First render slice of the per-dungeon room map over the D0 model (T-019.3). Adds
the map card to the dungeon band: a tab strip (dungeons 1–9 + Summary, plus
disabled FQ/SQ vanilla-outline placeholders), the selected dungeon's 8×8 room
grid with room-type sprites, the `LEVEL-N`/`BOARD-N` header spread one character
per column, an info strip (old-man count + reserved dungeon-items box), and a
click-to-open room-type picker (the reference's 7-wide grid order,
`DungeonPopups.fs:254-261`). Monsters, floor drops, completion toggle, doors, and
the Summary overview are later slices (D2/D3/D6).

Sprites come from the reference `new_icons13x9.png` (uncompleted top / completed
bottom variants). Room-type → tile-index map mirrors `DungeonRoomState.BmpPair`.

Follow-up fixes applied from user review of the first render:
- Tab bar was bunched left with dead space — now the dungeon tabs spread evenly
  across the full map width, FQ/SQ pinned to the right edge.
- The map card grew with window width, wasting space on wide windows — now capped
  at its natural content width (`DungeonMapView.contentWidth`, derived from the
  grid + info-strip constants), and the Blockers/Notes column grows to absorb the
  extra width instead (`minWidth: 390, maxWidth: .infinity`).
