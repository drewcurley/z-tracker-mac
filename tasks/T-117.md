# T-117 — Overworld tile enemies

## Description
Deliberate deviation beyond the reference (user request): overworld tiles can now
carry an **up-to-two enemy annotation**, like dungeon rooms, from a reduced set —
wizrobes, darknuts, lynels, pols voice, goriyas, gibdos, ropes, stalfos, tektites,
moblins (`MonsterDetail.overworldEnemies`, all mapping to existing monster sprites).

- `OverworldGrid` stores 2 enemy slots per tile (`enemyPair`/`enemies`/`toggleEnemy`),
  reusing the shared `MonsterDetail.togglingPair` normalization (extracted from
  T-116 so dungeon rooms and overworld tiles behave identically). Enemies are map
  knowledge, so they survive a groundhog/routers reset (`clearAllUsed`) and are only
  wiped by `clearAll`.
- The tile context menu gains an **Enemies** submenu (checkmarks show current picks;
  "Clear enemies" when any are set).
- Up to two enemy sprites render along the tile's bottom-leading edge, counter-flipped
  under a mirrored map.

## Acceptance criteria
- [x] The 10 requested enemy types are offered.
- [x] A tile holds up to two enemies; both render.
- [x] Enemies are per-tile and independent; survive groundhog reset; wiped by clearAll.
- [x] Unit-tested; build + full suite clean.
