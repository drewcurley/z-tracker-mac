# T-053 — Spot Summary

## Description
Ports the reference's **Spot Summary** (`MakeRemainderSummaryDisplay`) — a
"Remaining Locations Summary" showing what's still to be found on the overworld:
- **Unique locations** (one-of-a-kind): dungeons 1–9, any-roads 1–4, the three
  sword caves, the letter, and the armos item — dimmed once marked on the map.
- **Secrets remaining** by size, against the quest's totals (first-quest
  overworld: 3 large / 7 medium / 4 small; second-quest: 1 / 7 / 6).

Our `OverworldGrid` has no cross-cell use-counting like the reference's
`mapSquareChoiceDomain`, so this is derived by counting the grid marks. The
reference's unknown-secret bin-shuffling is simplified to a "+ N marked without
a size" note.
