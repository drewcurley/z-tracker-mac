# T-035 — Topmost section build-out (umbrella)

## Description
Flesh out the app's top section (above the overworld map) toward the real app's
layout — verified against the **Windows VM** (the Wine build has layout bugs).
Beyond the item grid (T-025, done), the reference top area has:

- **Map-overlay toggles** — icons that show a map overlay on hover and *lock it
  on* when clicked (user preference: **click the icon to toggle the lock — no
  separate checkbox** cluttering the UI):
  - **Open caves** — highlights unmarked open caves (`Nothingable`) until the
    wood sword cave is marked or you have both a sword and a candle; then just
    Armos spots.
  - **Rupee / money** (the blue-rupee icon by the bombs icon) — highlights
    Money Making Game, Unknown money secret, and known-yet-unclaimed money
    secret spots (`showLocatorRupees`).
  - **Zones** — outlines/labels the game's overworld regions (`owMapZone`).
  - **Coords** — overlays A1…P8 coordinates on the map.
  - (Swords→bombs icon = already the swordless toggle, T-025.4.)
- **Dynamic status fields** — "N OW spots left" and "N gettable" (capability-
  aware: raft/recorder/bracelet/candle/bombs, per quest). Already computed in
  `MapStateSummary` (`owSpotsRemain`, `owGettableLocations`).
- Later: timer + Pause/Reset, Spot Summary, FQ/SQ, recorder-warp destinations.

## Sub-tasks
- **T-035.1** — dynamic status fields (OW spots left, gettable). ← first
- **T-035.2** — open-caves + rupee/money hover-preview + click-lock overlays.
- **T-035.3** — Zones + Coords overlays (hover-preview + click-lock).
- **T-035.4** — timer / Pause-Reset / Spot Summary / FQ-SQ (as scoped).

## Notes
- Overlay interaction model: hover an icon → preview overlay on the map; click
  the icon → toggle a persistent lock of that overlay. No separate checkboxes.
- Reference: consult the Windows VM ("Windows 11 64-bit Arm") for exact
  behaviors, plus `OverworldData.fs` (`owMapZone`, capability masks) and the
  WPF locator code (`showLocatorRupees`, `Nothingable`).
