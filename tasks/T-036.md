# T-036 — Groundhog / routers reset

## Description
The reference's "Reset the TRACKER (remove inventory but preserve maps) for
groundhog/routers/4+4" button (`OverworldItemGridUI.fs:678-717`,
`ResetForGroundhogOrRoutersOrFourPlusFourEtc`). For replaying the same seed
from scratch while keeping everything you've learned.

`TrackerModel.resetForGroundhogOrRouters()`:
- **Reset** (run progress): dungeon triforces (1–8); every non-`.skipped`
  box's *possession* → `.no` (keeping its item *identity* + skipped marks);
  all `playerProgress` (progress items + take-any hearts — the "used" state);
  the reminder engine (announcements fire again).
- **Kept** (knowledge): overworld tile marks, box item identities, dungeon
  labels, blockers, and the seed's starting items.

Note: the reference's overworld extra-data "used" revert (priced secrets →
bright) is a no-op here — that state isn't set anywhere yet (it lands with the
money overlay / claim UI, T-035.2). In this app the take-any / wood-sword /
candle "used" state lives in `playerProgress`, which `resetAll()` clears.

## Acceptance criteria
- [x] `resetForGroundhogOrRouters()` clears inventory (triforce, box
      possession, progress, take-any) and keeps knowledge (marks, box
      identities, skipped, starting items). Tested.
- [x] A "Reset (keep maps)" button with a destructive confirmation dialog
      (no save/load yet, so it can't be undone — the dialog says so).

## Out of scope
- Save-before-reset (needs save/load, not built).
- Reverting overworld extra-data used-state (needs the claimed-state model).
