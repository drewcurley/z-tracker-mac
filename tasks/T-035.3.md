# T-035.3 — Map-overlay toggles: Zones + Coords

## Description
The other two top-section overlay toggles (same hover-preview / click-lock
model as T-035.2), added as two more cases on `OverworldOverlayState.Overlay`:

- **Zones** — tint each screen by its overworld region. Ported
  `OverworldData.owMapZone` (8×16 letter grid) + the per-letter colors
  (`UIComponents.fs:1006-1017`; M/L/R/H/C/G/D/F/S/W). `OverworldZones` (data +
  color); the map draws a translucent region tint.
- **Coords** — overlay each screen's coordinate. Ported `WPFUI.fs:626/1305`'s
  `"%c%d"` = **row letter (A–H) + column number (1–16)**, so the coast at
  (col 15, row 5) reads "F16". `OverworldCoords.label`; the map draws the label
  top-left.

Icons: `map.fill` (Zones) + `number` (Coords) SF Symbols in the chrome.

## Acceptance criteria
- [x] `OverworldZones` (8×16 data + 10 zone colors) and `OverworldCoords.label`
      (A1…H16), tested (incl. the F16 coast check).
- [x] `.zones` / `.coords` overlays render (region tint / coord labels) when
      active; two chrome toggle icons wired.
- [x] On-device verified: Zones tints the regions, Coords labels the screens.

## Out of scope
- The reference's white zone-boundary lines (tint-only here — the colors show
  the regions); Mirror-flipped coord numbering (`16-i`, needs MirrorOverworld,
  T-015.7).
