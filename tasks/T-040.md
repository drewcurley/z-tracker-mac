# T-040 — Sword hint label placement

## Description
T-039 first placed the white/magical-sword hint labels in the "Items" header,
then above the wrong columns: the empty grid slots between them collapsed
(an empty `Group` doesn't hold a `.frame` width), so both labels drifted left —
landing over the White Sword *indicator* (col 0) and the White Sword *item box*
(col 1) instead of their boxes.

Fix (user-directed): the White Sword cave hint sits over the **White Sword item
box (col 1)** and the Magical Sword cave hint over the **Magical Sword box
(col 2)**; every column reserves a fixed-width slot (`Color.clear` for empties)
so the labels stay aligned over their boxes.

## Acceptance criteria
- [x] White Sword hint above col 1; Magical Sword hint above col 2.
- [x] Empty columns reserve width (no collapse / drift).
- [x] On-device verified.
