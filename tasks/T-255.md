# T-255 — Mouse magnifier window

## Description
Audit §4 'built but hidden': the option existed (T-206 hid it) but the window was never built. Port of the reference's makeMouseMagnifierWindow (Layout.fs:428-529).

## Acceptance criteria
- [x] 'Mouse magnifier window' (Settings, default off) opens a resizable 'Mouse Magnifier' window showing the tracker at 3× around the mouse, nearest-neighbor, on a dark-slate-blue background, with a white arrow marking the pointer.
- [x] It follows the mouse over the main tracker window (~30 fps, with a trailing update so a fast move lands on its final spot); over other windows it keeps the last view.
- [x] Opens at launch when the setting is on; toggling the setting opens/closes it; focus returns to the tracker after opening; its frame is remembered.
- [x] No screen-recording permission: the tracker snapshots its own content view (cacheDisplay), verified with a SwiftUI hosting view.

## Notes
Limitation vs the reference: popovers/menus are separate windows, so they aren't in the magnified view. The reference's 8-second instructions box is not ported (explainer). Tests: MouseMagnifierTests (2).
