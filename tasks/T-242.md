# T-242 — Release pipeline hardening

## Problems (audit, and seen live on v1.2.12)
- A failure partway through `make-dmg.sh` (Intel notarization after arm64 succeeded) left an
  unnotarized DMG under its release name, the previous version's Intel appcast, and an x86_64
  project-root app (the restore step never ran).
- Misconfiguration degraded silently: a mistyped `ZTRACKER_SIGN_ID` fell back to ad-hoc signing;
  an unset notary profile skipped notarization; a missing `sign_update` only warned; nothing checked
  the (vanishing) keychain notary profile before a 10-minute build.
- The DMG itself wasn't code-signed; the notarization result wasn't checked; the appcast carried no
  release notes (users skipping versions saw nothing); the release tag could drift from the built
  commit; the SwiftBuild backend's shared output folder could hand back the wrong arch; a flat-layout
  plist was being added to the new deep resource bundle.

## Fix
- `make-dmg.sh`: preflight (Developer ID identity present, notary credentials work, `sign_update`
  present, clean tree) before building; `.p8` App Store Connect API key supported alongside the
  keychain profile; per-arch staging in `dist/.staging` with old outputs removed first; DMG
  code-signed; notarization status parsed (`Accepted` required, Apple's log printed otherwise);
  staple + validate + Gatekeeper check; EdDSA signature checked; appcast gains `pubDate`, the
  version's CHANGELOG section as HTML `<description>`, and a full-CHANGELOG link; min OS read from
  the bundle template; an EXIT trap always restores the host-arch app.
- `build-app.sh`: asserts the built binary's arch; skips the flat plist on a deep bundle; an
  explicitly requested identity that's missing is an error (dev fallback unchanged); verifies the
  Developer ID signature and hardened-runtime flag.
- `docs/RELEASING.md` rewritten for the real process (credentials, preflight, partial-failure
  recovery, `gh release --target`, verification, Intel end-of-life plan, key backup outside the repo).

## Verified
`bash -n` + ShellCheck clean; preflight fails fast (0.4 s) with no/bad identity; with real
credentials it passes identity + live notary checks and stops at the clean-tree check; release-notes
HTML extraction checked against 1.2.12; dev `build-app.sh` unchanged (arch assert passes). A full
signed release run is exercised at the next release.
