# T-085 — Door scroll quick-set

## Description
User: make the common door marks a single flick. Green and red are already the
left- and right-click; so on an as-yet **unknown** door, scroll-**down** now jumps
straight to **gold** and scroll-**up** to **purple** — putting all four door
states one gesture away. Once a door is placed, scrolling cycles as before
(green → red → gold → purple). Goal: the most common marks are the fastest to log
with just the mouse/trackpad.

- `DoorState.scrollDown` = `unknown ? .yellow : next`; `scrollUp` = `unknown ? .purple : prev`
  (an unknown door's `prev` already landed on purple; only scroll-down changed,
  from the redundant green to gold).

## Acceptance criteria
- [x] Unknown door: scroll-down → gold, scroll-up → purple.
- [x] Placed door: scroll cycles normally (unchanged).
- [x] Left = green, right = red unchanged; quick-set applies to shift-scroll too.
- [x] Logic in the model, unit-tested.
