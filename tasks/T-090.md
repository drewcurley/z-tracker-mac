# T-090 — Blockers layout + Level 9

## Description
Two user requests:
1. The blockers grid repeated "Blockers" in its top-left cell under the group
   header of the same name. Drop that cell; every dungeon shifts one column left.
2. Add a blocker row for **Level 9** to track what's blocking progress there.

Together these fill a clean 3×3 of dungeons 1–9. A deliberate deviation from the
reference (which excludes L9): `DungeonBlockersContainer.dungeonCount` 8 → 9, and
the reminder engine's blocker-unblock loops extend to include L9, so an L9 blocker
also fires "You can revisit dungeon 9 …". L9 has no triforce cell, so its
applies-to panel offers only its item boxes.

- [x] No redundant "Blockers" label cell; dungeon 1 starts in the left column.

- [x] Model + reminder logic unit-tested; layout verified on-device.
