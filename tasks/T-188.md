# T-188 — Real light theme

Follows T-187 (the theme picker). A **real** light theme: dark text on light surfaces via
wide color swaps, not dark cards on white (a first attempt at "dark cards on light" was
discarded per user feedback).

## Approach
- `Theme.swift` — semantic tokens resolving per app appearance (`NSColor` dynamic provider):
  `boxFill` / `cardFill` / `panelFill` / `border` / `hairline` / `canvas` go light in Light,
  dark in Dark. **Text keeps `.primary`/`.secondary`** (already adaptive). Game-content
  imagery (overworld terrain, dungeon room grid) stays dark — it's map art, with black baked
  into the room sprites — so those are dark panels within the light UI.
- Swapped the hardcoded dark fills/borders and fixed-light text across: dungeon item cards,
  the Items/obtainables group, section cards (`TopSectionGroup`), Blockers, Spot Summary,
  Timeline (ruler ticks; the floating event tooltip stays a dark pill by design), the
  dungeon-map chrome (tabs/GRAB/FQ-SQ/pickers/zoom), Notes, hint labels + zone picker,
  the hotkey + voice editors, the graphical chooser.
- Sprite backgrounds: most atlases are black-keyed transparent already; widened the key to
  catch the **near-black** floor-drop tile background (`threshold`) so the row-locator
  rupee/key/bomb read on light.

## User-requested polish (during QA)
- Notes text: green in Dark, black in Light (`Theme.notesText`).
- Graphical chooser: unmarked cell's X kept white (distinct from Don't-Care in Light).
- Hint gold (`Theme.hint`): bright yellow in Dark, dark goldenrod in Light; plus a **1px gold
  outline** on a *set* dungeon-location hint in Light (the color shift alone was too subtle).
- Row-locator: icons shifted right, hover markers widened, old-man readout centered.
- Zoom control: track the scaled info-strip width so it no longer bleeds over the corner box
  at 80% while staying full at 100/120%.
- **Theme persistence:** `appTheme` now saves immediately on change (not just at quest start),
  so a mid-session switch survives a quit.

## Tests
`TrackerOptionsTests`: theme default + immediate persistence. 722 tests pass. (Visuals were
QA'd on-device across the sections; user signed off.)
