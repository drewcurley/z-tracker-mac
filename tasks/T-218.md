# T-218 — Shop & Price tracker

A breakout window to record shop stock + prices in one place (inspired by zhelper), plus the
Info-panel changes that make room for it. Ships as **v1.2.2**.

## Behavior
- **Shop & Price window** (breakout-only): 4 shops (SH1–SH4) × 3 item slots, each slot picking one of
  the **8 shop staples** + a price; **two potion** prices; one **bomb-upgrade** price (2 upgrades,
  same price); **6 paid hints** as two hint shops × 3, each with a price + a **collected** checkbox.
  Standalone manual record (not linked to overworld shop marks). Saved with the game.
- **Item picker** opens on **left or right click** — a 2×4 graphical icon grid or a text list,
  following the same `graphicalOverworldChooser` setting the overworld uses; includes Clear.
- **Info panel:** the overlay-icon grid goes 2×3 → **2×4**. Top-row 4th = a **cart** that opens/closes
  the window (green while open). Bottom-row 4th = the **Commentary** quick toggle as a race-flag icon
  (the old checkbox is removed). No extra app vertical space.
- **Bomb-upgrade glyph:** the low-fi `wsMsBombUpgrade` atlas icon is replaced everywhere by the real
  bomb sprite + a green "+" (`BombUpgradeGlyph`) — swordless flag tile, swordless item boxes, and the
  shop window.

## Implementation
- `ShopPriceRecord` (TrackerCore, `@Observable`, saved `State?` on the model snapshot; restore
  normalizes a ragged/short save to the fixed 4×3 / 2×3 shape).
- `ShopPriceView` + `ShopSlotItemButton` + `ShopStaplePicker` (ZTrackerMac); `Window(id:
  ShopPricesWindowID)` with `model.showShopPricesWindow` driving the cart tint (transient, like
  `showProgressWindow`).
- `BombUpgradeGlyph` routed through `ItemGlyph` so every bomb-upgrade render is consistent.

## Tests
`ShopPriceRecordTests` — fixed shape, clear, save/restore round-trip, malformed-save normalization
(cycle helper retained + tested). **766 tests pass.**
