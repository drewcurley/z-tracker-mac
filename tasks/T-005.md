# T-005 — Settings panel follow-ups

## Description
`T-004` deliberately left several things disabled/deferred rather than guess
their contents or placement:
- The "More settings…" button (Overworld settings column) — its expanded
  contents were never confirmed against the reference app by screenshot.
- The "Change voice…" button (Reminders column) — needs real
  `AVSpeechSynthesisVoice` enumeration and a picker, not just a field.
- Five `TrackerModelOptions.fs` fields whose *placement* (this screen vs. the
  main window's own Options menu) is unconfirmed: `RequirePTTForSpeech`,
  `UseBlurEffects`, `GiveDungeonTrackerSunglasses`, `HideTimer`,
  `DefaultRoomPreferNonDescriptToMaybePushBlock` (see `docs/domain.md` § 4.1).

## Acceptance criteria
- [ ] Resolve each item above by checking the reference app directly (source
      and/or a live run) — not by guessing plausible placement.
- [ ] "More settings…" either implemented for real or explicitly decided as
      out of scope with a reason (e.g., if it only matters for features this
      project hasn't built yet).
- [ ] Voice picker lists real installed voices via `AVSpeechSynthesisVoice.speechVoices()`.
- [ ] `docs/domain.md` § 4.1 updated to remove the "unconfirmed placement" language.

## Out of scope
- Anything not already listed above.

## Risks / dependencies
- Depends on `T-004` — complete.
- Low priority — none of these block further feature work (overworld map,
  dungeon tracker) which is likely higher-value to pick up first.
