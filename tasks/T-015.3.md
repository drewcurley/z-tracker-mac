# T-015.3 — `recomputeMapStateSummary` + `MapStateSummary`

## Description
The central overworld-state derivation. Ports `TrackerModel.fs:1013-1143`:
the `MapStateSummary` type (`:1015-1030`), the 8 discovery booleans
(`magsCaveFound`, `woodSwordCaveFound`, `foundBlueRingShop`, `foundBookShop`,
`foundCandleShop`, `foundArrowShop`, `foundBombShop`, `havePotionLetter`,
declared at `:1013`), and the full recompute loop (`:1035-1143`) producing
`owGettableLocations` (the red/GYR input), `owRouteworthySpots`, the
dungeon/any-road/sword/armos locations, `owSpotsRemain`,
`owWhistleSpotsRemain`, `owPowerBraceletSpotsRemain`, and the
first/second-quest-only interesting-mark arrays.

All player-state inputs already exist: `PlayerComputedStateSummary` (T-014),
`DungeonTracker`/`armosBox` (T-013), `PlayerProgressAndTakeAnyHearts` (T-012).
