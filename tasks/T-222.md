# T-222 — Chooser hover labels + Ganon spelling

Two small fixes. Ships as **v1.2.4**.

## Bugs
1. The dungeon **room type**, **monster**, and **floor drop** choosers and the **overworld enemy**
   chooser didn't show the **live header label on hover** that the graphical overworld tile chooser
   has (T-205) — you had to wait out the system tooltip to see an option's name.
2. The room chooser spelled the room "**Gannon**"; correct is "**Ganon**".

## Fix
- Added a `hoverLabel` `@State` + `.onHover` to each of the four pickers (`RoomTypePicker`,
  `MonsterPicker`, `FloorDropPicker`, `OverworldEnemyPicker`), mirroring `GraphicalTileChooser`: the
  header shows the hovered option's name (primary color), reverting to the static prompt otherwise.
  Uses the same "clear only if this cell's label is still showing" guard so moving between cells
  doesn't blank the header.
- `RoomType.displayDescription` for `.gannon` → "Ganon" (display string only; the internal `.gannon`
  case name is unchanged, and every other surface — hotkeys, voice — already said "Ganon").

## Tests
No new logic (view hover state + a string). **771 tests pass**; no test asserted the old spelling.
