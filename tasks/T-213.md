# T-213 — Sword-cave real sprites + first notarized release

## Sword-cave sprites
The three sword-cave markers were the last overworld icons still using the small atlas glyph on a
dark plate. `swordCaveBadge` now draws the **real game sprites** (Wooden / White / Magical Sword
via `GameSprite.itemFile`) filling the tile with a drop-shadow for contrast — no plate — matching
the shop redraw (T-212 #3) and interior sprites. Falls back to the atlas glyph only if a sprite is
missing.

## Notarization (milestone)
This is the **first Developer ID-signed + Apple-notarized release**. The user's paid Apple
Developer enrollment activated; a Developer ID Application certificate (Team `VB8Y4UKJPQ`) was
created via CSR + the web portal (Xcode is incompatible with their beta macOS), imported with the
G2 intermediate, and a `notarytool` keychain profile (`ztracker-notary`) stored. `build-app.sh`
already signs with the hardened runtime + `Bundle/ZTrackerMac.entitlements` when a Developer ID
identity is present; `make-dmg.sh` notarizes + staples each DMG. No more first-launch
right-click-to-open.
