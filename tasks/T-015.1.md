# T-015.1 — Overworld terrain-capability masks + `OverworldInstance`

## Description
The pure, table-driven foundation the rest of T-015 needs. Ports
`OverworldData.OverworldInstance` and its `PrivateInternals` character masks
(`OverworldData.fs:62-339`) — the per-screen "can this overworld square be
uncovered by whistle/bomb/burn/raft/ladder/power-bracelet, and is it
always/sometimes empty" predicates that `recomputeMapStateSummary` (T-015.3)
and true GYR (T-015.4) consume. Zero dependencies; fully testable in
isolation.

## Acceptance criteria
- [x] All ~13 literal 16×8 masks transcribed verbatim + the 3 derived masks
      (`mixedQuestAlwaysEmpty`, `firstQuestOnly`, `secondQuestOnly`) computed
      exactly as the reference. — `OverworldInstance.swift`.
- [x] `OverworldInstance` predicates ported (`alwaysEmpty`, `ladderable`,
      `hasArmos`, `raftable`, `whistleable`, `powerBraceletable`,
      `gravePushable`, `burnable`, `bombable`, `nothingable`,
      `sometimesEmpty`), including the MIXED = 1Q-OR-2Q rules and the
      first-quest/single-quest special cases. — done.
- [x] Transcription-verification tests: per-mask `X`-count pinned to the
      reference source (counted from `OverworldData.fs`), derived-mask
      counts, MIXED-OR equivalence, quest branching. — 8 tests; 122/122.

## Out of scope
- `OWQuest.BLANK` (the reference's custom-overworld mode) — already omitted
  from the Swift `OverworldQuest` enum; deferred with that mode.
- Everything that *consumes* these predicates — T-015.2 … T-015.6.

## Risks / dependencies
- Transcription risk: ~104 hand-copied 16-char rows. Mitigated by the
  per-mask `X`-count pins against the reference.
