# T-035.11 — Top-section layout consistency

## Description
A consistency pass on the top section (user request):
- **Reset buttons** (Reset App / Timer / keep-maps) moved to the **right of the
  timer** (extracted into `ResetButtonsView`).
- **OW-spots / gettable** readout enlarged and moved into the open space **left
  of the timer** (`StatusReadoutView`).
- **"Hide tile icons"** is now an **icon in the Info overlay-toggle row** (first
  slot) rather than a Flags checkbox — it was always the same `.hideMarks`
  overlay (hover-preview / click-lock), so this unifies it with open-caves /
  money / zones / coords.
- **"Auto-map dungeons…"** moved under **Flags** (it's game config), extracted
  into `AutoMapDungeonsMenu`.

The Info group is now just Spot Summary + the overlay-icon row.
