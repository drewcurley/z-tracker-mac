# T-035.9 — Item Progress bar

## Description
A read-only progression strip below the map (ported from `MakeItemProgressBar`,
`UIComponents.fs:433`). 13 item cells — sword, candle, ring, bow, arrow, wand,
book/shield, boomerang, ladder, recorder, bracelet, raft, key — each showing the
current variant from `PlayerComputedStateSummary` (sword by level, candle
blue/red, arrow wood/silver, boomerang normal/magic), full when obtained and
dimmed when not. Derived state only; nothing clickable or persisted.
