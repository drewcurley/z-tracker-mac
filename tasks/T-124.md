# T-124 — Overworld break-out window

## Description
The overworld map can now open in its own window (companion to the dungeon-band
window, T-123). Extracted the section — the `OverworldMapView` plus all its tile-edit
wiring and the derived `MapStateSummary` / recorder-destination marker — into a
reusable `OverworldSectionView(model:options:overlays:timer:reminders:)`.

Crucially, the map-overlay toggles (`OverworldOverlayState`) are now **hoisted to app
level** and shared, so the six Info-group toggle icons, the inline overworld, and the
overworld window all drive the same highlights (previously the overlays were view-local
`@State`, which a separate window couldn't share).

The inline section gained the shared pop-out header + placeholder.

## Acceptance criteria
- [x] The overworld opens in its own window; tile edits stay in sync with the model.
- [x] Overlay toggles (open caves / money / zones / coords / hide marks) affect both
      inline and windowed overworld (shared state).
- [x] Inline shows a placeholder while popped out; "Bring back" closes the window.
- [x] Build + full suite clean.
