# T-023 — Speech synthesizer warm-up

## Description
Playtest: the first *voice* reminder ("you have located one dungeon") fired
~20s after the triggering action, while the visual toast was prompt (~1s). Root
cause: `AVSpeechSynthesizer`'s first utterance is slow because macOS spins up
the `com.apple.speech` service on first use. Fix: `ReminderController.init`
speaks a silent (`volume 0`) warm-up utterance at launch, absorbing that
latency before any real reminder. Detection is already ~1s (the 1 Hz poll), so
with a warm synthesizer the voice now fires within ~1-2s.

## Acceptance criteria
