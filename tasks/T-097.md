# T-097 — Single main window

## Description
User noticed the app let you open multiple full trackers (as window tabs or
separate windows) that shared game state but drifted on view-local state. That was
an unintended default of SwiftUI's `WindowGroup`, not a feature and not broadcast
prep. Switched the main scene from `WindowGroup` to a single-instance
`Window("Z-Tracker", id:)` (macOS 13+) and removed the "New Window" command — so
there's exactly one tracker window, no tab bar, no multiple copies.

## Acceptance criteria
- [x] Main scene is a single-instance `Window`; ⌘N does not spawn a second tracker.
- [x] "New Window" removed from the File menu; no tab bar.
- [x] Settings + Progress-HUD windows unaffected; game state/persistence unchanged.
