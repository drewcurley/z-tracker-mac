# T-132.1 — Groundhog hotkey completeness

## Description
The `Global_GroundhogReset` hotkey called `resetForGroundhogOrRouters()` but not
`timer.startLap()`, so it didn't fully match the "Reset (keep maps)" button — the lap
timer never restarted, making the reset look like it did nothing. Now the hotkey
performs both (still skipping the button's confirm dialog, as intended).
