# T-150 — Combined dungeon commands

## Description
`dungeonActions` used to early-return one kind of mark, so "nondescript digdogger
open left" only applied one part. It now **accumulates**: all door pairs, an
entrance, and one each of room type / monster / floor drop — so a single utterance
can mark them together. `matchCategory` does a longest-phrase match within a single
catalog category so room/monster/drop are picked out independently. Order: doors,
entrance, room, monster, drop. (A 2nd monster stays a separate utterance, T-116.)

## Acceptance criteria
- [x] "nondescript digdogger open left" → door + room + monster; "nondescript heart drop" → room + drop.
- [x] Existing single/compound door, entrance, single room/monster/drop unchanged. 598 tests.
