# T-120 — Bigger triforce hitbox

## Description
The dungeon triforce toggle was only the bare 9pt `triangle.fill` — a tiny target
that was easy to miss. The whole area between the location header and the first item
box — the slot label, the triforce pip, and the "applies to" chips — is now a single
tap target that toggles the triforce (dungeons 1–8; Level 9 has no triforce).

Extracted the region into `triforceRegion` (fills the column width) and moved the tap
gesture + accessibility to the enclosing view. The "applies to" chips are display-only,
so including them in the hitbox is safe.

## Acceptance criteria
- [x] Clicking anywhere on the label / pip / chips toggles the triforce.
- [x] Level 9 stays non-interactive (no triforce).
- [x] Toggle logic + accessibility preserved.
- [x] Build + full suite clean.
