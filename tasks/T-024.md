# T-024 — Pre-rendered reminder audio

## Description
Replaces live `AVSpeechSynthesizer` TTS for spoken reminders with **pre-
rendered audio clips** (user idea). Playback via `AVAudioPlayer` is instant —
eliminating the ~20s first-utterance service spin-up (T-023's warm-up hack is
removed) and any speech-service race conditions — and the clips are rendered
with the **Zoe (Premium)** neural voice for a far more natural sound than the
classic `say` voices the live TTS used.

- `ReminderAnnouncement.audioKey` (TrackerCore) maps each announcement to a
  bounded clip name (~40 clips: consider-sword2/3, dungeon-complete 1–9,
  located 1–9, triforce 1–8, the 4 TAG levels, 6 per-blocker unblock phrases,
  ladder/key nudges). The one variable case (unblock's dungeon *list*) is
  rendered as a bounded per-blocker phrase.
- `ReminderAudioPlayer` (ZTrackerMac) plays the bundled `Resources/audio/*.m4a`;
  `ReminderController` prefers the clip and falls back to live TTS only if a
  clip is missing.
- Clips generated by `scripts/generate-reminder-audio.swift` (driven by
  `.sh`): a single `AVSpeechSynthesizer.write` process keeps the neural voice
  loaded (each separate `say` reloaded the model ~60s/clip), rendering CAF
  then transcoding to m4a (532KB total).

**Trade-off:** pre-rendering fixes the voice, so the in-app voice-*picker*
option no longer changes spoken reminders (re-render with a different voice
to change it — one command).
