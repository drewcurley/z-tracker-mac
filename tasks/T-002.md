# T-002 — Initial Xcode/SwiftPM project scaffold

## Description
The first real code task. Creates the buildable skeleton `docs/onboarding.md`,
`docs/testing.md`, and `.github/workflows/checks.yml` already assume exists:
an Xcode project (or SwiftPM package driving an app target) targeting macOS,
Apple Silicon, with an empty `TrackerModel` and a placeholder SwiftUI window,
plus a unit test target that actually runs. This task is also where several
docs' explicit "UNKNOWN — needs human confirmation" items must be resolved,
not deferred further:
- Minimum macOS deployment target (`stack.md`).
- Sprite-rendering approach: SwiftUI-only vs. AppKit/Core Graphics interop
  (`stack.md`).
- macOS-appropriate save-file storage location (`data-model.md` § 1).

## Acceptance criteria
- [ ] Xcode project builds and runs a minimal window on Apple Silicon.
- [ ] `swift build` / `swift test` (or `xcodebuild`) succeed in CI — remove the
      `continue-on-error: true` on the `build-and-test` job in
      `.github/workflows/checks.yml` in this same PR.
- [ ] At least one real XCTest exists and passes.
- [ ] `stack.md` and `data-model.md` updated to replace the resolved UNKNOWNs
      with the actual decisions (this is a `/docs/*` change — carries the
      unanimous-consensus assertion per `playbook/AGENTS.md` § 8).
- [ ] `onboarding.md` updated with the real, verified build/run/test commands.

## Out of scope
- Any actual tracker feature from `domain.md` — this is scaffold only.
