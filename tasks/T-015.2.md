# T-015.2 — Shop extra-data store + `OverworldTileMark` raw-index bridge

## Description
Closes the one genuinely-missing *model* piece the recompute needs. The
reference stores a per-tile "extra data" array
(`overworldMapExtraData`, `TrackerModel.fs:996`; accessors `:1000`/`:1009`)
used for: 3-item shops' **second item** (key `SHOP`, value 1–8 in `ToItem`
format), `THE_LETTER`'s have-potion-letter toggle, and `DARK_X`'s
un-revealed toggle. `z-tracker-mac`'s `OverworldGrid` has no such store and
no second-shop-item concept.

Also add the raw-int bridge the recompute's arithmetic needs onto the typed
`OverworldTileMark`: `rawIndex`/`fromRawIndex` reproducing
`MapSquareChoiceDomainHelper`'s numbering (`TrackerModel.fs:310-352`), plus
`isItem`/`toItem`/`shopKey` (`:336-339`). Recommend the raw-index approach so
the recompute (T-015.3) ports nearly verbatim as int logic rather than being
rewritten against enum cases.

## Acceptance criteria
- [x] Per-tile extra-data store on `OverworldGrid` with get/set, ported from
      `TrackerModel.fs:996-1011` (36 keys/tile = `DARK_X+1`; `clearAll`
      resets it too). — `OverworldGrid.swift`.
- [x] `OverworldTileMark.rawIndex`/`fromRawIndex` matching
      `MapSquareChoiceDomainHelper`'s 0…35 numbering exactly, pinned by test
      (all 36 marks + `.unmarked`→-1, full round-trip). —
      `OverworldTileMarkRawIndex.swift`.
- [x] `isItem`/`toItem`/`shopExtraDataKey`/`numShopItems`/`maxRawIndex`
      helpers (`:336-339`, `:340`), tested.
- [x] Three-item-shop second item representable and round-trips through the
      store (independent per tile and per key).

## Out of scope
- The recompute that consumes this — T-015.3. The picker — T-015.6.

## Risks / dependencies
