# T-127 — Scalable dungeon map

## Description
Reduces the vertical footprint on smaller monitors and lets the dungeon map +
blockers + notes sit side-by-side at a narrower window.

- **Zoom control** — a compact −/+ (with a % readout) in the map card's
  **bottom-trailing** corner scales the whole card (`scaledFootprint`, 60–140%),
  reclaiming vertical space; the Summary tab isn't scaled.
- **`ScaledFootprint` modifier** — scales a view *and shrinks its layout footprint*
  (plain `.scaleEffect` leaves the old bounds behind). Takes a known `naturalWidth`
  so the width stays deterministic inside the dungeon band's `ViewThatFits` — a
  measured width reads 0 during the fit probe and broke the reflow when zoomed.
- **Trimmed base size** — room cells 52×36×16 → 46×32×14 (~12% smaller; door
  segment lengths derived so they track), and the blockers/notes column min 390 →
  360, so all three columns fit side-by-side at a narrower window (was ~1194px).

Ultrawide overworld↔dungeon reflow was considered and **dropped** (user decision):
the scalable map + break-out windows cover the need without the added complexity.
