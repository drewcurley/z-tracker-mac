# T-151 — Coordinate + level → mark

## Description
Live QA: "E2 level two" switched to the level-2 tab and dropped the coordinate; the
user meant to **mark** dungeon 2 at E2. When a coordinate is present, "level N" now
routes like "set E2 level N" (mark the dungeon at that cell). Bare "level N" (no
coordinate) still switches tabs.

**Deferred (not fixed here):** the "two → to/too" homophone ("set level to" → no
number) — "to" appears in legitimate phrases ("go **to** level"), so mapping it to
2 causes false positives. Left as a recognition limitation.

## Acceptance criteria
- [x] "E2 level two" → mark dungeon 2 at E2; "A6 level six" → dungeon 6 at A6.
- [x] "level two" (no coordinate) still switches the tab. 599 tests.
