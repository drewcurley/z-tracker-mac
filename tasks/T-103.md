# T-103 — Two small fixes

## Description
1. Selecting **candle** on a take-any tile should auto-activate "has candle" in the
   items area (you took the blue candle). Implemented as a `didSet` on
   `takeAnyHearts` so it covers every write path (overworld tile + Items-group heart
   box); only turns it on (a candle from elsewhere isn't cleared).
2. The **Notes** placeholder now hides as soon as the field is **focused** (clicked
   into), not only once typing starts — via `@FocusState`.

## Acceptance criteria
- [x] Take-any candle → `hasBlueCandle` on (any slot/path); non-candle states don't.
- [x] Removing candle doesn't clear a candle held elsewhere.
- [x] Notes placeholder disappears on click/focus.
- [x] Unit-tested (candle link); build clean.
