# T-146 — Flexible entrance phrasing

## Description
Live QA showed dungeon-entrance marking only accepted the exact adjacent form
"entrance <direction>"; every natural variation failed (the user's most-repeated
voice failure). Fix `VoiceGrammar.dungeonActions`: an entrance **trigger phrase
anywhere** + a **direction anywhere** (either order, tolerant of fillers like
"from"). Catalog Entrance phrases gained "entered from" / "came from" /
"entering". Bare "enter" is deliberately NOT a trigger — that would steal
"enter level N" (tab switch), which a test guards.

## Acceptance criteria
- [x] "entrance from north", "enter from north", "north entrance", "entrance from left" all → entrance.
- [x] "enter level 5" still switches the tab. 590 tests.
