# T-054 — Overworld used/unused toggle

## Description
Claimable-once overworld tiles — secrets, take-any, armos, the letter, hint shop
— can now be toggled **used** (collected) vs unused with a **left-click**,
dimming the tile on the map and updating the Spot Summary counts.

Grounded in the reference's `toggleables` / `ToggleOverworldTileIfItIsToggleable`
(`OverworldMapTileCustomization.fs`), which stores the used flag in
`overworldMapExtraData` at the mark's own index. This port reuses the existing
`extraData` store the same way. Per the user, the set drops the reference's
wood-sword cave (tracked via its item box) and adds armos + the letter.

## Acceptance criteria
- [x] Left-click a claimable tile toggles used ⇄ unused (`OverworldGrid.isUsed`
      / `toggleUsed`); a non-claimable mark is unaffected.
- [x] A used tile is dimmed on the map (dark overlay + darkened icon; no extra
      glyph — the checkmark was redundant).
- [x] Spot Summary: secrets remaining = total − **used**; armos/the letter show
      found (placed) vs collected (used) via a 3-state opacity.
- [x] `OverworldTileMark.isUsedToggleable`, grid used-state, and the summary
      impact are unit-tested; on-device verified.
