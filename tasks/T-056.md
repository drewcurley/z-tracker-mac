# T-056 — Claimable tiles default to used

## Description
When you mark a claimable overworld tile (secret / take-any / armos / letter /
hint shop) from the picker, it now defaults to **used** — you typically mark one
right after collecting it. A left-click then flips it back to unused. This is
the default player behavior.

## Acceptance criteria
- [x] Picking a claimable mark sets it used immediately (tile dimmed, no click).
- [x] Left-click flips it used ⇄ unused as before.
- [x] Non-claimable marks are unaffected.
- [x] `OverworldGrid.setUsed` unit-tested; on-device verified.
