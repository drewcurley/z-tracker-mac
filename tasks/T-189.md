# T-189 — Open-caves overlay as a 3-way toggle

## Ask
The open-caves overlay toggle/hover in the Info area becomes a 3-way click cycle: (1)
open caves only [current], (2) a different border color reflecting ALL currently-gettable
locations, (3) off. Hover still previews.

## Implementation
- `OverworldOverlayState`: `openCavesMode` (off / openCaves / allGettable) replaces the
  binary lock for open caves; `toggleLock(.openCaves)` cycles it. `effectiveOpenCavesMode`
  folds in hover (hover-while-off previews open-caves-only). Other overlays stay binary.
- `OverworldMapView.overlayHighlight` returns the border `Color?`: green for money +
  open-caves; **orange** for the all-gettable mode (`mapState.owGettableLocations`).
- Overlay toggle icon reflects the mode: grey (off) → green (open caves) → orange (all
  gettable).

## Tests
`OverworldOverlaysTests`: the 3-way cycle + hover-preview + effective-mode. 722 tests pass.

## Note
"All gettable" border color is orange (distinct from green open-caves + cyan cursor);
trivially changeable.
