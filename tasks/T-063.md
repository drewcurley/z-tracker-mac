# T-063 — Sword-cave item icons + Take-any menu grouping

## Description
Two overworld tile-selector polish items from the "finish out the upper area"
request:

1. **Sword caves render with the Items-area sword sprites.** The reference's
   `ow_icons5x9` sword markers are tiny and stamp the level number (1/2/3) into
   the sprite. We replace them with the high-fidelity `icons7x7` swords used in
   the Items group — wood / white / magical for cave levels 1 / 2 / 3 — drawn on
   a dark plate and sized like the dungeon-number badge. The stamped number is
   dropped: the sword itself names the level.

2. **"Take any" moved up with the other submenus.** It became a submenu in
   T-057 (Unclaimed / Potion / Blue candle / Heart) but stayed in its old
   position among the one-shot marks. It now sits with Dungeon / Any road /
   Sword cave / Shop / Secret, above the divider.

## Acceptance criteria
- [x] Sword-cave tiles show the Items wood/white/magical sword sprite, no number.
- [x] The Spot Summary's sword-cave icon uses the same sprite.
- [x] "Take any" appears in the submenu cluster, not among the flat buttons.
- [x] Per-type exhaustion still disables placed sword levels.
- [x] Tests updated: swords map to `.swordCaveItem`, interior sprites now 3...13.
