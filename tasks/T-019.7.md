# T-019.7 — Dungeon room details (D2b)

## Description
Completes D2 over D2a (T-019.6): the monster + floor-drop detail markings and the
circle/brightness gesture, matching the reference (`DungeonUI.fs:1348-1471`,
`DungeonRoomState.fs:495-540`).

- **Sprites**: `DungeonMonsterAtlas` (from `zelda_bosses16x16.png`) and
  `DungeonFloorDropAtlas` (from `zelda_items16x16.png`), both black-keyed. The
  `MonsterDetail → tile` map mirrors the reference tuple order (index 11 is
  `old_man`, not a MonsterDetail — non-sequential); the `FloorDropDetail → tile`
  map mirrors `FloorDropDetail.Bmp()`.
- **Overlays** on the room cell: monster top-left (dimmed on a completed room
  unless it's a persistent hazard — bubbles/traps/others, per `:534-537`),
  floor drop bottom-right (dimmed when marked "already collected"), and the
  "circled" ring (yellow dashed ellipse overhanging the cell).
- **Gestures** (via `RoomMouseCatcher`): Shift+left = monster picker, Shift+right
  = floor-drop picker, middle = circle (no drop) / floor-drop brightness. Pickers
  mirror the reference `All()` grids (monster 8×4, floor drop 3×3), each with an
  `unmarked` (clear) cell.
- **Model**: `MonsterDetail.allInPickerOrder` / `darkensWhenCompleted`,
  `FloorDropDetail.allInPickerOrder`, `DungeonRoomMap.middleClick`.
- VoiceOver: named actions for set-monster / set-floor-drop / toggle-circle; the
  cell value announces monster, drop (+ collected), and circled state.

## Acceptance criteria
- [x] Monster + floor-drop sheets load; every marked detail crops to a sprite.
- [x] Overlays render in the reference positions with completion/collected
      dimming; circle renders as a dashed ring.
- [x] Shift+left / Shift+right open the correct pickers; picking sets (or clears
      via the `unmarked` cell); middle toggles circle-or-brightness per the drop.
- [x] Picker grids use the exact reference `All()` order.
- [x] VoiceOver announces details and offers the detail actions.
- [x] Unit tests for orders / darken rule / middle-click / atlas loading; build
      clean; on-device visually verified (sprites, positions, dimming, circle,
      old-man count) via a temporary seed (removed before commit).
