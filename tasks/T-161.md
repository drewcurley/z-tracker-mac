# T-161 — Real game sprites for icons + an app icon

## Description
The tracker's icons were the reference app's very low-res atlases (`icons7x7` at 7×7,
`ow_icons5x9` at 5×9, `icons3x7` at 3×7) — cruder even than the actual game sprites.
Migrated the item tracker, dungeon item boxes, overworld marks, shop items, and blocker
icons onto the real Zelda 1 game sprites (project-owner-supplied GIFs in `Resources/`;
see NOTICE.md for provenance). Also added the app's first dock icon.

### How
- `Package.swift`: switched the target's resources to `.process("Resources")` so every
  supplied sprite GIF (172) bundles at the root without per-file `.copy` entries.
- New `GameSprites.swift`: `GameSprite` loads a named GIF's first frame as a cached
  CGImage; `ItemGlyph` renders the mapped game sprite (nearest-neighbor, aspect-preserving
  so tall sprites aren't stretched) and falls back to the original atlas glyph when no
  sprite is mapped. Item/overworld/shop mappings live here.
- Wired every icon render site through `ItemGlyph` / the sprite lookup: item grid +
  dungeon boxes (`ItemProgressGridView`, `DungeonTrackerView`), blockers (`BlockersView`,
  all four surfaces), the recorder destination counter (`RecorderInfoWidget`), the
  take-any potion overlay, and the overworld marks + shop items (`OverworldMapView`).
- Overworld composites for tracker-only concepts with no single game sprite: money game
  → a static orange rupee (frame 0 of the blinking Rupy), secrets → 1/2/3 clustered
  five-rupee sprites, unknown secret → Goriya, door repair → the flame sprite.
- App icon: `Bundle/AppIcon.png` (full-bleed squircle, transparent corners) → `build-app.sh`
  generates `AppIcon.icns` (sips + iconutil) into the bundle; `CFBundleIconFile` added to
  the Info.plist template.
- NOTICE.md records the game-sprite (© Nintendo) and icon provenance separately from the
  MIT reference atlases.
