# T-016 — Hide Dungeon Numbers (HDN) mode (umbrella)

## Status: split into T-016.1 … T-016.3

"Hide Dungeon Numbers" is a whole alternate randomizer mode where dungeon
identities are shuffled/hidden and the player labels discovered dungeons by
color/letter — a large orthogonal complexity multiplier that roughly doubles
most dungeon code paths (per the `T-012` scoping read). Like T-015, it splits
into a **model core** (portable now) and **UI/rendering** pieces that need a
dungeon-tracker room-grid UI which does not exist yet.

| Sub-task | Title | F# ported | State |
|----------|-------|-----------|-------|
| [T-016.1](./T-016.1.md) | HDN model core — box counts, completion, triforce indexing, label/color state | `TrackerModel.fs:682-836` (HDN branches) | completed |
| [T-016.2](./T-016.2.md) | Basement-stair metadata — `StairKind`/`BoxOwner`/`CurrentlyHasBasementStair` | `TrackerModel.fs:587-632` | completed |
| [T-016.3](./T-016.3.md) | HDN labeling UI + overworld lettered-dungeon rendering | `Color`/`LabelChar` UI; `iconSource` HDN variant | proposed |

## Original acceptance criteria (now distributed)
- [x] HDN `Dungeon.IsComplete`, box counts, `GetTriforceHaves` indexing —
      **T-016.1**.
- [ ] `Color`/`LabelChar` labeling UI — **T-016.3** (needs the dungeon-tracker
      UI as a host).
- [ ] `CurrentlyHasBasementStair` + `StairKind`/`BoxOwner` — **T-016.2**
      (deferred further: the dungeon-room-grid UI it feeds hasn't started).

## Risks / dependencies
