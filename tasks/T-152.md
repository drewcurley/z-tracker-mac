# T-152 — Two-digit column fold

## Description
Two-digit overworld columns (10–16) frequently mis-recognise: "G12" → "G1 two" /
"G1 2", landing the mark on G1 with the trailing digit orphaned. `coordinate` now
folds: if the first digit after the letter is 1 and the next token is a small number
(0–6), it combines to a 10–16 column. Only folds on a number token, so "G2 potion"
stays G2.

## Acceptance criteria
- [x] "G1 two"/"G1 2" → G12; "E1 six" → E16; "G1 two door repair" → mark at G12.
- [x] "G2 potion" unchanged. 600 tests.
