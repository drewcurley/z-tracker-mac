# T-114 — Timeline hover: split + location

## Description
Hovering a timeline icon now shows the split time first, then the item, then
where it was found when that's known — e.g. `31:03  Silver Arrow — LEVEL-3 Box 1`
(issue #8). Box-sourced items get a location; overworld/starting/take-any items
just show the name.

`TimelineEvents.locations(dungeonTracker:boardInsteadOfLevel:hideDungeonNumbers:)`
maps each collected dungeon/coast box item to a label ("LEVEL-1 Box 1", "Coast"),
using the shared `DungeonLabeling.columnName` so the naming matches T-112. The map
is stored on `TimelineModel.acquiredLocation` (pruned to currently-acquired events)
and read by the hover; the pop-out Timeline window gets it for free since it reads
the same model.

## Acceptance criteria
- [x] Hover leads with the split time, then the item name.
- [x] Box-sourced items show their LEVEL/BOARD box label (letters under HDN); coast
      items show "Coast".
- [x] Location is dropped when the event is un-acquired.
- [x] Unit-tested; build + full suite clean.
