# T-101 — Timer duplicate window

## Description
The user's companion idea to the break-out pattern: duplicate the run timer into a
separate window (e.g. a stream overlay), with the inline timer still shown.

- Hoisted `TrackerTimer` from `MainTrackerPlaceholderView` to the app level so a
  `Window` scene can bind to the same instance; `resetApp` recreates it.
- `Window("Timer", id: TimerWindowID)` renders `TimerWindowView` — a large
  `H:MM:SS.mmm` readout (green running / orange paused, yellow lap) mirroring the
  same timer.
- A pop-out button beside the inline timer opens it (`openWindow`).

## Acceptance criteria
- [x] Timer shows in its own window, mirroring the inline timer live.
- [x] Inline timer stays (it's a duplicate, not a break-out).
- [x] Timer hoisted to app level; resets with the app.
- [x] Build clean; launches without crash.
