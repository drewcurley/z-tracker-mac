# T-142 — Voice progression toggles

## Description
Lets the player flag item-grid "acquired" boxes by voice, per the user's two rules:

1. **Scope** — overworld-acquired items (wood/magical sword, blue candle, wood arrow,
   blue ring, boomstick book, meat) fire only while the cursor is in the **overworld**
   region. **Bombs** are global (a near-gimme, droppable in dungeons); **Ganon/Zelda**
   end-states are global too.
2. **Action words disambiguate** — a bare "meat" still marks the meat *shop*; you must
   say an action word ("**took** / got / bought / grabbed / have / killed / rescued…")
   to flag the *item*. So "meat" = shop, "took meat" = have the bait.

- **`VoiceCatalog`** — new `.progression` category (Prog_* actions), item words only;
  the action word is matched by the grammar (a grammar constant, like NATO letters).
- **`VoiceConfig.Scope.progression`** — matched before region/structural.
- **`VoiceGrammar`** — `progressionToggle(words:config:)` requires an action word then a
  `.progression` phrase match; `globalProgressionIDs` / `isGlobalProgression`;
  `VoiceCommand.toggleProgression(id:)`. Action words seeded into `contextualStrings`.
- **`ProgressionVoiceApply`** — pure helper: id → `ItemToggle`, region-scope gate,
  set-the-flag-on (acquisition is directional, so a double-recognition can't un-mark).

## Acceptance criteria
- [x] "took wood sword" / "got magical sword" / "bought bombs" / "killed ganon" toggle.
- [x] Bare "wood sword" / "meat" / "bomb shop" stay cave/shop marks.
- [x] "take any potion" isn't swallowed (action word present, no progression match).
- [x] Overworld items gated to the overworld region; bombs/ganon/zelda global. 579 tests.

## Out of scope (→ T-143)
The three **item boxes** (coast / armos / white-sword) hold a *chosen item* (bow / raft /
ladder / recorder / …) — they need a full item vocabulary + a "which box + which item"
grammar ("coast ladder"). Deferred. Also: a voice "un-mark / clear" verb for progression;
remove `/tmp` diagnostics before final.
