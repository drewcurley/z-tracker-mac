# T-122 — Reminder log window + timestamps + icons

## Description
The reminder log was a small popover. It's now a **break-out window** (opened by the
"Log" button), each entry carrying a **timestamp** (run-time split) and a row of
**icons** describing what the reminder is about — e.g. the ladder → the coast item, or
the magical sword → Level 3.

- `ReminderController` is hoisted to app level so the Log window and the poll loop
  share one `ReminderLog`; a new `Window("Reminder Log", id: LogWindowID)`; the Log
  button calls `openWindow` (no more popover); Reset App clears the log.
- `ReminderLog.Entry` gains `elapsedSeconds` + `icons: [ReminderIcon]`.
- `ReminderIcon` (new, TrackerCore) + `ReminderIcons.icons(for:swordLevel:ringLevel:coastItemId:)`
  — a pure resolver, computed at fire-time so tiered/contextual icons are accurate
  (the sword/ring you just reached, the coast item behind the ladder). Mirrors the
  reference `SendReminder(..., icons)` lists.
- `ReminderLogView` renders timestamp + `ReminderIconView` row + text; the icon view
  maps each case to the item atlas / overworld marks / SF Symbols.

## Acceptance criteria
- [x] Log opens in its own window (not a popover); can stay open beside the tracker.
- [x] Each entry shows a timestamp and descriptive icons.
- [x] Coast-item reminder shows ladder → coast item; combat unblock shows the actual
      sword/ring → the dungeon(s).
- [x] Unit-tested (resolver + log storage); build + full suite clean.
