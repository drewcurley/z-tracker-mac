# T-219 — Drop Rooms window + Hint Decoder polish

Two polish items shipping together as **v1.2.3**.

## 1. Hint Decoder "Other hints" — clickable title
The "Other hints" `DisclosureGroup` only expanded via its chevron. The **title text** now toggles it
too (tap gesture on the label).

## 2. Drop Rooms breakout window
A new breakout that shows the vanilla room **layouts** that never contain a floor drop in the dungeon
currently selected on the Dungeon Map tab — so a runner knows not to check them.

### Behavior
- New **"Drop Rooms…"** button in the Info area, **between Hint Decoder and Settings**.
- Shows the universal **NEVER** rooms (Zelda, 3 Rows, Spike Trap, Single Block, Circle Wall) plus the
  **level-specific** set for the current dungeon, with the real room thumbnails + labels, a title, a
  "Level N" badge, and a one-line explanation.
- Per-dungeon sets (from the community drop-room chart; applies to **both quests**):
  L1 = Spiral Stair, Gleeok, Maze, T, Diamond Stair, Single 6 · L2/3/6/7/8/9 = Five Pair, Maze,
  Pointless Moat · L4 = Grid, Diamond Stair, Five Pair, Single 6, Spiral Stair · L5 = Grid, Diamond
  Stair, Gleeok, Maze, Spiral Stair, Five Pair, Single 6.
- Updates live as the selected dungeon changes. Summary tab / an unidentified HDN dungeon show a
  prompt instead of wrong data (dungeon number resolved via `labelChar.wholeNumberValue`, mirroring
  `expectedOldMen`).

### Implementation
- `DropRooms` (TrackerCore): the 14 `DropRoom` layouts + `never` / `levelSpecific(dungeon:)` /
  `neverDrop(dungeon:)`.
- The 14 thumbnails were sliced from the user-provided reference PNG at detected uniform geometry
  (137×79, 147px pitch) and bundled as `droproom-*.png`.
- `DropRoomsView` + `DropRoomImage` loader (ZTrackerMac); `Window(id: DropRoomsWindowID)`; button in
  `MapInfoView`.

## Tests
`DropRoomsTests` (grouping per dungeon) + `DropRoomImageTests` (all 14 thumbnails load from the
bundle). **771 tests pass.**
