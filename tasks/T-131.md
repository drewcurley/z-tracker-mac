# T-131 — Hotkey editor UI

## Description
The in-app editor (opened from Settings' "Edit hotkeys…"), rendering every selector
grouped by context (Global first). Click a binding → press the key(s) → captured; a
conflicting key prompts **"Reassign key?"** (it moves the key, removing the old
binding). Per-row clear, Clear all, live filter, and Import/Export the Windows
`HotKeys.txt` via file pickers. `HotkeyConfig` hoisted to app level + a dedicated
editor window. Command (⌘) is intentionally not a bindable modifier.

## Acceptance criteria
- [x] Editor lists all contexts (Global first); filter works.
- [x] Key capture via a local event monitor; Escape cancels.
- [x] Conflict → "Reassign key?" naming what it removes; confirming moves the key.
- [x] Import/Export round-trips the Windows HotKeys.txt.
- [x] Build + full suite clean; user-QA'd on-screen (capture, conflict, reassign, clear).
