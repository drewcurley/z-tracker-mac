# T-039 — Location hints (hint zones)

## Description
The clickable location-hint areas above each dungeon and the white/magical
sword boxes (user-identified). Ported from the reference's `HintZone` /
`GetLevelHint`/`SetLevelHint` (`TrackerModel.fs:1299-1409`).

- **Model (TrackerCore):** `HintZone` (11 zones — Unknown + 10 regions; each
  with `twoChars`, `displayName`, and a `zoneChar` matching `owMapZone`),
  `HintTarget` (11 indices: dungeons 1–9 → 0–8, white sword → 9, magical
  sword → 10), and `TrackerModel.levelHints: [HintZone]`. Hints are map
  *knowledge*, so the groundhog reset keeps them.
- **UI:** `HintLabel` (the two-char label, yellow when set / gray Unknown,
  click → picker) above each dungeon card and beside the white/magical sword
  icons in the item-grid header; `HintZonePicker` (target name + current hint +
  an 11-zone grid).

## Acceptance criteria
- [x] `HintZone` (11) + `HintTarget` + `levelHints`; hints survive a groundhog
      reset; tested.
- [x] Hint label above each dungeon (1–9) + white/magical sword; picker sets it.
- [x] On-device verified: picker shows all 11 zones; selecting DM sets Dungeon
      2's label yellow "DM".

## Out of scope
- Highlighting the hinted region on the map (ties into the Zones overlay's
  `zoneChar`); the white/magical-sword hint-highlight on the sword boxes
  (`makeHintHighlight`); hotkeys.
