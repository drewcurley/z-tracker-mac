# T-230 — Tracker zoom: 110% / 120% zoom-in

Extends the universal "Tracker zoom" ([T-229](./T-229.md)) with two **zoom-in** levels for larger
displays, so the picker now spans **120 / 110 / 100 / 90 / 80 / 70 / 60%**. Ships as **v1.2.8**.

## Behavior
- Two new picker options, **110%** and **120%**, on the welcome + in-app "Tracker zoom" setting.
- Zoom-in composes with the responsive layout the same browser-style way as zoom-out: at 120% the
  content lays out at the *smaller* logical width (viewport ÷ 1.2) then scales up, so the panels
  collapse a touch sooner and the window scrolls vertically — as expected for a magnified view.

## Acceptance criteria
- [x] Given zoom = 120%, the whole tracker renders larger and the content still fills the window width.
- [x] The existing 100–60% levels and the mirror-window exclusion are unchanged.

## Implementation
- `SettingsPanelView` — add `Text("120%").tag(1.2)` and `Text("110%").tag(1.1)` above 100% in the
  "Tracker zoom" `Picker`; help text updated to mention scaling up.
- No engine change: `ScaledFootprint` already handles `scale > 1` (its `.fixedSize` guard prevents
  the grow-loop), and `effectiveWidth = contentWidth / zoom` already generalizes to zoom > 1.

## Out of scope
- Zoom beyond 120% or a continuous slider — not requested.
