# T-057 — Take-any item from the overworld picker

## Description
QoL: the overworld tile picker's "Take any" is now a submenu — **Unclaimed /
Potion / Blue candle / Heart**. Picking a claimed item marks the tile take-any
(used) and fills the **next unclaimed** take-any slot in the Items group with
that state; "Unclaimed" marks the tile take-any but leaves it unclaimed and
touches no slot.

## Acceptance criteria
- [x] "Take any" is a submenu with the four states.
- [x] Potion/candle/heart → tile marked used + next take-any slot set to that
      state; "Unclaimed" → tile take-any, not used, no slot change.
- [x] Fills slots in order; no-op once all four are taken.
- [x] `PlayerProgressAndTakeAnyHearts.recordTakeAny` unit-tested; on-device
      verified.
