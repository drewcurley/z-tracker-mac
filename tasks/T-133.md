# T-133 — Dungeon-tab hotkeys + focus state

## Description
Wires the Global `DungeonTab1–9` / `DungeonTabS` hotkeys to switch the dungeon map's
visible tab. To make the tab reachable by the app-level dispatcher, its state moved
from `DungeonMapView`'s private `@State` into a new app-level `TrackerFocusState`
(threaded app → ContentView → main view / dungeon-band window → `DungeonMapView`).
Bonus: the selected tab now **survives the dungeon-band reflow** (previously reset,
same class of bug as the zoom did before T-129). `TrackerFocusState` will also hold
the keyboard cursor in the next phase.

## Acceptance criteria
- [x] `DungeonTab1–9`/`S` switch the dungeon map tab from anywhere in the main window.
- [x] Clicking tabs still works; the tab persists across the reflow.
- [x] Build + full suite clean; user-QA'd (bound `3` → jumps to tab 3).
