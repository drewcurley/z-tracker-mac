# T-207 — Animate tile changes, shop hiding, settings persistence, hint hover

The "animate tile changes" build from the T-206 audit, plus a cluster of overworld/settings
refinements the user surfaced during QA of the same batch.

## Animate tile changes
- Mark glyphs **pop** in with a slight overshoot when they change (spring, low damping),
  gated by the `animateTileChanges` option; instant swap when off.
- The "still-gettable / open-caves / money" highlights **pulse** slowly when the option is on.
  Driven by a `TimelineView(.periodic)` clock in `PulsingHighlight`, **not** a
  `withAnimation(.repeatForever)` transaction — the latter leaked a global animation into every
  tile's `.animation(value:)` and made the darkening overlays flicker regardless of the flag.

## Overworld shop hiding (`hideNoLongerRelevantShopItems`)
- **Per-item:** a combo shop drops only the items you already own and keeps showing the
  still-relevant one (bomb/ring with the ring owned → shows just the bomb).
- **Whole-tile:** when *every* item a shop sells is owned, the tile takes the full **"don't
  care" darkening** (a shop is never `used`, so it previously only dimmed its icon) and reveals
  on hover.
- **Consumables** (bomb, meat, magic shield) are never hidden by relevance; meat still hides
  only via the explicit `alwaysHideMeatShops`.
- **Book** shop hides on `haveBook` (`(haveBookOrShield && isCurrentlyBook) || hasBoomBook`) —
  so marking the boomstick book as gotten now dims a book shop.

## Settings persistence
- Every persisted bool now writes immediately on change (`didSet`), not only at quest-start
  `saveSettings()` — a preference toggled mid-session (e.g. "Listen for speech") survives a quit.
- **Auto-save and quit** (`autoSaveOnQuit`): skip the save prompt on close — autosave the run
  and quit. Also unblocks the dev build/relaunch scripts, which the save dialog was hanging.

## Hint-zone hover label
- The dungeon location-hint popover header updates to the hovered zone's name as the pointer
  moves across the grid (matching the overworld tile chooser), instead of waiting on the tooltip.

## Acceptance criteria
- [x] Marks pop on change when `animateTileChanges` is on; instant when off; overlays don't
      flicker when off.
- [x] Combo shop with one item owned shows only the still-relevant item.
- [x] Shop with all items owned takes the full darkening + reveals on hover.
- [x] Bomb/meat/shield shops never hide by relevance; book shop hides on the boomstick book.
- [x] A setting toggled mid-session persists across a quit without starting a run.
- [x] `autoSaveOnQuit` skips the prompt and autosaves.
