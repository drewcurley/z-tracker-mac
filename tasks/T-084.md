# T-084 — Dungeon-tab "needs" markers

## Description
Mark on each dungeon tab what that dungeon still needs (the user's request; the
reference `updateHeaderCanvases`, `DungeonUI.fs:849-867`):

- **Bait-meat icon** (leading edge) when the dungeon has a Hungry-Goriya meat
  block, with a lime **checkmark** once it's been fed (room marked complete).
- **DodgerBlue dot** (top-trailing) when it has a Bomb-Upgrade room not yet bought.
- **Red dot** (bottom-trailing) when it has an unread NPC hint — gated on the
  "book for helpful hints" option, exactly as the reference.

Markers only appear on dungeon tabs 1–9 (not Summary) and only when applicable,
so tabs stay clean until a special room is marked.

## Acceptance criteria
- [x] Bait icon for Hungry-Goriya; lime check once fed.
- [x] Blue dot for an unbought Bomb-Upgrade; clears when complete.
- [x] Red dot for an unread NPC hint, only with the book option on; clears when read.
- [x] Summary tab unaffected; VoiceOver value reflects the markers.
- [x] Model flags unit-tested; markers render-verified on-device (temp seed, removed).
