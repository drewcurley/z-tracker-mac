# T-025.3 — Item-box located / superseded highlighting

## Description
The border-state highlighting on the item-grid toggle boxes
(`veryBasicBoxImpl` redraw, `OverworldItemGridUI.fs:289-311`), deferred from
T-025.1. Border precedence, ported exactly:

1. **held** (the flag is set) → green (existing).
2. else **superseded** → gray + an X (the item is moot; you have a better one).
3. else **located** → yellow (the item's shop/cave has been found on the map
   but you haven't collected it).
4. else → dim (existing default).

Per-box located / superseded logic (`OverworldItemGridUI.fs:328-385`):

| Box | located | superseded |
|-----|---------|------------|
| wood sword | swordLevel==0 && `woodSwordCaveFound` | swordLevel≥1 |
| wood arrow | arrowLevel==0 && `foundArrowShop` | arrowLevel≥2 |
| blue candle | candleLevel==0 && `foundCandleShop` | candleLevel≥2 |
| blue ring | ringLevel==0 && `foundBlueRingShop` | ringLevel≥2 |
| magical sword | `magsCaveFound` | never |
| boomstick book | `foundBookShop` | never |
| bomb | `foundBombShop` | never |
| ganon / zelda | never | never |

Levels come from `PlayerComputedStateSummary`; the found-flags from
`MapStateSummary` (both already modeled). Pure render.

## Acceptance criteria
