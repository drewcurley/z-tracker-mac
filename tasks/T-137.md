# T-137 — Voice control (structured grammar, v1)

## Description
Hands-free tracking via on-device `SFSpeechRecognizer`, toggled from a mic button in
the FLAGS group. Each spoken phrase is parsed by a pure `VoiceGrammar` and executed
through the same region-apply code the hotkey cursor uses.

- **Grammar** (`TrackerCore/Voice/VoiceGrammar.swift`, pure + tested): coordinates use
  the app's own labels — **letter = row (A–H), number = column** (overworld 1–16). Parses
  overworld marks ("D5 bomb shop"), take-any with claimed item ("E6 take any potion" →
  updates the linked heart slot), dungeon-tab switch ("enter level 5"), and cursor
  directions ("north"). Substring matching + homophones + `contextualStrings` bias the
  recognizer toward the tracker's jargon.
- **`VoiceController`** (app): audio engine + tap set up **once**; per-utterance the
  recognition request is swapped via a lock-guarded `RequestBox` (the audio thread never
  races `endAudio`); a **generation guard** ignores stale callbacks (kills the 301
  "canceled" restart loop); acts ~0.7 s after speech stops; `Global_ToggleVoice` hotkey
  (unbound by default).
- **Signing**: `build-app.sh` now signs with a stable self-signed identity so TCC
  remembers the mic/speech grant across rebuilds.

## Acceptance criteria
- [x] Mic toggle in FLAGS; on-device recognition; permission flow works from the `.app`.
- [x] Overworld marks, take-any (+ linked heart), dungeon-tab, and directions execute.
- [x] Grammar is pure + unit-tested (coords, marks, take-any, two-digit columns).
- [x] Stable across many commands (no crash/lockup); user-QA'd live.

## Known gaps (→ T-138)
- Coordinates are overworld-only (not region-aware); coord-only doesn't move the cursor;
  action-only doesn't apply at the cursor. Limited vocabulary (no set-start / items /
  hint zones / dungeon-room / blocker words). NATO letters needed to disambiguate
  "E"/"east". Dedup (`maxUses`) is still UI-only, so voice can place duplicate dungeons.
- File diagnostics (`/tmp/ztracker-voice.log`) are dev scaffolding, to remove before final.
