# T-035.4 — Run timer (main + lap)

## Description
The top-section run timer (the reference's `H:MM:SS` + Pause/Reset), with two
user-requested additions:

1. **Milliseconds** — the main timer shows `H:MM:SS.mmm` for precise timing.
2. **Groundhog lap** — clicking the "Reset (keep maps)" groundhog reset starts a
   smaller **yellow lap timer** beneath the main one that runs independently for
   that reset instance; the main timer keeps running.

- `TrackerTimer` (`@Observable`): a main stopwatch (`accumulated` + a running
  `segmentStart`) and an independent lap (`lapOrigin`). `mainElapsed(asOf:)` /
  `lapElapsed(asOf:)` are pure functions of an injected `now`, so the display is
  driven by a `TimelineView(.periodic by: 0.03)` while the logic stays testable.
  Pause/resume freezes both; reset zeroes both and clears the lap.
- `TimerFormatting.hmsMillis` — `H:MM:SS.mmm`, clamping negatives.
- The groundhog reset button (`ItemProgressGridView`) calls `timer.startLap()`
  alongside `model.resetForGroundhogOrRouters()`.

## Acceptance criteria
- [x] Main timer `H:MM:SS.mmm`, green running / orange paused; Pause + Reset.
- [x] A groundhog reset starts a yellow lap timer that runs independently while
      the main keeps going; the lap only shows once a reset has happened.
- [x] Tests: formatting; main counts; lap independence; pause freezes both;
      reset clears.
- [x] On-device verified (main 17.680 / lap 12.088 after a reset).

## Out of scope
