# T-193 — HUD letter slot + boomstick-nudge fixes

Two user-reported bugs.

## Bug 1 — HUD letter slot shown backwards
The faux in-game HUD's letter icon appeared when the overworld letter tile was in its
bright state and disappeared when dim — reversed. The letter's dim is *inverted* (T-118): a
**held** letter renders dark (`isUsed == false`) and brightens once delivered. But
`ProgressHUDView.haveLetter` keyed off `isUsed`, so the HUD showed the letter exactly when
you *didn't* hold it.

**Fix:** `haveLetter` now reports **holding** the letter — placed and not used
(`!isUsed`) — matching the tile's dim and the map-derived `havePotionLetter`. Extracted a
pure `holdsPotionLetter(_:)` helper so it's unit-tested.

## Bug 2 — boomstick "buy the book" nudge ignored the Boomstick flag
Toggling the **Boomstick** flag (slot 0 = shield ⇒ book relocated to a shop,
`!isCurrentlyBook`) appeared to start the "consider buying the boomstick book" reminder, but
turning the flag off never cleared it: the reminder only checked `haveWand && !hasBoomBook &&
bookShopMarked`, never the flag, so it kept firing every 5 min.

**Fix:** gate `considerBoomstickBook` on `!isCurrentlyBook` (a boomstick seed). Turning the
flag off now clears the nudge; buying the book (`hasBoomBook`) still stops it.

## Tests
`ProgressHUDTests`: letter held ⇔ placed & not used. `ReminderEngineTests`: boomstick nudge
fires only in a boomstick seed with wand + book shop + no book. 725 tests pass; QA'd on device.
