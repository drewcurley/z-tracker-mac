# T-025.5 — Item-grid chrome (Book/Shield + Max Hearts)

## Description
The rest of the item-grid chrome (`OverworldItemGridUI.fs:395-562`), building
the controls that have a real, wired effect and deferring the two whose
consumers don't exist yet:

1. **Book / Shield toggle** (`isCurrentlyBook`, `CustomComboBoxes.fs:46`) — in
   boomstick seeds item slot 0 is the Magic Shield instead of the Book. New
   `TrackerModel.isCurrentlyBook` (default book); item-icon display for
   `ITEMS.bookOrShield` renders book vs shield. Same swap pattern as swordless.
2. **Max Hearts** readout + `+/-` (`OverworldItemGridUI.fs:542-556`) — shows the
   derived `playerHearts` and steps `maxHeartsDifferential`.

Refactor: the per-box swap flag was generalized from a bare `wsmsReplacedByBU`
Bool to an `ItemIconOptions` value (`wsmsReplacedByBU` + `isCurrentlyBook`),
threaded through `BoxView`/`BoxItemPicker`/the dungeon + coast boxes via
`model.iconOptions`.

## Deferred (dead without a consumer — not built)
- **Book-is-Atlas** — gates the dungeon-map-reveal feature, which isn't built,
  so the toggle would do nothing. Add with that feature.
- **Highlight-open-caves** — a hover-highlight of "nothingable" caves with
  nuanced state logic; needs the locator-highlight system. Its own task.

## Acceptance criteria

- [x] Book/Shield + Max Hearts controls in the item-grid chrome, wired.
- [x] Tests: book/shield swap (default book), swordless+book independence,
