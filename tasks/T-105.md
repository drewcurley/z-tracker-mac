# T-105 — Secret-count reminders

## Description
User: the app lets you mark too many of each money-secret size. Add a reminder
when there is **one of that size left**, and when there are **none left**, so you
don't over-mark. (Beyond the reference — it has no such reminder; the actual cap
is unlimited by design.)

- New `ReminderCategory.secrets` (defaults on; appears in settings via `allCases`).
- `ReminderAnnouncement.secretsRemaining(size:remaining:)` → "One large secret left"
  / "No more large secrets to find".
- Engine fires once when a size's remaining crosses to 1 or 0 (re-fires on unmark);
  not reset on groundhog (secret marks are permanent).
- `pollReminders` counts sized secrets on the grid; remaining = quest total − placed
  (1Q 3/7/4, 2Q 1/7/6).

## Acceptance criteria
- [x] "One <size> secret left" at remaining 1; "No more <size> secrets" at 0.
- [x] Fires once per crossing; re-fires on un-mark; per size.
- [x] New `.secrets` category (default on, toggle in settings).
- [x] Unit-tested (engine + display); build clean.
