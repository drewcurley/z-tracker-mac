# T-035.13 — Flags as toggleable icon tiles

## Description
Consistency housekeeping (user request): the Flags group's five seed/config
checkboxes (Heart Shuffle, Hidden Dungeon Numbers, Swordless, Boomstick,
Mirror OW) are now **toggleable icon tiles** matching the Info overlay tiles and
the item icons (`itemGridCellSize`, 34×34), laid out in a grid. Clicking a tile
is the same as clicking the old checkbox/label — including the mid-run
destructive confirmation for Heart Shuffle and Hidden Dungeon Numbers
(T-051/T-052), which is unchanged. Tooltips carry each flag's name (icon-only,
like the reference).

A shared `flagTile` helper mirrors the overlay-tile style (green fill+border when
on); it takes either an SF Symbol (tinted — e.g. the red heart) or an atlas icon
(Swordless bomb-upgrade; the Boomstick tile's book/shield icon follows the mode).
The Auto-map dungeons menu is unchanged (it's a dropdown, not a toggle).

## Acceptance criteria
- [x] The five flags render as 34×34 icon tiles (item-icon size), in a grid.
- [x] Clicking a tile toggles the flag (green when on), same effect as the old
