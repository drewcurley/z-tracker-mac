# T-030 — Dungeons and items side by side

## Description
User preference (2026-07-14, deferred): the main tracker currently stacks the
dungeon tracker **above** the item grid in a `VStack`
(`MainTrackerPlaceholderView`). Lay them out **side by side** instead. The
reference puts the item grid in the top-right next to the overworld map, with
the dungeon area elsewhere — so this is also a step toward the reference's
spatial arrangement.

## Notes / considerations
- Width budget: the dungeon tracker is 9 cards wide (~400px+) and the item grid
  ~5 columns (~220px); side-by-side is ~650px+, which the window accommodates
  but should be checked responsively (the whole thing is in a `ScrollView`).
- Decide whether this is a plain `HStack(dungeons, items)` or a fuller move
  toward the reference layout (items top-right by the overworld map).

## Acceptance criteria (draft)
- [ ] Dungeon tracker and item grid render side by side, not stacked.
- [ ] Responsive / no horizontal overflow at the app's normal window sizes.

## Status
Deferred by the user ("we can address that later"). Proposed / not started.
