# T-029 — Fix right-click in item boxes/picker

## Description
Right-clicking an item in the box picker (and on placed boxes / item-grid
toggles / take-any hearts) — meant to set "don't have it" / clear — did not
register. User-reported.

**Cause:** `onRightClick` attached `RightClickCatcher` as a `.background()`, so
the NSView sat *behind* SwiftUI's own gesture layer (`.onTapGesture`), which
consumed the mouse events before the catcher's `rightMouseDown` could fire.

**Fix:** make the catcher an `.overlay()` (in front) and override `hitTest` to
claim the point *only* during a right-mouse event (`NSApp.currentEvent`),
returning `nil` otherwise so left-click, hover, and scroll fall straight
through to the SwiftUI content behind. One central change fixes every
`.onRightClick` site: dungeon boxes, the `BoxItemPicker`, item-grid toggles,
and take-any hearts.

## Acceptance criteria
- [x] Right-clicking a picker item sets the box to that item with "don't have
      it" and dismisses the popover. On-device verified (coast picker → book →
      orange border).
- [x] Left-click (have it / open picker) and hover are unaffected. On-device
      verified (coast picker → raft → green border; box left-click opens picker).
- [x] The intercept decision is a pure, tested helper
      (`RightClickCatcher.intercepts`).
