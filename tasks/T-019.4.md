# T-019.4 — Stack Blockers over Notes

## Description
Follow-up to T-019.2 (user feedback): Blockers and Notes were side-by-side. The
reference stacks them (Blockers on top, Notes below) as a narrow column so the
per-dungeon room-map grid gets the horizontal space to its side; and since the
map is tall, the short blockers grid + notes stack beside it add no height —
important because the app already uses a lot of vertical space.

Changed the band to `HStack { VStack { Blockers; Notes }.frame(width: 420);
Spacer() }` — a 420-wide left column with the rest reserved for the room grid
(D1). The 420 width fits the full 3×3 blockers grid without clipping.

## Acceptance criteria
- [x] Blockers renders above Notes in a single column (not side-by-side).
- [x] The column is a fixed narrow width; the 3×3 blockers grid isn't clipped;
      the rest of the band width is free for the room grid.
- [x] Build clean (debug + release); on-device verified.
