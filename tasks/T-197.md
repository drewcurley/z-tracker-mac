# T-197 — In-menu hotkey hints

Coverage §1 #3b — the last unshipped sliver of the HotKeys system. Reference:
`AppendHotKeyToDescription` (`OverworldItemGridUI.fs:139`) shows a choice's bound key inline.

## Implementation
- `HotkeyHints` (TrackerCore): maps an overworld mark / hint zone → its `HotKeys.txt`
  selector id (derived by iterating the catalog + reusing `fromHotkeySuffix` /
  `fromHotKeyName`, so there's no second mapping to maintain), then formats the bound chord
  as an inline `" (B)"` suffix or a bare `"B"` badge; empty when unbound.
- `HotkeyConfig` is injected into the SwiftUI environment once (`MainTrackerPlaceholderView`)
  so leaf menus read it without wide plumbing.
- **Overworld tile menu** (SwiftUI right-click + native left-click-reopen): each mark item
  gets the inline hotkey suffix (shops, levels, any-roads, swords, secrets, take-any, and the
  standalone marks).
- **Hint-zone picker**: each zone shows its key as a small badge under the two-char code, and
  in the tooltip — the reference-faithful surface.
- Bindings are set by default (tiered palette), so hints appear out of the box; unbound
  choices show nothing (no clutter).

## Tests
`HotkeyHintsTests`: mark/zone → selector mapping; suffix/keyLabel reflect the bound chord and
are empty when unbound. 730 tests pass. Visual placement QA'd on device.
