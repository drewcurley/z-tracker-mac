# T-031 — Extra Candles option

## Description
A randomizer option (distinct from swordless / WSMS→BU, T-025.4) the user
described: when **Extra Candles** is on, a **blue candle** is placed in the
**wood sword cave**, and the **take-any caves'** possible contents become
{red potion, blue candle, heart}.

This is a deliberate extension (verify exact reference/wiki behavior before
building — the reference tracker may not model it; the user is the authority on
the intended behavior). Do **not** conflate with the swords→bombs toggle: the
wood sword is untouched by that toggle.

## Resolved design (user-confirmed 2026-07-14)
- **Own chrome toggle** (`extraCandles`), like swordless / book-shield.
- **Wood sword box**: shows a **blue candle** AND counts as a candle (raises
  candle level, not sword level) — `PlayerComputedStateSummary.compute` branch.
- **Take-any caves**: four distinct states — unclaimed / heart / potion /
  candle. The empty-heart shape stays as the background; a taken heart fills it
  (pink), a taken potion/candle keeps the empty heart and overlays that item's
  icon. Blue candle (not red).

## Acceptance criteria
- [x] `TrackerModel.extraCandles`; `PlayerComputedStateSummary` counts the

- [x] Extra Candles chrome toggle; wood-sword box → blue candle icon under it.
- [x] Tests: wood→candle derivation, 4-state cycle, raw values.
