# T-064 — Enlarge the interior-sprite tile icons

## Description
The plain interior-sprite tiles (secrets, door repair, money making game, the
letter, armos, hint shop, take-any, potion) rendered small and off-center,
confined to the reference's tiny 5⁄16 × 9⁄11 interior region. They now render
**large and centered** in the tile — same reference sprites, no new art — so
they read at map scale like the dungeon-number and sword-cave tiles.

Shops are unchanged: their orange-plate + two 3×7 item icons already read well,
so they keep the reference interior-region placement (split into a separate
`shopIconView`).

## Acceptance criteria
- [x] Interior sprites render at ~0.9 tile height, horizontally centered.
- [x] Native 5×9 aspect preserved (`.fit`, nearest-neighbor) — no distortion.
- [x] Shops keep their orange-plate presentation.
- [x] Suppressed by "Hide tile icons" and dimmed by "used" exactly as before
      (still inside the gated `!hideMarks` block).
