# T-136 — App-bundle + permission scaffolding

## Description
Package the app as a real `ZTrackerMac.app` bundle so it can request microphone +
speech-recognition access — macOS TCC hard-kills a bare executable that asks for the
mic, and won't remember a grant without a stable signed identity. This is the
prerequisite for the voice-control feature (T-137).

- `Bundle/Info.plist.template` — bundle id `com.drewcurley.ztracker-mac`, the two TCC
  usage strings (`NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription`),
  `NSPrincipalClass`, min-OS 14, and version fields.
- `VERSION` (single source of truth) → `CFBundleShortVersionString` / `CFBundleVersion`.
  Earmarks the **versioning + self-update-on-load** system (a later task): the update
  check will compare the bundle's short version against a release feed.
- `scripts/build-app.sh [release|debug]` — `swift build`, assemble the `.app`, copy the
  SwiftPM resource bundle into `Contents/Resources` (where `Bundle.module` resolves it),
  substitute the version, ad-hoc code-sign.

## Acceptance criteria
- [x] `scripts/build-app.sh` produces a signed `ZTrackerMac.app` (stable bundle id).
- [x] The `.app` launches and resources resolve (item/overworld sprites render).
- [x] Info.plist carries the mic + speech usage strings and version from `VERSION`.
- [x] `.app` build product is git-ignored; full suite still green (545 tests).
