# T-015.6 — Destination-picker menu

## Description
Builds the routing destination picker, ported from `Z1R_WPF/LinkRouting.fs`
(`:15-235`; entry `SetupLinkRouting :38`, popup `activatePopup :65-235`,
triggered by the animated "Link" icon `:236-238`). The `RouteDestination`
model has three payload shapes (`:15-18`): `OW_MAP of (int*int) list`,
`HINTZONE of HintZone*bool`, `UNMARKEDINSTANCEFUNC of (int*int -> bool)`.

Target taxonomy (in build order, `:109-229`): potion shop; the five item
shops (bomb/book/blue-ring/arrow/candle, matching primary mark OR stored
second item); open caves (`UNMARKEDINSTANCEFUNC owInstance.Nothingable`);
triforces/dungeons 1–8 (located -> `OW_MAP`, else hinted -> `HINTZONE`);
level 9; White Sword cave (`Sword2Location`); Magical Sword cave
(`Sword3Location`); any overworld tile (click-anywhere).

## Acceptance criteria
- [ ] `RouteDestination` (3 cases) + the picker UI, matching the reference
      taxonomy exactly (not invented).
- [ ] Selecting a target drives the cyan route-target rendering (T-015.4).
- [ ] Tests for target enumeration against hand-constructed map state.

## Out of scope
- `HINTZONE` targets depend on the hint system (`GetLevelHint`/`HintZone`),
  not yet ported — gate those behind the hint work (coordinate with T-016)
  or ship the picker with hint-based targets disabled first.

## Risks / dependencies
- Depends on T-015.1–T-015.5. Largest and last sub-task.
