# T-047 — Mirror-overworld flag

## Description
Mirrored seeds flip the entire overworld East↔West. The reference has a
"Mirror overworld — Flip the overworld map East<->West" option
(`TrackerModel.MirrorOverworld`, `OptionsMenu.fs:20`) that applies a
`ScaleTransform(-1, 1)` to the whole map canvas and re-flips the readable
elements (`UI.fs:1302-1310`). This adds the same to the Mac tracker.

Implementation: a `mirrorOverworld` model flag + a **Mirror OW** toggle in the
Flags group. The map container gets `scaleEffect(x: -1)` when on — which flips
both the render and the hit-test coordinate space, so a tap still lands on the
tile you see (no column remap). The readable glyphs — dungeon/any-road numerals,
interior icons, the fairy, and the coordinate labels — are counter-flipped so
they don't render backwards, mirroring the reference's re-flip. The flag is also
fed to `MapStateSummary.compute` (it already consumed a `mirrorOverworld` for
the mirrored screen-scroll routing edge).

Book-as-atlas — the other reference flag — is deliberately **not** added: its
only consumer (`PlayerCanSeeMapOfThisDungeon`, a dungeon-map view) isn't built
yet, so a toggle would be a dead control.
