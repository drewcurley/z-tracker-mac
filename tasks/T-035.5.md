# T-035.5 — Auto-map vanilla dungeons (the FQ/SQ button)

## Description
An "Auto-map dungeons…" control in the Info group that drops the vanilla
First- or Second-Quest dungeon locations onto the overworld. Ported coordinates
from the reference (`OverworldData.fs:25-26`,
`vanilla1QDungeonLocations` / `vanilla2QDungeonLocations`).

**Deliberate deviation from the reference:** the reference paints a
non-destructive numbered-*circle* overlay on a separate layer this port doesn't
have. Per the user's request ("map the vanilla locations and remove any previous
dungeon markers"), the clone instead sets the real `.dungeon(n)` marks and
clears any prior dungeon marks first. Destructive, so it confirms.

## Acceptance criteria
- [x] A menu offering "First Quest vanilla" and "Second Quest vanilla".
- [x] Each places dungeons 1–9 at the correct vanilla screens.
- [x] Prior dungeon marks are cleared; other marks (shops, secrets) are kept.
- [x] A take-any tile overwritten by a dungeon releases its heart slot (T-066).
- [x] Destructive → confirms first.
