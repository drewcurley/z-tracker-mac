# T-033 — Chrome cleanup

## Description
Two user-feedback items on the T-025.5 chrome:

1. **Max Hearts is read-only.** It's a program-computed number (rises as the
   player collects heart containers / take-any hearts) — not user-editable.
   Removed the `+/-` stepper (and the now-unused `MaxHeartsControl`); the
   readout reads the derived `playerHearts`. (The rarely-needed starting-hearts
   differential remains adjustable in the debug panel.)
2. **Labels → tooltips.** Per the user's general UI preference (keep it clean),
   the seed-option toggles are now **icon-only checkboxes with rollover
   tooltips** instead of icon + long visible text — which also matches the
   reference (`OverworldItemGridUI.fs:395-427`, icon-only checkboxes + ToolTip).
   The take-any hearts already had no visible label (tooltip only); confirmed.

Chrome relaid as a single row: the three icon toggles + a spacer + the
Max Hearts readout.

## Acceptance criteria
- [x] Max Hearts readout is read-only (no stepper); updates as hearts are
      collected.
- [x] Swordless / Book-Shield / Extra Candles toggles are icon-only with
      tooltips.
- [x] Take-any hearts carry no visible label (tooltip only).
