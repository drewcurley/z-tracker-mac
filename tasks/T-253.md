# T-253 — Dungeon invert button + "Left-drag auto-inverts"

## Description
Audit §4 'built but hidden': the option was hidden in T-206 'until drag-paint exists' — drag-paint shipped in T-072, but the reference's invert operation it depends on was never built.

## Acceptance criteria
- [x] An invert button (off-the-map sprite / orange slash / unmarked sprite, cyan border on hover) under the dungeon minimap swaps every unmarked room ↔ off-the-map; marked rooms untouched; disabled in grab mode.
- [x] With 'Left-drag auto-inverts' on, the first-ever drag in a dungeon, if it's a left drag, inverts first so the drag paints the map on; any drag or invert disarms it (session-only, as the reference's hasEverInvertedOrDragged).
- [x] While auto-invert is armed, a plain left press waits for mouse-up, so a press that becomes a drag doesn't first click the start room (the reference never fires a click for a drag).
- [x] The setting is visible again with the reference's description.
- [x] Middle-drag paint uses 'Default to NonDescript' like left-click (was hard-coded).

## Notes
Also restores the reference tip about editing items in the box beside the dungeon map (it exists — the ITEMS card in the dungeon info strip); T-250 dropped it in error. Not ported: the off-map grid outline + minimap popover shown during a drag (cosmetic). Tests: DungeonInvertTests (3).
