# T-015 — Real GYR + destination picker + live routing state

## Description
Closes the loop `T-011` deliberately left open. With `T-012`/`T-013`/`T-014`
in place, this task:

1. Ports the shop/cave-discovery flags and gettable/routeworthy
   classification from `recomputeMapStateSummary`
   (`TrackerModel.fs:1033-1140`) — `OwGettableLocations`,
   `OwRouteworthySpots`, and the 8 discovery booleans
   (`magsCaveFound`, `woodSwordCaveFound`, `foundBlueRingShop`,
   `foundBookShop`, `foundCandleShop`, `foundArrowShop`, `foundBombShop`,
   `havePotionLetter`, all declared together at `:1013-1014`). This
   function is mostly overworld/routing-domain work `z-tracker-mac` already
   has (T-006-T-010) — this task adds the missing player-state-derived
   inputs it needs (`GetDungeon(x).IsComplete`, `.PlayerHasTriforce()`,
   `playerComputedStateSummary.*`, `armosBox.IsDone()`,
   `playerProgressAndTakeAnyHearts.PlayerHasMagicalSword`/`.PlayerHasBombs`).
2. Upgrades `T-011`'s `OverworldRouteHighlight` "reachable/unmarked"
   stand-in to true GYR (green="accessible", yellow="sometimes empty" via
   `owInstance.SometimesEmpty`, red="inaccessible" via
   `!OwGettableLocations`), per `OverworldRouteDrawing.fs`'s
   `doComputedDrawing`.
3. Wires `OverworldMapView`'s remaining placeholder constants
   (`isMirror`, `canScreenScroll`'s recorder-warp/any-road inputs) to live
   state, and reinstates the dashed/skipped warp-line styling in
   `OverworldRouteHighlight` that `T-011` correctly left unported as dead
   code (no warp destinations existed yet to exercise it).
4. Builds the destination-picker menu (specific tile, shop type, dungeon,
   WS/MS cave, remaining open caves) — read `OverworldRouteDrawing.fs`'s
   and the WPF/Avalonia UI callers' destination-selection code (not yet
   read in depth) before implementing, per the Grounding & Completeness
   Protocol.

## Acceptance criteria
- [ ] `magsCaveFound`/`woodSwordCaveFound`/shop-discovery flags ported and
      tested.
- [ ] `OwGettableLocations`/`OwRouteworthySpots` classification ported,
      tested against hand-constructed scenarios.
- [ ] True GYR rendered in `OverworldMapView`, replacing the single-color
      "reachable" highlight.
- [ ] Destination-picker menu built, matching the reference's own taxonomy
      (not invented).
- [ ] `ladder`/`raft`/`isMirror` placeholders removed from `OverworldMapView`
      entirely — everything wired to live state.
- [ ] Tests at every layer, per the established discipline.
