# T-211 — Sparkle in-place auto-update

## Description
Replace the "download from GitHub" flow with a true in-place updater: the app downloads the new
version, verifies it, swaps the `.app`, and relaunches — one click. Wanted by the user; the
planned next step already sketched in `docs/RELEASING.md`.

Works on the **free/self-signed path today** — updates are authenticated by an EdDSA signature,
independent of Apple notarization. When the user's paid Developer account comes through,
notarization is a drop-in (build-app.sh already detects a Developer ID identity).

## What shipped
- **Sparkle 2** SwiftPM dependency; `SparkleUpdaterController` wraps `SPUStandardUpdaterController`.
- App menu **Check for Updates…**; the startup banner's button becomes **Update now** (in-place),
  keeping a **View on GitHub** fallback.
- `Info.plist`: `SUPublicEDKey` (committed) + per-arch `SUFeedURL` (injected by `build-app.sh` →
  `…/releases/latest/download/appcast-<arch>.xml`); automatic checks off (app drives them).
- `build-app.sh` embeds + signs `Sparkle.framework` and adds the `@executable_path/../Frameworks`
  rpath. `make-dmg.sh` EdDSA-signs each `.dmg` and emits `dist/appcast-<arch>.xml`.
- **Per-architecture appcasts** so the dedicated arm64 / Intel builds each update to their own
  native binary. Private signing key lives in the release machine's Keychain (never in the repo).

## Acceptance criteria
- [x] "Check for Updates…" (menu) and "Update now" (banner) run Sparkle's flow.
- [x] A newer signed build downloads, verifies (EdDSA), installs in place, and relaunches —
      **verified end-to-end locally** (0.9.2 → 1.0.1 over a localhost appcast, self-signed).
- [x] arm64 and Intel builds each point at their own appcast.
- [x] Works un-notarized; notarization remains a drop-in.

## Out of scope / notes
- **First-release bootstrap:** pre-Sparkle builds (≤ v0.9.2) can't auto-update *to* v1.0.0 — users
  install it manually once via the GitHub banner; auto-update works from v1.0.0 onward.
- Notarization (paid Apple account) removes the one-time Gatekeeper prompt on first manual install;
  it is not required for the auto-update itself.
