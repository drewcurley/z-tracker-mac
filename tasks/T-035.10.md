# T-035.10 — Progress HUD

## Description
Replaces the read-only Item Progress strip (T-035.9) with the reference's faux
items+hearts inventory HUD (`Popouts.makeFauxItemsAndHeartsHUD`), which mimics
the in-game inventory subscreen so players read it by muscle memory.

- **`FauxItemsHUD`** composites the HUD by *drawing* into a CGContext (reliable
  orientation): the "best" (all-items) bitmap with each slot erased when unowned
  or overlaid with the "worse" (downgraded) variant at level 1, plus a heart row.
  New assets `all-items-hud-pixels1.png` / `-worse.png` / `icons8x8.png`.
- **"Progress" toggle** — a visual-toggle icon in the Info overlay row; a click
  opens/closes the HUD as a **separate, resizable, freely-stretching window**
  (secondary `WindowGroup(id:)` opened via `openWindow`/`dismissWindow`).
- **Removed** the always-on "Max Hearts: N" field (redundant — the player's
  heart count is always on-screen in game; the HUD shows the row anyway).
- **Meat toggle** added to the Items grid (under Zelda), driving the HUD's meat
  slot (beyond the reference, which never tracks meat).

Deliberate deviations (user requests): hearts fill logically (first three red in
the top row, then spill to the second); the letter/potion slot always shows the
**letter**, lit from the overworld letter cave being **used**; no hover preview
(a plain window toggle — a hover popover fought the click).

## Acceptance criteria
- [x] HUD composites in the correct in-game layout (items + 2 heart rows).
- [x] Slots erase when unowned; level-1 items show the downgraded variant.
- [x] Meat lights from the new toggle; letter lights when the letter cave is used.
- [x] "Progress" icon toggles a separate resizable window (stretches to fill).
- [x] Item Progress strip and Max Hearts field removed.
