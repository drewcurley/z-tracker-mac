# T-078.1 — Row-locator design correction

## Description
T-078 built the row-locator wrong (a grid-aligned strip whose rupee/key/bomb
icons only appeared on hover, with a full-width row bar). Per the user + the
reference (`DungeonUI.fs:556-577`) and their Windows screenshots, the correct
design is a **compact widget by the old-man counter**: the rupee/key/bomb icons
are **always visible** (keying the 8 in-game-HUD rows into bands — rows 1-2 =
rupee, 3-4 = blank, 5-6 = key, 7-8 = bomb), and hovering a room reveals a small
gray marker at that room's row beside the icons.

- `RowLocatorWidget` (new): the always-on rupee/key/bomb icon column + an 8-slot
  marker column that reveals the hovered row.
- `hoveredRow` moved up to `DungeonMapView` (a `@Binding` into the grid) so the
  grid (hover source) and the info-strip widget share it. The grid's reserved
  strip + full-row bar from T-078 are removed.

## Acceptance criteria
- [x] Rupee/key/bomb icons always visible in the info strip by the old-man count.
- [x] Hovering a room reveals a marker at that room's row band (verified with a
      forced hover: row 1 → rupee band).
- [x] Grid width/layout back to pre-T-078 (no reserved strip). Build clean; tests pass.
- [ ] Live hover confirmed by the user.
