# T-181 — Spoiler-log importer

## Description
Import a Z1R randomizer **spoiler log** (`*_log.txt`) and auto-mark the board. New feature
(the reference tracker does **not** import spoilers — its only `_log` reference is a crash log;
it merely *snoops* the emulator window title for seed/flags display). Re-scoped up from "likely
never" (T-180). Seed/flags **snoop is out of scope** for now (importer only).

Format fully decoded from a real log (`SEED 3952398579`, flags `1K9hKZCQam…`). Seed + flag string
also live in the filename: `Legend of Zelda, The.nes_<seed>_<flagstring>_log.txt`.

## Scope (user-locked 2026-07-28)
On import, show a panel of **per-section checkboxes (remember last selection)**; apply only the
checked sections; overwriting the board is fine (spoiling is the point) but **confirm first**:
1. **Overworld markers** — the `CAVES` section: every screen → its `OverworldTileMark`.
2. **Dungeon items** — the `ITEMS` section, incl. **White Sword Cave / Coast (Ladder Spot) / Armos**
   items, plus each `Level N` dungeon's held item + its overworld location.
3. **Dungeon room maps** — the `LEVEL N MAP` ASCII → the 8×8 `DungeonRoomMap` (rooms/doors/transports).
4. **L9 reqs + start spot** — append the required triforces to **Notes** ("Triforces needed for
   Level 9: 3 5 7"; no direct UI for it) and mark the **Start Screen** spot.

## Format spec (from the real log)
- `SEED <n>` — the seed.
- `LEVEL 9 ENTRY:` → `Specific triforces needed:  3 5 7` and `Start Screen:  B15`.
- `ITEMS` → `Level 1-6 (located at 47 E8) contains Boomerang` = dungeon# `6`, hex screen `0x47`,
  overworld coord `E8`, item `Boomerang`. Plus `White Sword Cave contains Wand`,
  `Armos Item contains Red Ring`, `Coast Ladder Spot contains BOMB UPGRADE`, and L9's two items.
- `CAVES` → `Location E10 contains: MAGICAL SWORD CAVE` = screen `E10` → mark.
- `SHOP INFO` → `SHOP 1..4` + `POTION SHOP` with `Item:  price` lines (cross-ref for `SHOP N` caves).
- `LEVEL N MAP` → ASCII grid: room `*`, doors `-`/`|`, transports `A`–`H` (shared-letter pairs),
  entrances `>` `<` `v` `^`.

**Coordinate mapping (verified):** rows `A`–`H` = 0–7, cols `1`–`16` = 0–15;
`hexIndex = row*16 + (col-1)` (`E8`→`0x47`=71 ✓). Grid is 16×8 (`OverworldGrid.columnCount/rowCount`);
`OverworldGrid.setMark(_:column:row:)` takes column 0–15, row 0–7.

## Cave-string → mark mapping
**Confident (standard Zelda):** `LEVEL N`→`.dungeon(N)`; `WOODEN/WHITE/MAGICAL SWORD CAVE`→
`.swordCave(1/2/3)`; `10/30/100 SECRET`→`.secret(.small/.medium/.large)`; `DOOR REPAIR`→`.doorRepair`;
`MONEY MAKING GAME`→`.moneyMakingGame`; `POTION SHOP`→`.potionShop`; `LETTER CAVE`→`.theLetter`;
`SHOP N`→shop (map via `SHOP INFO` notable items → `ShopKind`, up to 2).

**Resolved by user (2026-07-28), authoritative:**
- `TAKE ANY ROAD...` → an **any-road / warp cave** (`.anyRoad` 1–4). The spoiler doesn't give the
  1–4 order, so import them as a **NEW 5th "?" (unknown-order) any-road state** (see build step 1);
  the user assigns 1–4 later as discovered.
- `TAKE ANY ONE` → `.takeAny` — an unclaimed take-any secret (resolves to heart / potion / candle).
- `SECRET IS IN...`, `WATERFALL PAY ME`, `LOST WOODS PAY ME` (both "PAY ME" caves), `OLD MAN AT GRAVE`
  → `.hintShop` (generic hint cave).

Parser still routes any *unrecognized* string to an `unmapped: [(coord, raw)]` list surfaced to the
user rather than mis-marking.

## Build plan
0. **Any-road "?" (unknown-order) state** — add a 5th any-road option to `OverworldTileMark` for a
   warp cave whose 1–4 position isn't known yet (the importer marks all `TAKE ANY ROAD...` caves this
   way; also useful manually). Wire it into the tile picker + rendering; routing skips it (no known
   destination). **Schema-sensitive** — touches the raw-index/save bridge (T-015.2) → Architect + Data
   + SDET must cover the enum/raw-index/save round-trip.
1. **Parser** (`TrackerCore/SpoilerLog.swift`, pure/`Sendable`) → structured `SpoilerLog` value
   (seed, l9Triforces, startScreen, items, caves→marks, shops, dungeonMaps, unmapped). Unit-tested
   against the real log embedded as a fixture. *(Room-map ASCII parse can be a second slice.)*
2. **Apply** (`SpoilerLog.apply(to: TrackerModel, sections:)`) — selective per checkbox; wraps the
   board overwrite; Notes append + start-spot mark for §4.
3. **Import UI** — NSOpenPanel for `*_log.txt` (default `GameSave.defaultDirectory`, see
   [[default-file-location]]), the remembered-checkbox panel, confirm, then apply. Entry point in
   Settings and/or the header.

## Acceptance criteria
- [ ] Parser round-trips the real log; every `CAVES`/`ITEMS` line either maps or lands in `unmapped`.
- [ ] Ambiguous cave strings verified against z1r sources before being mapped (none invented).
- [ ] Import panel: per-section checkboxes, remembered; confirm-before-overwrite.
- [ ] Each section applies correctly (overworld marks, dungeon items incl. sword/coast/armos, room
      maps, L9→Notes + start spot); unchecked sections untouched.
- [ ] Parser + apply unit-tested; user real-mouse QA on their own log before merge.
