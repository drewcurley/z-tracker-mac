# T-025.2 — Take-any hearts row

## Description
The bottom row of the item grid (T-025): the 4 overworld "take-any" heart-cave
slots (`HEARTS`, `OverworldItemGridUI.fs:197-222`), each a tri-state box the
player cycles by clicking. Ported from the reference:

- States (`PlayerProgressAndTakeAnyHearts.takeAnyHearts`, already modeled):
  `untaken` → `takenHeart` → `takenPotionOrCandle`, cycled `(cur + delta + 3)
  % 3` — left-click forward, right-click backward
  (`OverworldItemGridUI.fs:207-209`).
- Sprites: `owHeartEmpty` (untaken / potion) and `owHeartFull` (taken heart)
  from `icons10x10.png` (indices 3 and 4, `Graphics.fs:602-618`), newly
  vendored. The potion/candle choice draws an X over the empty heart
  (the reference's `placeSkippedItemXDecoration`).

## Acceptance criteria
- [x] `icons10x10.png` vendored + `OverworldHeartAtlas` (empty=3, full=4);
      NOTICE attribution added.
- [x] Grid extended to 4 rows; row 3 = `[heart0…heart3, empty]` matching
      `OW_ITEM_GRID_LOCATIONS.HEARTS` (nothing at 4,3).
- [x] `TakeAnyHeartBox`: full sprite when a heart was taken, empty otherwise,
      X on potion/candle; left-click cycles forward, right-click backward.
- [x] Cycle formula extracted to a pure, tested `ItemProgressGrid.cycledHeart`.
- [x] Tests: layout row 3 mapping; cycle wrap (both directions);
      heart→`PlayerComputedStateSummary` hearts integration (taken heart +1,
      potion +0). On-device verified all three visual states.
