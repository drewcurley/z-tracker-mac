# T-149 — Universal clear / un-mark

## Description
The single most-hit voice-QA pain point: nothing could be **un-marked** — "clear
triforce" re-marked it, "un take silver arrows" set the flag. Fix: a negation verb
("clear / remove / erase / un-take / un-mark / reset…") whose target is generic, a
dungeon thing, a bare direction (door), or a progression item routes to a new
`clearAtCursor` / `clearAt` command; a negation whose target is a *specific*
command (e.g. "clear start" → OW_ClearStart) falls through to normal parse.

Execution (region-aware):
- **Overworld** → cell unmarked (or a progression clear).
- **Dungeon** → clear the named door / room type / floor drop / monster, or the
  **whole room** with no target ("clear").
- **Progression** ("un-take wood sword") → flag false, from any region (undo isn't
  region-gated).

## Acceptance criteria
- [x] "clear triforce"/"clear gleeok"/"clear north"/"clear" route to clear; "clear start" doesn't.
- [x] dungeonClearActions resolves door/room/monster/drop; empty → room clear.
- [x] Progression clear (value:false) from any region. 597 tests.
