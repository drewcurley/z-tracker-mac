# T-111 — Money highlighter includes marked money secrets

## Description
The money-locator overlay (one of the six top-section info icons) only highlighted
the Money Making Game and Unknown Secrets — sized money secrets never lit up because
the call site hardcoded `secretValue: 0` and this port has no per-secret rupee
pricing. The reference (`WPFUI.fs:1467-1483`) highlights sized secrets that carry a
rupee value; lacking that, we now highlight any large/medium/small money secret
you've **marked but not yet collected** (`!used`) — the ones still worth walking to.
A collected (used/dark) secret is spent and drops out of the highlight.

`isMoneyTile(_:secretCollected:)` replaces the unused `secretValue:` parameter; the
map call site passes the tile's `grid.isUsed`.

## Acceptance criteria
- [x] MMG + Unknown Secret always highlight.
- [x] Marked large/medium/small secrets highlight while not collected; drop out once
      collected.
- [x] Non-money marks never highlight.
- [x] Unit-tested; build + full suite clean.
