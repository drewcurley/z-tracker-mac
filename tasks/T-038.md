# T-038 — Timer display stutter on groundhog reset

## Description
The user noticed the timer stuttering when clicking the groundhog reset. The
elapsed value is **accurate** (`mainElapsed = accumulated +
now.timeIntervalSince(segmentStart)` — wall-clock derived, never drifts; the
reset doesn't touch the main anchor). The stutter was purely visual:

1. `TimelineView(.periodic(from: Date(), by: 0.03))` re-anchored its refresh
   schedule on every re-render — and a groundhog reset triggers a large
   re-render — re-phasing the ms ticks. Fixed with a stable `@State`
   `refreshAnchor` created once.
2. The lap line appearing shifted the layout. Fixed by always reserving the lap
   line's height (hidden via opacity until a lap starts).

## Acceptance criteria
- [x] Stable `TimelineView` anchor (no re-phase on re-render).
- [x] Lap line reserves height (no layout jump when it appears).
