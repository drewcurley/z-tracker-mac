# T-018 — Reminders, announcements, Triforce-and-Go

## Description
The top-of-stack consumer of the entire player-state system, correctly
scheduled last. Grounded in `TrackerModel.fs:1439-1750` (~310 lines):

- **`TriforceAndGoSummary`** (`:1439-1485`, ~47 lines) — a heuristic-scored
  "are you basically done, should you beeline to the final dungeon"
  advisor. Reads `playerComputedStateSummary.{HaveBow,ArrowLevel,HaveLadder,
  HaveRecorder}`, `GetDungeon(8).Boxes`, and
  `unreachablePossibleDungeonSpotCount()` (`:1422-1438`).
- **`ITrackerEvents`** interface (`:1486-1508`, ~23 lines) — the full
  contract of UI callback events the reference model drives (hearts,
  dungeon-location/completion, routing info, blocker reminders, item
  reminders). Effectively the entire event surface a Swift ViewModel would
  need to implement, if following this exact architecture (worth
  reconsidering against `@Observable`'s reactive model rather than porting
  literally — a real design decision for whoever starts this task, not
  assumed here).
- **`allUIEventingLogic(ite)`** (`:1568-1750`, ~180 lines) — diffs
  previous-vs-current state and fires announcements: heart-threshold
  reminders for sword caves, dungeon-completion/found/triforce-count
  announcements, Triforce-and-Go announcements, blocker "you can go back"
  reminders, one-shot item-acquisition nudges. Depends on ~a dozen
  `prior*`/`remembered*` mutable trackers (`:1511-1530`) for edge-transition
  detection.
- `doesPlayerHaveTriforceAndWhichDungeonIndexIsIt` (`:1553-1567`) and
  `ResetForGroundhogOrRoutersOrFourPlusFourEtc` (`:1531-1552`, a full-state
  reset for a "restart run" feature).

## Acceptance criteria (indicative — refine before starting)
- [ ] Decide the Swift-idiomatic equivalent of `ITrackerEvents` (reactive
      `@Observable` properties + `.onChange`, vs. a literal delegate-
      protocol port) — this is a real architecture decision, evaluate
      before implementing, don't default to a literal port just because
      it's easiest to transcribe.
- [ ] `TriforceAndGoSummary` ported and tested.
- [ ] Announcement/reminder logic ported for the announcement types this
      app actually has a surface for (many of the reference's reminders are
      tied to UI this project hasn't built yet — reminders.md/§4.3 in
      `docs/domain.md` may already cover some of this; cross-check before
      assuming it's all new).
