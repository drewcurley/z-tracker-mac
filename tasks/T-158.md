# T-158 — Single-utterance two-item shop

## Description
The T-141 second-shop-item logic only fires when the second shop word arrives as a
*separate* command on a tile that is already a shop. Saying both items in one breath —
"bomb shop and meat", "bomb shop second item meat" — set only the primary and dropped
the second. Decision (per "go crazy on all fixes"): resolve two distinct shop kinds in
a single utterance to `(primary, second)` and set both at once.

New `VoiceGrammar.overworldShopPair(words, config)` scans the utterance token-by-token
for the eight real `ShopKind` shops and returns the first two *distinct* kinds in the
order spoken (nil for zero/one, so the normal single-mark path is unaffected). The
VoiceController overworld path checks it before the single-mark path: apply
`.shop(primary)` then `setShopSecondItem(second)`. Potion/hint shops are their own tile
marks (not `ShopKind`) and never form a pair.

## Acceptance criteria
- [x] "bomb shop and meat" / "bomb shop second item meat" → primary bomb + second meat.
- [x] Spoken order decides primary vs second ("meat and bomb shop" → meat, bomb).
- [x] Single shop, repeated same shop, and potion/hint-only utterances → no pair.
- [x] 614 tests.
