# T-035.8 — Start spot

## Description
Mark the overworld screen the player spawned on, rendered as a lime ring on a
violet glow (ported from `makeStartIcon`, `UIComponents.fs:189-203`). State is a
single optional coordinate (`TrackerModel.startSpot`, ported from
`startIconX/Y`). Set/cleared from the tile context menu ("Set as start spot" /
"Clear start spot") — simpler than the reference's modal placement mode, and it
fits the existing per-tile menu. Purely a marker; changes no tile mark. Auto-
mirrors with the map.

## Acceptance criteria
- [x] "Set as start spot" on the tile menu places the marker.
- [x] The marked tile shows the lime/violet ring.
- [x] "Clear start spot" (shown when the tile is the start) removes it.
- [x] Independent of the tile's mark; only one start spot at a time.

## Out of scope
- Auto-prompting the start spot after a tracker reset (reference convenience).
