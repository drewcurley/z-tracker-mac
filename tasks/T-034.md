# T-034 — Remove the Extra Candles flag + wood→candle behavior

## Description
The user corrected the Extra Candles mechanic (reversing an earlier statement):
Extra Candles puts a candle in the wood sword cave **alongside** the wood sword
(the wood sword still counts as a sword — unless swordless). So T-031's dedicated
`extraCandles` tracker flag, its chrome toggle, and the wood-sword-box→candle
display/derivation were **incorrect** and are removed.

**Kept:** the 4 distinct take-any heart states (unclaimed / heart / potion /
candle) with the potion/candle overlays — that part is correct and stands on its
own (the game's Extra Candles option can put a blue candle in take-any caves).

## Removed
- `TrackerModel.extraCandles`.
- `PlayerComputedStateSummary.compute` `extraCandles` param + the
  wood-sword→candle branch (reverted to: wood sword always raises sword level).
- The Extra Candles chrome toggle; the wood-sword branch in `iconOverride`.
- The `extraCandlesWoodToCandle` test + the helper's `extraCandles` param.

## Acceptance criteria
- [x] No `extraCandles` anywhere in Sources/Tests; wood sword always counts as
      a sword.
- [x] Chrome shows only Swordless + Book/Shield toggles + Max Hearts.
- [x] 4-state `TakeAnyHeartState` + take-any rendering preserved.
