# T-016.3 — HDN labeling UI + overworld lettered-dungeon rendering

## Description
The user-facing half of HDN. **Premise corrected by reading the reference
first** (the T-016 acceptance note): the overworld dungeon tile does **not**
render the player-assigned color/number — it shows the fixed A–H *slot* letter
on yellow (green when the triforce is obtained and the player has the recorder).
The player-assigned **color + real number** render on the **tracker** (the
reference's triforce-row swatch / dungeon tab), not the map
(`OverworldMapTileCustomization.fs:215-225`, `UI.fs:235-241`,
`Z1R_Avalonia/Dungeon.fs`).

So the real work here:
- **Color palette + assignment UI** (was entirely missing — `Dungeon.color`
  was written-once dead state). Added `DungeonColorPalette` (14 hues × 3 shades
  = 42 swatches, ported from `flatColorArray`) + `isBlackGoodContrast`, a color
  swatch grid in the HDN dungeon chooser popover, and rendering the assigned
  color+number on the dungeon card's chip (glyph black/white by contrast).
- **Overworld lettered rendering** was already faithful (A–H via `slotLabel`,
  shipped T-049/T-050). The only remaining overworld piece — the green
  "triforce-obtained + recorder" variant — is a warp indicator (applies in
  numbered mode too) and is deferred as its own follow-up (see Out of scope).

## Acceptance criteria
- [x] Read the HDN assignment UI flow in the reference first.
- [x] Overworld dungeon tiles render the correct HDN glyph (fixed A–H letter —
      already shipped; confirmed faithful, not the player color/number).
- [x] A way to assign `color` (new swatch grid) and `labelChar` (existing).
- [x] The assigned color+number render on the dungeon tracker card.

## Out of scope
- Basement-stair rendering — T-016.2 (done).
- Overworld green "warpable dungeon" tile variant (triforce + recorder) — a
  warp indicator independent of HDN; entangles with the known recorder quirk.
  Filed as a follow-up.
- Auto-opening the number chooser on triforce claim (reference convenience) —
  deferred; not core to assignment.
