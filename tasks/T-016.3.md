# T-016.3 — HDN labeling UI + overworld lettered-dungeon rendering

## Description
The user-facing half of HDN. Two pieces:
- **Overworld lettered-dungeon rendering:** in HDN, an overworld dungeon tile
  shows the player-assigned color + letter (`Dungeon.color`/`labelChar`)
  instead of the numbered digit. `OverworldTileMark.iconSource`'s
  `.dungeonDigit` note already flags this as the deferred HDN variant.
- **Label/color assignment UI:** how the player assigns a color+letter to a
  discovered dungeon (a dungeon-tracker surface that doesn't fully exist yet).

## Acceptance criteria
- [ ] Read the HDN-mode assignment UI flow in the reference first (per the
      original T-016 note — not yet done).
- [ ] Overworld dungeon tiles render the HDN color/letter in HDN mode.
- [ ] A way to assign `color`/`labelChar` to a dungeon.
