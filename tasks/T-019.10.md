# T-019.10 — Local triforce/item inset

## Description
Fills the last placeholder in the dungeon-map info strip (the "Dungeon items
(soon)" box) with the **selected dungeon's card** — its triforce pip + item
boxes — so items can be marked while looking at the room map, without scrolling
up to the top row. This is the reference's local dungeon-tracker panel beside the
room grid (the scope doc: "the dungeon tab area holds both the room grid and a
local item/triforce inset").

Reuses the existing `DungeonCardView` (made non-private) with a new
`showLocationHeader` flag (default true preserves the top row; the inset passes
false to drop the overworld hint / HDN chooser — the room map is about interior
contents, not where the dungeon sits on the overworld). Bound to the same
`dungeonTracker`, so the inset and the top card stay in sync.

## Acceptance criteria
- [x] The info strip shows OLD MEN + the selected dungeon's triforce + item boxes.
- [x] The inset card omits the overworld-location header.
- [x] Marking in the inset updates the top card (shared model) and vice-versa.
- [x] The top row is unchanged (default `showLocationHeader: true`).
- [x] Build clean; on-device verified (inset + top row).
