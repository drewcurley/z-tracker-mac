# T-199 — Spot Summary popout window

Coverage §2 "Progress popouts" — trimmed to just the Spot Summary popout per user call:
- **Remaining Items** popout dropped — there is no separate Remaining-Items view (the
  reference's was already killed as redundant with the right-click item picker, §4 #16).
- **Max-Hearts hover** dropped — max hearts is obvious to the player; it was deliberately
  removed from the main view and needs no hover/popout.

## Implementation
- New `SpotSummaryWindowID` + a `Window("Spot Summary", …)` scene rendering
  `SpotSummaryWindowView(model:)`, which recomputes `SpotSummary.compute(...)` live from the
  (`@Observable`) model so it stays current while open.
- The existing "Spot Summary…" popover gains an **"Open in window"** button that opens the
  window and dismisses the popover. The transient popover still works for a quick glance.

## Tests
Window/view plumbing only; `SpotSummary.compute` is already covered by `SpotSummaryTests`.
730 tests pass. Popout QA'd on device (user sign-off).
