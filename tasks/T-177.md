# T-177 — Startup button sizing + load wiring

## Description
Two startup-screen fixes:
- **Equal sizing:** the "previously saved state" and "custom overworld map" buttons used
  string titles without the full-width label + vertical padding the four quest buttons
  have, so they rendered shorter and read as lesser options. Give them the same label form.
  The "- OR -" separator stays.
- **Wire the load button:** "Start: from a previously saved state" was still `.disabled`
  with a stale "needs save-file persistence" tooltip — but Save/Load shipped in T-165.
  Wire it to `GameSave.manualLoad`; applying a save sets `model.quest`, which flips
  ContentView to the tracker (same path as resume). `manualLoad` already skips the
  "replace current run?" confirm when `quest == nil` (startup).

## Acceptance criteria
- [x] Bottom two buttons match the quest buttons' height; separator kept.
- [x] "Previously saved state" opens a load panel and starts the loaded run.
