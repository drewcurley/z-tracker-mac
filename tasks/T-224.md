# T-224 — Shop items + panel sync

Three related shop improvements, shipping in **v1.2.5** (with the armos work, T-223).

## Behavior
1. **Standalone-heart shop item** — `ShopKind.heart` (the `Heart.gif` sprite), a consumable (always
   visible, never hidden-as-owned). Offered in the graphical chooser (a 9-item shop row), the menu,
   hotkeys/voice, and the panel; recognized on spoiler import (guarded against "Heart Container").
2. **Three items per shop tile** — a shop holds up to 3 items (was 2). The next pick fills the 2nd
   then 3rd slot; a 4th distinct item replaces the primary; removing an item shifts the rest up.
3. **Shop & Price panel ↔ map sync** — the panel's 4 fixed slots follow the overworld shops:
   - Each slot **follows one shop tile** (by coord), so editing that shop's items on the map updates
     the slot; prefill fills only **empty** cells, so typed items/prices survive.
   - New shops claim free slots in mark order. Two shops **consolidate to one slot only when their
     item sets are equal** (the game's four shop *types*; many instances each), so subset-related
     shops stay separate until identical; a duplicate's typed prices fold into the survivor.
   - A shop removed from the map releases its (followed) slot; hand-entered slots are left alone.

## Implementation
- `ShopKind.heart`; raw-index bridge extends heart as an app index (37, like any-road "?") — safe
  because shops aren't `isUsedToggleable` and it persists via the Codable enum.
- 2nd/3rd shop items **bit-pack** into the existing `shopExtraDataKey` (low/high nibble), so old
  saves (bare 2nd item) still decode. `OverworldGrid` gains `shopThirdItem`/`setShopThirdItem`;
  `shopItems`, the hide-owned path, `MapStateSummary` found-shop detection, and the hotkey/voice
  smarts all handle three items.
- `ShopPriceRecord.slotCoords` + `syncToMap(shopItemsByCoord:orderedCoords:)`; `TrackerModel`
  `syncShopPriceSlots()` runs each poll + on panel open.

## Tests
Grid packing round-trip + pre-T-224 save compat; 3-slot hotkey smarts (fill/promote/replace); the
reported sync scenario (separate-until-equal, followed-slot update, dedup, release); heart
eligibility/rendering; updated 8→9-shop invariants. **787 tests pass.**

## Activity log

  feedback: identity is by **equal** item set (not subset), slots **follow** their shop so edits
  propagate. Approved. Ships as notarized v1.2.5 with T-223.
