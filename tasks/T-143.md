# T-143 — Voice item boxes

## Description
Sets the three off-map item picker boxes by voice, using the user's chosen **box + item**
grammar: "coast ladder", "armos item recorder", "white sword item bow".

- **`VoiceCatalog`** — two new categories: `.itemBoxes` (Box_Coast / Box_Armos /
  Box_WhiteSword) and `.items` (the 15 box items + "nothing" to clear), ids matching
  `ItemBoxMark.itemIndex(forHotkeySuffix:)`. The armos/white-sword boxes require a
  qualifier ("item"/"box"), so a bare "armos" / "white sword" still marks the overworld
  cave.
- **`VoiceGrammar.itemBoxCommand`** — matches a box name, **strips the box phrase**, then
  matches an item in the remainder, so "white sword item bow" holds a *bow* (not the
  white sword named in the box phrase). Parsed before region so the overworld cave mark
  can't grab it.
- **`ItemBoxVoiceApply`** — pure helper reusing `ItemBoxMark` (the item-hotkey path):
  id → CoastBox / item index, overworld-scoped, respects the unique-item rule.

## Acceptance criteria
- [x] "coast ladder" / "armos item bow" / "white sword item bow" set the right box+item.
- [x] Box phrase stripped so it can't be read as the item; "nothing" clears.
- [x] Bare "white sword" / "armos" stay cave marks.
- [x] Coast box still can't hold the ladder (deliberate rule) — voice honors it. 588 tests.

## Out of scope (→ later)
- A voice "un-mark / clear <item>" verb for the progression toggles (T-142 is set-only).
- Reuse the `.items` vocabulary for the per-dungeon item card (`.dungeonItem` region).
- Remove `/tmp` diagnostics before "final" (kept for QA).
