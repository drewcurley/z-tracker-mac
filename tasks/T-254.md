# T-254 — Overworld hover magnifier ("Show magnifier")

## Description
Audit §4 'built but hidden': the option existed (T-206 hid it) but the magnifier was never built. Port of the reference's MakeMagnifier (UIComponents.fs:19-179).

## Acceptance criteria
- [x] Hovering the overworld shows the 3×3 screens around the mouse at 8× (clamped at the map edge), with a white frame behind the hovered screen, hanging just below the map over the dungeon band (the reference's spot).
- [x] Each block is drawn from the map's block data with a darkened grid; diagonal rocks are split along their diagonals using the reference's four rock tables (ported verbatim, with its per-quest borrowing).
- [x] Entrances pop: open caves ringed cyan (one ring for vanilla's two-wide entrance), bomb / recorder / burn / push spots ringed black, each with a black outline; a legend row explains the five.
- [x] Lost Woods / Lost Hills get the reference's direction arrows; the panel flips with Mirror Overworld; off on a custom map; non-interactive.
- [x] 'Show magnifier' is visible again in Settings (default on, as the reference).

## Notes
Hover isolation: OverworldHoverState.magnifierTile is read only by OverworldMagnifierOverlay, so crossing a tile re-renders the panel alone (T-244 pattern). Magnified screens are rendered once per quest+screen and cached. Not ported: the broadcast-window 'include magnifier' option. Tests: OverworldMagnifierTests (3).
