# T-140 — Voice dungeon-region vocabulary

## Description
Extends the config-driven voice grammar (T-139) with the **dungeon region** so the
cursor can mark rooms hands-free, mirroring the overworld work.

- **`VoiceCatalog`** — a `takesDirection` flag plus five new categories:
  `dungeonRooms` (~24 room types incl. parametric `Room_Transport` #), `monsters`
  (~30, a **shared** category usable overworld or dungeon later), `floorDrops`
  (Triforce / heart / key / rupee / map / compass / …), `doors`
  (open / blocked / key / shutter / none), `entrances`.
- **`VoiceConfig.Scope`** gains `.dungeon`; region actions (overworld **or** dungeon)
  resolve at the cursor and are dispatched by the active region at execution.
- **`VoiceGrammar.dungeonActions`** — returns `[DungeonAction]` so a single utterance
  can mark **compound doors** ("open west shutter east key north" → three doors).
  A door command is a **state word + direction** ("open left"); direction is
  left/right/up/down (also west/east/north/south). Entrances: "entrance south" /
  "entrance down" → `startEnterFromS`. Otherwise a single room / monster / floor-drop.
- **Region-first parse** — region actions win over structural, so "open left" is a
  door command, not a cursor move; bare "left" still moves the cursor.
- **`VoiceController`** — the `.dungeonMap` region applies room type / monster / floor
  drop via `DungeonRoomMark`, and doors via `setHorizontalDoor`/`setVerticalDoor`
  (guarding grid edges); honors the door-inference option.

## Door convention (user's mapping to the generic `DoorState` colors)
open → `.yes` (green) · blocked → `.no` (wall) · key → `.yellow` (gold) ·
shutter → `.purple` · none → `.unknown`. Seeded as **editable** default phrases.

## Acceptance criteria
- [x] Rooms / monsters / floor drops resolve from spoken words; `Room_Transport` takes a number.
- [x] Single and compound door commands; edge doors guarded; entrance direction.
- [x] Region-first parse (door commands not eaten by cursor moves); overworld unchanged.
- [x] Editor lists the new categories with a direction hint. 568 tests.
