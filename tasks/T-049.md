# T-049 — HDN toggles moved to Flags + A–H slot labels

## Description
The startup screen mirrored the Windows app's top-of-screen Heart Shuffle /
Hidden Dungeon Numbers checkboxes — but the reference only put them there
because its timer started immediately. With the Go button (T-041) removing that
constraint, they can be set on the map. This moves both toggles into the in-app
**Flags** group.

It also makes them actually work (Hidden Dungeon Numbers was a dead toggle — the
model always built the tracker in `.default` mode):
- **Heart Shuffle** re-seeds the dungeon floor-item hearts on change.
- **Hidden Dungeon Numbers** rebuilds the dungeon tracker in `.hideDungeonNumbers`
  mode (3 boxes per dungeon), preserving the second-quest-dungeons choice.

And it applies the HDN **slot relabel** (deferring the number *chooser* to a
follow-up): dungeons 1–8 show as **A–H** (Level 9 stays "9") in both the dungeon
tracker and the overworld tile selector/map. The mark still stores the slot
number, so located-linking is unchanged. The location-hint picker is hidden in
HDN (it's replaced by the dungeon-number chooser — T-050).
