# T-078 — Row-locator (rupee/key/bomb)

## Description
User-requested (audit #18, `use.md#main-dungeon-row-location`, reference
`DungeonUI.fs:556-577`): hovering a room in the dungeon editor reveals a strip
right of the grid keyed to the in-game HUD map's row bands — rows 0-1 = rupee,
2-3 = blank, 4-5 = key, 6-7 = bomb — with a gray bar on the hovered room's row,
so you can read off where that room sits on the in-game HUD. A hover reveal (per
the user), not always-on.

- `DungeonRoomGridView`: a 26pt strip reserved right of the grid (folded into
  `contentWidth`); `hoveredRow` @State driven by an `onHover` on each
  `RoomCellView` (hover falls through the mouse catcher, which claims only
  button-downs).
- `rowLocator` renders on hover: a full-row gray highlight + the three band icons
  (`fiveRupee`/`key`/`bombPack` from the floor-drop atlas), centered on the row pairs.

## Acceptance criteria
- [x] Hovering a room reveals the strip + highlights that room's row.
- [x] Icons align to the reference row bands (rupee 0-1, key 4-5, bomb 6-7).
- [x] Strip space reserved (no layout shift); build clean.
- [ ] Live hover confirmed by the user (can't synthesize hover here).
