# T-044 — Map-style box interaction

## Description
The dungeon item boxes (and the coast / armos / white-sword picker boxes, which
reuse `BoxView`) used left-click to open the picker and right-click to mark
"don't have it". That made the common action — marking a known floor item as
*taken* — require reopening the picker every time.

Per the user, mirror the overworld map's interaction:
- **Right-click** opens the item picker (left-click an item = have it,
  right-click = don't have it, plus Don't-want-it / Clear).
- Once an item is known, a **left-click** on the box toggles taken ⇄ untaken.
- An empty box has nothing to toggle, so a left-click opens the picker too.

## Acceptance criteria
- [x] Right-click a box opens the picker (empty or filled; filled shows the
      current item selected).
- [x] Left-click a box with a known item toggles taken (`.yes`) ⇄ untaken
      (`.no`), item unchanged; a `.skipped` box becomes taken.
- [x] Left-click an empty box opens the picker.
- [x] Applies to dungeon boxes and the coast/armos/white-sword boxes (shared
      `BoxView`).
- [x] `Box.toggleTaken` / `hasKnownItem` unit-tested; on-device verified.
