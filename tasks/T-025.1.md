# T-025.1 — Item grid scaffold + toggle boxes + coast boxes

## Description
The core of the `owItemGrid` render (T-025): a single coherent item panel
matching the reference's top-right grid arrangement
(`OW_ITEM_GRID_LOCATIONS`), containing:

- The **9 toggle item boxes** (`veryBasicBoxImpl`,
  `OverworldItemGridUI.fs:272-333+`) — each a fixed-sprite box that toggles a
  `PlayerProgressAndTakeAnyHearts` bool on click: wood sword, wood arrow, blue
  candle, blue ring, magical sword, boomstick book, bomb, Ganon, Zelda. The
  magical-sword box shows the bomb-upgrade sprite when `isWSMSReplacedByBU`
  (`OverworldItemGridUI.fs:283-285`).
- The **3 coast/armos/white-sword picker boxes** (`ladderBox`/`armosBox`/
  `sword2Box`), each a full item-picker `Box` (reuses `BoxView`), with its
  indicator sprite (ladder / armos key / white sword) in the column to its
  left — matching the reference `LADDER_ICON`/`ARMOS_ICON`/`WHITE_SWORD_ICON`
  cells. These move **out** of the temporary "Standalone" row under the
  dungeon tracker (where T-013 parked them) into their real home.

Border precedence for a toggle box is ported as has→green else red; the
superseded (gray-X) and located (yellow) states are **T-025.3**, explicitly
deferred here.

## Acceptance criteria
- [x] `ItemProgressGridView` renders the 5×3 grid at the reference cell
      positions (adapted): row0 `[WS icon][WS box][mags][wood sword][boomstick]`,
      row1 `[ladder icon][coast box][blue candle][wood arrow][blue ring]`,
      row2 `[armos icon][armos box][bomb][ganon][zelda]`.
- [x] Each toggle box click flips its `playerProgress` bool; sprite shows;
      green border when set. Magical-sword box swaps to the BU sprite under
      `isWSMSReplacedByBU`. Verified on-device (wood-sword click → green).
- [x] The 3 coast boxes reuse `BoxView` (picker intact) and are removed from
      `DungeonTrackerView`'s Standalone row.
- [x] Wired into `MainTrackerPlaceholderView`.
- [x] Tests: the pure grid-layout mapping (cell → item) matches the reference
      positions; a toggle→`PlayerComputedStateSummary` integration check
      (magical sword ⇒ swordLevel 3; blue candle ⇒ candleLevel ≥ 1).

## Out of scope
