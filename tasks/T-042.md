# T-042 — Moving floor-item "ghost" box (L1 ↔ L4)

## Description
Some seeds pair a **first-quest overworld** with **second-quest dungeons**:
the extra floor item that normally sits in Level 1 moves to Level 4 instead
(only that one item moves). The reference shows a dimmed "ghost" box under
whichever of L1/L4 doesn't currently hold the extra item; clicking it toggles
which dungeon carries it.

The model already moved the shared `finalBoxOf1Or4` between L1 (1Q) and L4 (2Q)
via `isSecondQuestDungeons` (T-013). This task adds the UI: a
`toggleSecondQuestDungeons()` method + `ghostBoxDungeonId` on the instance, and
a `GhostBoxView` (dashed, dimmed, down-arrow) rendered in the non-owning
dungeon's card. Clicking it flips the flag, moving the box — and whatever item
is marked in it, since it's a single shared `Box`.

## Acceptance criteria
- [x] 1Q (default): L1 carries the extra box (3 boxes); a ghost slot shows under
      L4.
- [x] Clicking the ghost moves the extra box (and its item) to L4; the ghost
      then shows under L1. Toggling back restores the 1Q arrangement.
- [x] HDN mode shows no ghost (`ghostBoxDungeonId == nil` — no shared box).
- [x] The shared box's marked item travels with it across the toggle.
- [x] Unit tests for the toggle + ghost identifier; on-device verified.
