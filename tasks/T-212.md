# T-212 — Tracker UX batch + Heart Shuffle intra mode

Five items from live play feedback, shipping together as v1.1.

## 1. Sword-cave hint auto-fill (bug)
Marking a White-Sword-Item (`.swordCave(2)`) or Magical-Sword (`.swordCave(3)`) cave on the
overworld now fills its location-hint chip ("UN") to that screen's zone — mirroring what placing
a dungeon marker already does. Wired through the mouse, hotkey, and voice apply paths via a new
`placeSwordCave` closure on `OverworldMark.apply` + `didPlaceSwordCave`.

## 2 / 2a. Bigger indicators
Hint chips 9→12pt (in a taller slot); triforce pips 9→15pt. Click targets unchanged (already the
whole region).

## 3. Shop icon redraw
Dropped the orange/brown plate. Shop item sprites now fill the tile like the other overworld
interior icons, with a black drop-shadow for contrast on any terrain. One change to `shopIconView`
fixes both the map and the graphical chooser (they share the view).

## 4. Large X on unwanted items (+ option)
A "don't want it" (`.skipped`) box now shows a large X across the whole box by default, and reads
**dimmed/untaken** (full colour is reserved for actually-obtained items). New persisted setting
**"Large X on unwanted items"** (default on) reverts to the small corner X. Threaded via
`ItemIconOptions.largeUnwantedX`.

## 5. Heart Shuffle → 3-state + intra deduction
`heartShuffle` is now a `HeartShuffle` enum (`.off` / `.intra` / `.full`) instead of a Bool, with
a back-compatible decoder (old `false`/`true` saves → `.off`/`.full`). The Flags tile cycles
off → intra (I) → full (F). **Intra**: the heart isn't pre-placed, but it's guaranteed within its
own dungeon — once one **stair-category** (floor vs basement) is fully identified as non-hearts,
the heart must be in the other category, so `applyIntraHeartDeduction()` marks one of that
category's open slots as a dimmed, untaken Heart Container. Re-derived reactively on any dungeon-
box edit (idempotent) and on restore.

## Tests
`OverworldMarkApplyTests` (sword-cave hint), `HeartShuffleTests` (enum codec back-compat, cycle,
pre-placement, intra deduction incl. D8/SQ-L4 and FQ-L1 category cases), `TrackerOptionsTests`
(largeUnwantedX default), plus the Bool→enum migration across existing suites. **750 tests pass.**
