# T-225 — GitHub Sponsors plug

The author set up GitHub Sponsors (goal: offset costs, not a big ask). Surface it tastefully. Ships
as **v1.2.6**.

## Behavior
- **Persistent footer link** at the bottom of the startup/settings screen: a heart + "Sponsor
  Z-Tracker on GitHub" → `github.com/sponsors/drewcurley`.
- **Occasional post-run thank-you**: when a run finishes (`hasRescuedZelda` → true), a dismissible
  banner (Sponsor / Maybe later / Don't show again). Rate-limited to **at most once a week**
  (`@AppStorage` timestamp), the opt-out is remembered, and it never shows on the broadcast/mirror
  window.

## Implementation
- `SponsorPlug.swift`: `Sponsor` (URL + `@AppStorage` keys + weekly `minInterval`), `SponsorFooterLink`,
  `SponsorCompletionBanner`.
- `StartupView` renders the footer link after the settings panel; `MainTrackerPlaceholderView`
  triggers the banner from the completion `onChange` (gated on `!isMirror`, opt-out, and the weekly
  cap) and shows it as a bottom overlay.

## Tests
`SponsorPlugTests` — the URL and the weekly interval. **789 tests pass.**
