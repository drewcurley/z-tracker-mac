# T-206 — Settings screen audit

Walked every settings toggle with no functional consumer (12 dead stubs) and decided each
with the user (per-item):

## Nixed (removed entirely — option + UI + tests)
- **Show basement info**, **Animate shop highlights**, **Snoop for seed&flags**,
  **Display seed&flags** (the seed/flags feature was already declined; no seed source exists).

## Hidden / back-burnered (settings line commented out, option kept for later)
- **Show magnifier** (overworld hover magnifier), **Mouse magnifier window**,
  **Left-drag auto-inverts** (needs drag-to-paint rooms first).

## Wired up (feature existed, toggle wasn't connected)
- **Hide timer** → suppresses the inline `TimerView` when set.
- **Default to NonDescript** → the left-click room accelerator marks unmarked rooms
  `.nonDescript` instead of `.maybePushBlock`. Threaded a `defaultRoom` param through
  `DungeonRoomGesture.leftClick` / `DungeonRoomMap.leftClick` and `preferNonDescript` through
  the room views (mirrors `inferDoors`).
- **Listen for speech** → auto-starts voice recognition once at launch (prompts for mic the
  first time), instead of clicking the FLAGS mic icon.

## Still to build (separate tasks, from the same audit)
- Animate tile changes (fade/pop + overlay pulse) → T-207.
- Confirmation sounds (voice + input, two toggles) → T-208.

## Tests
`DungeonRoomGestureTests`: the accelerator honors the `defaultRoom` override. Removed the
now-invalid nixed-option assertions. 733 tests pass.
