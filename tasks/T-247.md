# T-247 — Wire the "Warn when quitting while the timer is running" setting

## Description
Audit §4: the setting was orphaned when T-165's save-on-quit dialog replaced the T-109 warning; the function it gated was never called.

## Acceptance criteria
- [x] With "Auto-save and quit" on and the timer running, quitting asks first (Quit / Cancel) when the setting is on.
- [x] Without auto-save, the existing Save / Don't Save / Cancel dialog already stops the quit and now says the timer is still running — no double prompt.
- [x] No prompt when the timer isn't running, no run is in memory, or the run is finished.

## Notes
Pure rule GameSave.shouldWarnTimerRunning (tested in RunSafetyTests). Alert text no longer claims the timer is lost (the run is auto-saved).
