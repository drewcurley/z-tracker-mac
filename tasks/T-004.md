# T-004 — Startup screen embedded settings panel

## Description
`T-003` deliberately scoped out the reference app's 3-column embedded
settings panel (`docs/domain.md` § 4.1) — ~30 toggles across Overworld
settings, Dungeon settings, Reminders (with a Voice/Visual matrix for the 8
categories in § 4.10), and Other (including the broadcast-window size
radio group, which stays fixed-size per ADR 0003 even though the rest of the
layout is responsive). This task builds that panel.

Scope firmed up mid-task: rather than rely solely on a partial screenshot
(cut off before the bottom of the "Other" column), the exhaustive,
authoritative field list was read directly from
`Zelda1RandoTools/Z1R_Tracker/Z1R_Tracker/TrackerModelOptions.fs`. That cross-
check also caught a real error carried since the original inventory pass:
`docs/domain.md` § 4.10 said "7 reminder categories" and omitted "Coast
Item" — the `ReminderCategory` enum has 8 (plus an `Asterisk`/"Error beeps"
case not confirmed as user-facing, left out). Fixed in the same change.

## Acceptance criteria
- [x] Every toggle **confirmed by screenshot** to appear on this screen has a
      corresponding model field and a real UI control. Fields that exist in
      `TrackerModelOptions.fs` but whose placement on *this* screen (vs. the
      main window's own Options menu) was not confirmed are explicitly
      deferred (`T-005`), not silently included or silently dropped.
- [x] Model fields live in `TrackerCore.TrackerOptions`, a dedicated type
      (not grown onto `TrackerModel`), with per-field doc comments citing the
      exact reference-app source field and default.
- [x] Panel is responsive per ADR 0003 (`LazyVGrid` with adaptive columns —
      reflows to fewer columns per row as the window narrows).
- [x] Real tests cover the new state (7 new tests: defaults match source,
      per-category reminder defaults, disableAllReminders behavior and
      scoping, independent toggling, enum raw values / display names; 18/18
      passing overall).
- [x] `domain.md` § 4.1's settings-panel bullet updated from "not
      implemented" to implemented, with the remaining unconfirmed items
      explicitly named rather than glossed over.

## Out of scope
- Making any of these toggles actually *do* anything yet beyond holding
  state (e.g. "Draw routes" doesn't need working route-drawing yet — that's
  the overworld-map feature's job).
- The "More settings…" button's contents, a real "Change voice…" picker, and
  5 fields whose on-screen placement is unconfirmed — tracked as `T-005`.

## Risks / dependencies
- Depends on `T-003` (this repo's startup screen core) — complete.
