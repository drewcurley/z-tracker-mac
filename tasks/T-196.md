# T-196 — Save/Load phase 3

Closes the remaining Save/Load "phase 3" items from coverage §2. (Timeline history was
already added to the save in T-186, so only two pieces remained.)

## Implementation
- **Starting-items config in the save.** `StartingItemsAndExtras` gains a `Codable State`
  + `state`/`restore` (mirroring the reference `StartingItemsAndExtrasModel`,
  `SaveAndLoad.fs:94-151`). `TrackerModel.State.startingItems` is optional so pre-T-196 saves
  still decode (restoring the default empty inventory). Round-trips via snapshot/restore.
- **Save on completion.** The existing "Save on completion" toggle is now wired: when Zelda
  is rescued, `GameSave.saveOnCompletionIfEnabled` writes a timestamped
  `ztracker-completed-<date>.json` (reference `zt-save-completed-…`, `SaveAndLoad.fs:382`).
  Guarded by `GameSave.isApplyingSave` (cleared on the next runloop tick) so loading a
  *finished* run doesn't spawn a duplicate — the reference's `not isCurrentlyLoadingASave`.
