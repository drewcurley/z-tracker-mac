# T-065 — Sword-cave claimed state

## Description
Now that sword caves render as prominent Items-area sword icons (T-063), they
should support the same **claimed** (collected/dimmed) state as the other
single-claim tiles (secrets, armos, letter, hint shop, take-any). Previously
`isUsedToggleable` deliberately excluded sword caves (tracked via their Items
box). This makes all three sword caves claimable: marking one from the picker
defaults it to claimed (T-056), a left-click toggles claimed ⇄ located, and a
claimed cave dims on the map and reads as collected in the Spot Summary.

The map dim is a visual "collected" marker; it does **not** replace the Items
box that still tracks the sword itself.

## Acceptance criteria
- [x] `OverworldTileMark.swordCave` is `isUsedToggleable`.
- [x] Marking a sword cave defaults to claimed; left-click toggles it (T-054/T-056).
- [x] A claimed sword cave dims on the map.
- [x] Spot Summary: a placed sword cave is "found, not collected"; a used one is
      collected/done (`SpotSummary` passes `usedAny(.swordCave(n))`).
- [x] Tests cover the toggleable flag + the Spot Summary done-on-used behavior.
