# T-171 — Custom dungeon label prefix

## Description
Generalizes the reference's `BOARDInsteadOfLEVEL` boolean into a durable custom label.
The editable value is the whole **prefix** before the digit, carrying its own separator:
`area-` → area-1 … area-9, `DUNGEON` → DUNGEON1, default `LEVEL-`. Capped at 7 chars so
prefix + one digit fills the 8-cell dungeon header. Under Hidden Dungeon Numbers it
composes the same way (`area-A`).

- `DungeonLabeling.columnName(slot:prefix:hideDungeonNumbers:)` + `columnWord(prefix:)`
  (strips a trailing separator for the picker submenu title).
- `TrackerOptions`: `renameLevelsEnabled` (Bool, persisted) + `customLevelPrefix` (String,
  persisted like broadcastWindowSize) + computed `levelPrefix`.
- Wired through the dungeon-map header, overworld tile-selector submenu, dungeon summary,
  and timeline labels.
- Settings: replaced the "BOARD instead of LEVEL" toggle with a **Rename levels** checkbox
  + an **Edit…** button opening a prefix editor (text field, live preview, Cancel/Save,
  draft so Cancel discards).

## Acceptance criteria
- [x] Custom prefix renames the dungeon-map header and the overworld tile-selector submenu.
- [x] Prefix carries its own separator (area-1 vs DUNGEON1); default LEVEL-; ≤7 chars.
- [x] Composes with HDN; durable across restarts; off by default.
- [x] Editor: checkbox + Edit dialog with text field, preview, Cancel/Save.
