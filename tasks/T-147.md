# T-147 — Flexible door phrasing

## Description
Live QA: door marking failed on every natural phrasing — "open door north"
(filler word "door" broke the state→direction adjacency) and "green door north"
(the user's colour convention wasn't accepted). Fix:
- The door scan skips filler words (`door`, `the`, `on`, `is`, `to`, `a`) between
  a state and its direction, incl. within compound utterances.
- Colour synonyms in the Door_* catalog phrases: green→open, red→blocked,
  gold/yellow→key, purple→shutter (editable).

## Acceptance criteria
- [x] "open door north", "shutter door left" mark doors; compound with fillers works.
- [x] "green north", "green door north", "red east", "gold up", "purple down" resolve. 592 tests.
