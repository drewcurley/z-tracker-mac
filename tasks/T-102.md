# T-102 — Reminder log

## Description
The reference's "log" affordance (audit item #14): a Log button showing the
reminders that have fired, to review what you may have missed.

- `ReminderLog` (TrackerCore, `@Observable`): a capped (100), most-recent-first
  buffer of fired reminder texts; distinct ids for duplicate text.
- `ReminderController.handle` appends each **surfaced** reminder (shown or spoken).
- A "Log" button in the timeline header opens `ReminderLogView` (list + Clear).
