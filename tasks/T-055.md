# T-055 — Layout cleanup

## Description
Two UI cleanups (user request):
1. Remove the **player-state debug** collapsible that sat between the upper
   section and the overworld map — a T-012 foundation surface that's now
   redundant (the real trackers exercise that state).
2. The overworld map was capped at `maxWidth: 900`, so it shrank with the window
   but never expanded past that. Removed the cap (`maxWidth: .infinity`) so it
   **stretches to the full window width**.

## Acceptance criteria
- [x] The debug DisclosureGroup + `PlayerStateDebugPanel` are gone.
- [x] The map fills the window width, no upper bound (verified at 1200 and 1700).
- [x] Still shrinks gracefully when narrowed (aspect-ratio preserved).
