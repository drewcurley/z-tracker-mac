# T-096 — Overworld-overwrite reminder

## Description
User: the "overworld overwrite" reminders (e.g. "C4 changed from door repair to
money making game") weren't firing — they were never ported (only the
`overworldOverwrites` category existed).

Ported the reference's `RemindOverworldOverwrites` (`Z1R_WPF/Reminders.fs:130-146`):
when you change an overworld mark **from a real mark to a different one**, fire a
reminder in case it was accidental. Skips the reasonable refinement of an *unknown*
secret into a sized secret, and does nothing for unmarked/don't-care originals.

- `ReminderAnnouncement.overworldOverwrite(coordLabel:from:to:)` + the
  `OverworldOverwriteReminder.announcement(old:new:coordLabel:)` builder (destructive
  filter), category `.overworldOverwrites`.
- Fired from `OverworldMapView.applyMark` via a new `onOverwrite` callback →
  `MainTrackerPlaceholderView` delivers it immediately through `reminders.handle`.

## Acceptance criteria
- [x] Changing a real mark to a different one fires "You changed <coord> from <a> to <b>".
- [x] No reminder for a fresh mark, a no-op, or a don't-care original.
- [x] Unknown-secret → sized-secret refinement is not reported.
- [x] Builder unit-tested; build clean.
