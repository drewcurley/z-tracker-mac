# T-246 — Groundhog reset: single press + Undo

## Description
T-239 guarded the groundhog-reset hotkey with a 1.5 s double-press. User feedback: that's annoying,
and a deliberate single press out of habit silently does nothing, leaving the tracker out of step
with the game. Replace it with the reference's safety model (its reset button saves the tracker to a
file before resetting) plus an Undo.

## Acceptance criteria
- [x] One press of the hotkey (or the button's dialog) resets immediately: items, triforces,
      take-any hearts, used spots; the lap restarts; the main timer is untouched.
- [x] Before resetting, the full run is written to `~/Documents/ztracker/ztracker-pre-groundhog-<date>.json`
      (loadable via Load).
- [x] A toast "Inventory reset (groundhog restart)" shows an **Undo** button for 10 s; Undo restores
      the model, the lap, and the reminder engine's memory (restored items don't re-announce).
- [x] A repeat press inside the window keeps the original snapshot (a habitual double-tap still
      undoes to before the first press) and writes no second backup.
- [x] Plain toasts never take clicks; a burst of reminders can't evict the Undo toast.
- [x] Hotkey label back to "Groundhog reset (skip confirmation)".
