# T-092 — Book for Helpful Hints as a seed flag + reminder

## Description
Per the agreed split, "Book for Helpful Hints" is seed-specific, so it moves out of
the preferences panel into the **Flags section** as a tile — icon
`character.book.closed.fill` (a book with a character glyph = "translate the old
man's gibberish", the user's idea). And once you hold the Book *and* the flag is
on, a one-shot reminder nudges you to visit the hint NPCs.

- Flags tile toggles `options.bookForHelpfulHints` (still persisted); removed from
  `SettingsPanelView`.
- New `ReminderAnnouncement.remindVisitHints` (category `.haveKeyLadder`): "You
  have the book — visit the hint NPCs"; fires once when `bookForHelpfulHints` +
  the player holds the Book (item 0 as book, not shield). Re-armed on groundhog.
- `pollReminders(bookForHelpfulHints:)` threads the flag from `options`.

## Acceptance criteria
- [x] Book-for-Hints is a Flags tile (translation-book icon); gone from preferences.
- [x] One-shot "visit hints" reminder on getting the Book, only with the flag on.
- [x] Shield seed (item 0 = shield) does not trigger it.
- [x] Reminder logic unit-tested; icon confirmed to resolve on macOS 14.
