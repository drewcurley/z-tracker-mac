# T-089 — Remaining periodic reminders

## Description
Audit (2026-07-16) of the reference `Z1R_WPF/Reminders.fs` `PeriodicReminders`
found four reminders still unported (door-repair was done in T-088):

- **Coast item** (`CoastItem`, every 3 min): have ladder but not the coast item —
  "Get the coast item with the ladder" / "Get the <item> off the coast".
- **Recorder spots** (`RecorderPBSpotsAndBoomstickBook`, every 5 min): have
  recorder — "There is/are N recorder spots".
- **Power-bracelet spots** (same category, every 5 min): have power bracelet —
  "There is/are N power bracelet spots".
- **Boomstick book** (same category, every 5 min): have wand, no boom book, a
  boom-book shop is marked — "Consider buying the boomstick book".

These are **time-based** (3-5 min cooldowns), unlike the current engine which is
pure per-poll edge-triggered — so this needs a cooldown/timestamp mechanism
(inject a clock so it stays unit-testable). Also check "Consider the magical
sword before dungeon nine" (`UI.fs:1480`, DungeonFeedback) which may be unported.

## Acceptance criteria (draft)
- [ ] The four reminders fire under the reference's conditions + cooldowns.
- [ ] Cooldown clock injected (testable without real time).
- [ ] Categories/toggles already exist; wire spoken + visual paths.

## Resolution (2026-07-16)
Ported all four with an injected cooldown clock (`now: Date` passed to
`poll`; `pollReminders` passes `Date()`, tests pass fixed dates):
- Coast item (`.coastItem`, 3-min): "Get the coast item with the ladder" / "Get
  the <item> off the coast"; white-sword nag suppressed once you have the mags.
- Recorder spots + power-bracelet spots (`.recorderPBSpotsAndBoomstickBook`,
  5-min): "There is/are N … spots"; quiet once the count shrinks (progress).
- Boomstick book (same category, 5-min): wand + no book + a marked book shop.

Item names via new `ITEMS.spokenName` (faithful to `AsPronounceString`, minus the
"beau" phonetic — we keep "bow"). "Consider the magical sword before dungeon nine"
(`UI.fs:1480`) is a distinct DungeonFeedback line — deferred (not part of these four).
6 new tests. Build clean; coast reminder verified on-device (toast fired).
