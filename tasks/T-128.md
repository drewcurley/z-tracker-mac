# T-128 — Discrete map zoom levels

## Description
The map zoom (T-127) stepped with a precedence bug (`by * 10` added a full 1.0
instead of 0.1), so −/+ jumped straight between 60% and 100%. Replaced the
continuous step with discrete levels **60 / 80 / 100 / 120%** (user request); −/+
move one level, clamped at the ends; the % button still resets to 100%.

- [x] Zoom cycles 60 → 80 → 100 → 120 one step at a time.
- [x] Buttons disable at the ends; % button resets to 100.
