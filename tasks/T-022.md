# T-022 — Playtest feedback round 1

## Description
Five fixes from playing the T-021 build side-by-side with the reference,
grounded in the reference source:

1. **Item uniqueness (ChoiceDomain).** Items already placed in a box disable
   in the picker (each item is unique) — **except Heart Containers, of which
   there are 9** (8 dungeon floors + coast). `DungeonTrackerInstance.maxUses`/
   `itemUseCount`/`canSelectItem` port `allItemWithHeartShuffleChoiceDomain`'s
   max-uses (`ITEMS.itemNamesAndCounts`: all 1 except heart 9).
2. **Floor-item hearts.** Heart Shuffle **off** → dungeons 1–8's top box seeds
   a Heart Container (unobtained); **on** → empty. Ported from `UI.fs:142-144`
   / `turnHeartShuffleOff` (`Program.fs:584`); applied in
   `TrackerModel.selectQuest`.
3. **Right-click = "don't have it"** on a placed box and on picker items (the
   reference's 3-way mouse), via an AppKit `RightClickCatcher` (macOS SwiftUI
   has no native right-click).
4. **Bigger overworld dungeon/any-road numbers** — rendered as a centered
   badge (~0.82× the tile) instead of confined to the tiny 5px interior region.
5. **Dark tile = darkening overlay** (`.black.opacity(0.62)` over the terrain)
   instead of a solid-black fill, so the map stays readable — an aesthetic
   improvement over the reference's opaque black.

## Acceptance criteria
