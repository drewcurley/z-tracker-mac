# T-191 — Overworld icon refresh + left-click reopen + picker order

## Ask (user requests, beyond the reference)
1. Replace the **unknown-secret** icon (a Goriya) with a **pale-white "ghost" rupee**, in
   both the graphical chooser and the overworld map.
2. Replace the **hint** icon (the Old Man) with a **gray "?" tile** in the same style as
   the level / any-road digit tiles.
3. **Left-click reopens the chooser** on tiles that already carry a mark you might want to
   revise: an **unknown secret** and a **shop** (which always has one or two items) — the
   same behavior Don't-Care already had (T-185).
4. In the graphical overworld picker, **swap money-making game ↔ door repair**, and reorder
   the take-any variants to **potion → candle → heart** (the in-game order).

## Implementation
- `OverworldTileIconSource` gains `.ghostRupee` and `.hintTile`; `iconSource` maps
  `.secret(.unknown)` → `.ghostRupee` and `.hintShop` → `.hintTile` (TrackerCore).
- Rendering added in all three glyph sites so map, chooser (reuses `TileView`), and Spot
  Summary stay consistent:
  - Ghost rupee: the real `Rupy` sprite desaturated + brightened (`saturation 0`,
    `brightness +0.45`, `opacity 0.9`, faint white glow).
  - Hint tile: `digitIcon("?", background: gray 0.58)` — same rounded digit-tile style.
- `handleLeftClick` routes unknown-secret and shop tiles through a shared
  `openMarkChooser` helper (graphical grid or native menu, per setting), alongside the
  existing Don't-Care case.
- `OverworldChooserLayout` row 2 and row 3 reordered per the ask.

## Tests
`OverworldTileMarkTests` updated for the new icon sources (ghost rupee / hint tile);
`GraphicalTileChooserTests` updated for the new row order. 724 tests pass. Glyph visuals
QA'd on device (user sign-off).
