# T-115 — Timer window scales with size

## Description
The duplicate Timer window (T-101) used fixed 44/22pt fonts, so resizing the window
left a small readout in a big frame. The main and lap readouts now scale with the
window via a `GeometryReader`: the font size is the smaller of a width-based and a
height-based cap (the height cap reserves room for the half-size lap line), floored
at 12pt with `minimumScaleFactor` as a safety net. Padding/spacing scale too.

## Acceptance criteria
- [x] Growing the window grows the digits; shrinking shrinks them.
- [x] Width- and height-limited windows both constrain the size (text always fits).
- [x] A shown lap line reserves extra vertical room.
- [x] 12pt floor respected on tiny windows.
- [x] Unit-tested; build + full suite clean.
