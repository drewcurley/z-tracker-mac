# T-051 — Confirm state-destructive controls

## Description
The top section packs many controls close together, so a misclick on something
that wipes game state could ruin a run. Per the user:
- **State-destructive toggles** (Heart Shuffle, Hidden Dungeon Numbers — both
  rebuild/re-seed dungeon state) confirm **when the timer is running**; before
  the run starts or while paused they apply directly (that's deliberate setup,
  not a misclick during play).
- **Reset Timer** now confirms too (always), matching Reset App and
  Reset (keep maps).

## Acceptance criteria
- [x] Heart Shuffle / Hidden Dungeon Numbers apply directly when the timer isn't
      running; when running they show a destructive confirmation (Cancel reverts
      the toggle).
- [x] Reset Timer confirms first (always), like the other two reset buttons.
- [x] The guard routing is unit-tested.
- [x] On-device verified (HDN direct-apply before Go; confirmation + revert
      while running; Reset Timer confirmation).
