# T-071 — FQ/SQ vanilla dungeon-outline overlays

## Description
Wires the FQ/SQ tab-bar buttons (previously disabled placeholders): toggle an
overlay of a dungeon's **vanilla** (canonical NES) footprint over the room map, so
the user can compare their mapping to the known first/second-quest layout.

- `VanillaDungeonData` (TrackerCore) — the 18 layouts (9 dungeons × FQ/SQ),
  transcribed exactly from the reference `DungeonData.firstQuest`/`secondQuest`
  (`DungeonData.fs:72-290`); 8×8 of `X`(room)/`.`(none) + `isRoom` / `roomCount`.
- `VanillaOutlineOverlay` (view) — a `Canvas` mirroring the reference
  `makeOutlineShapesImpl`: MediumPurple boundary lines where a room borders a
  non-room, plus a translucent purple wash on non-room cells (rooms stay clear so
  marks show through). Sits in the room grid's coordinate system, non-interactive.
- **Global toggle** (per user: not per-dungeon): a single `outlineMode`
  (off / FQ / SQ) applied to whichever dungeon is being viewed — switching tabs
  shows that dungeon's own vanilla footprint. The active button is highlighted
  purple.

## Acceptance criteria
- [x] Vanilla data matches the reference exactly (9×8×8, only X/.).
- [x] FQ/SQ toggle the overlay; the active button reads as on.
- [x] The overlay draws boundary lines + non-room wash in the grid's coordinates.
- [x] Global across dungeons (one toggle, follows the selected tab).
- [x] Unit tests for the data; build clean; on-device render verified.
