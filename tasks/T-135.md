# T-135 — Region cursor cycle + per-region dispatch + default bindings

## Description
Turns the keyboard cursor (T-134) into a working marking tool across regions, plus a
usable default binding scheme and a readable editor.

- **Region cycle** — the cursor cycles a ring of regions (`CycleRegionForward` /
  `CycleRegionBackward`, on PgDn / ⇧PgDn), replacing the reference's 2-way toggle
  (old `ToggleCursorOverworldOrDungeon` id aliased on import). Live regions: **items
  ▸ overworld ▸ dungeon map ▸ blockers** (the dungeon-item card is deferred — the
  user navigates dungeons by tab).
- **Per-region dispatch** — a bound region key acts on the cursor's cell exactly as a
  mouse click would, through a shared apply used by *both* the click path and the
  hotkey path (so they can't drift): `OverworldMark`, `DungeonRoomMark`, `ItemBoxMark`,
  blockers via `BlockerRegion` + `DungeonBlocker.fromHotKeyName`.
- **Whistle destination** — `RecorderDestPrev/Next` Global hotkeys step the recorder
  destination (Home / End), same as the ◀▶ arrows by the recorder.
- **Right-half default scheme** (`HotkeyDefaults`) — every selector bound on the
  keyboard's right half, tiers plain → Shift → Option (never Cmd/Ctrl); regions share
  a 25-key typing block (distinct scopes), Globals live on the nav cluster + F-keys.
  Collision-free by construction (verified). Dungeon **rooms** plain, **monsters**
  Shift, **floor drops** Option (user's rule); the 8 door-nudge selectors stay unbound.
- **macOS-reserved keys** — defaults avoid *plain* F11/F12 (Show Desktop / Dashboard,
  eaten by the WindowServer before the app): dungeon tabs are F7–F10 (1–4) + ⇧F7–⇧F12
  (5–9,S).
- **Readable editor** — `HotkeyChord.displayName` resolves raw `\nnn` codes to the
  physical key (F8, ←, Page Down, `-`, Space…) so the editor never shows `\100`.

## Acceptance criteria
- [x] PgDn / ⇧PgDn cycle the cursor through items ▸ overworld ▸ dungeon map ▸ blockers.
- [x] A bound region key marks the cursor cell identically to a click, in all four regions.
- [x] Whistle destination steps by hotkey.
- [x] `HotkeyDefaults` binds every selector (except door nudges) with no conflicts.
- [x] Defaults avoid plain F11/F12; editor shows human-readable key labels.
- [x] Build + full suite clean (545 tests); user-QA'd each region on-screen.
