# T-185 — Graphical tile chooser + related overworld/dungeon tweaks

Three user-requested changes:

## 1. Left-click on a Don't-Care tile opens the chooser
Previously left-click unmarked → Don't-Care, and a second click did nothing. Now a
second left-click on a Don't-Care tile opens the tile chooser (menu popover in menu
mode, graphical grid in graphical mode). `handleLeftClick` adds the `.dontCare` case.

## 2. Graphical tile chooser (optional)
New `graphicalOverworldChooser` option (default off; toggle in `SettingsPanelView`,
which the startup screen embeds — so it's on both). When on, right-click (and
left-click-Don't-Care) opens a 5×8 icon grid instead of the text menu, because
graphics read faster than menu text.

**Layout (user-specified):** row 1 = 8 shops · row 2 = 4 secrets, door repair, money
game, hint, potion · row 3 = letter, armos, take-any potion/heart/candle, don't-care,
unmarked, start · row 4 = levels 1–8 · row 5 = level 9, any-road 1–4, swords 1–3. The
"?" any-road is omitted (in the chooser you know the rotation number). Exhausted marks
dim + disable. Scroll-up on a tile opens the overworld enemy picker.

**Reuse:** the grid draws each option with the map's own `TileView` glyph (made
`internal`) so options look exactly like placed tiles; take-any variants (not drawn on
the map tile) use a heart+overlay glyph mirroring the Items-grid box; a `ScrollUpCatcher`
NSView intercepts only scroll events (clicks/hover pass through).

**Menu mode is unchanged:** right-click still uses the native context menu (user choice).
Left-click-Don't-Care in menu mode opens the same options in a popover (a native menu
can't be opened programmatically).

## 3. Bigger dungeon floor-drop / monster picker buttons
MonsterPicker cell 30→34 (icon 22→26), FloorDropPicker cell 34→38 (icon 24→28).

## 4. Follow-up fixes (second QA round)
- **Graphical chooser shop 2nd item:** picking a shop on a tile that's already a shop
  fills the second-item slot; a third replaces the primary (reuses
  `OverworldMark.applyShopHotkeySmart`).
- **Sword tooltips** (graphical): "Wood sword (or candle cave if swordless)",
  "White sword item", "Magical sword (or magical bomb upgrade if swordless)".
- **Double-left-click (menu mode) is now a real `NSMenu`** (`makeMarkNSMenu`, the AppKit
  twin of `markMenu`), popped up at the cursor via `showNativeMarkMenu` — chrome-identical
  to the right-click menu (size, spacing, fonts, submenu arrows) and auto-closes natively.
  Right-click keeps its SwiftUI `contextMenu` (also native); the two menu definitions must
  be kept in sync (noted in code).
- **Bow pronunciation:** the weapon "bow" is respelled "beau" for TTS (whole-word) so
  "get the bow off the coast" says /boʊ/, not /baʊ/ (`SpeechText.spoken`).
- **Overworld enemies:** added octorok / peahat / leever (overworld-only, NOT in the
  dungeon picker); they render from game-sprite GIFs via `OverworldEnemyGlyph`.
- **White-sword-item reminder → two tiers:** "Consider getting the white sword item" at
  4–5 hearts, then a stronger "Get the white sword item" **once** on first reaching 6+
  (`.getSword2`). Both under the existing *Sword hearts* category.
- **Armos-item reminder (new):** periodic "Get the armos item" every 3 min while the armos
  is located on the map but its box isn't done (`.getArmosItem`), under a new toggleable
  *Armos Item* reminder category.
