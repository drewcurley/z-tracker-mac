# T-194 — Voice recorder-destination stepper

## Ask
Add voice commands "recorder up" / "recorder down" that do the same thing as the ◀ ▶
recorder-destination arrows (and the T-135 hotkey stepper).

## Implementation
- New `VoiceCommand.recorderDestPrev` / `.recorderDestNext`.
- Catalog actions `Recorder_Prev` / `Recorder_Next` (navigation category): "recorder
  up/next/forward/right" → next; "recorder down/previous/back/left" → prev (plus
  "whistle next/previous").
- `parse` checks the recorder step **before** the region/blocker match, because "recorder"
  alone is a blocker/item word that would otherwise swallow the phrase; only the two
  recorder commands short-circuit, so every other word still resolves normally.
- `VoiceController` dispatches to the same model mutation the arrows use:
  `recorderDestinationManual = true; recorderDestinationIndex ±= 1`.

## Tests
`VoiceGrammarTests.recorderDestinationStepper`: the four phrasings parse to the right
step, and bare "recorder" still routes as an action (no regression). 726 tests pass.
