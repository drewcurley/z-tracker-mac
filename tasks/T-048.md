# T-048 — Reset buttons omnipresent under Info

## Description
T-046 mis-modeled the request as the Windows pause dialog: pausing the timer
revealed a reset "hub". The user actually wanted **three distinct reset buttons,
always visible, under the Info area** — and crucially the groundhog reset must
**not** pause the global (main) timer (the Reset App / Reset Timer options
reset the timer anyway, so gating them behind pause was pointless).

This revises T-046:
- The run timer goes back to just a **Pause/Resume** control (no hub).
- **Reset App**, **Reset Timer**, **Reset (keep maps)** become omnipresent
  buttons at the bottom of the Info group.
- The groundhog reset (**Reset (keep maps)**) now only restarts the lap; the
  main timer keeps running (no pause/resume).

## Acceptance criteria
- [x] Three reset buttons are always visible under the Info group (not gated by
      pause).
- [x] Pausing the timer just pauses it (no reset hub).
- [x] Reset (keep maps): groundhog reset + restart lap, **main timer keeps
      running** (never paused).
- [x] Reset App / Reset (keep maps) confirm first; Reset Timer is immediate.
- [x] On-device verified (buttons omnipresent; after groundhog, main timer stays
      green/running while the lap resets).
