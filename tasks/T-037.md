# T-037 — Rescuing Zelda pauses the timer

## Description
Clicking the Zelda box (rescuing Zelda = the run is finished) immediately
pauses the run timer — both the main and the lap (the lap tracks the main).
Un-rescuing resumes it. Ports the reference's `PlayerHasRescuedZelda.Changed`
→ `LastChangedTime.PauseAll()` / `ResumeAll()`
(`OverworldItemGridUI.fs:428-440`).

- Added explicit `TrackerTimer.pause()` / `resume()` (idempotent);
  `togglePause` now delegates to them.
- `MainTrackerPlaceholderView.onChange(of: playerProgress.hasRescuedZelda)`
  pauses on `true`, resumes on `false` — so any path that rescues Zelda (the
  item box, the debug panel) stops the clock.
