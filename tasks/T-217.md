# T-217 — "Bomb Droppers" overworld enemy marker

A generic overworld enemy option for any screen whose enemies drop bombs (bomb farming), shown as a
plain **bomb icon** rather than a specific enemy. Ships as **v1.2.1**.

## Behavior
- New `MonsterDetail` case **`.bombDroppers`** ("Bomb Droppers"), appended to the reduced
  **overworld** enemy set — offered on overworld tiles (graphical scroll-up picker + the right-click
  enemies menu), **not** in the dungeon monster picker.
- Renders as the plain **bomb** game sprite (the same `"Bomb"` sprite the shops use), via
  `OverworldEnemyGlyph`. It participates in the normal up-to-two enemy pairing per tile.

## Implementation
- `MonsterDetail` (TrackerCore): add `.bombDroppers` in the overworld-only section; add to
  `overworldEnemies`; `displayName` = "Bomb Droppers". Not added to `allInPickerOrder` (dungeon
  picker) so it stays overworld-only.
- `DungeonMonsterAtlas.tileIndex`: `.bombDroppers → nil` (not on the dungeon sheet).
- `OverworldEnemyGlyph.gifName`: `.bombDroppers → "Bomb"`.

## Tests
- New `OverworldEnemyGlyphTests` case: the marker resolves to the `"Bomb"` sprite and is absent from
  the dungeon sheet.
- Updated the enum-count (35→36), overworld-set, and picker-order / atlas exclusion invariants to
  include the new case. **759 tests pass.**

## Activity log
- 2026-08-27 — requested ("a more generic bomb droppers, icon is simply a bomb"); built + QA'd
  ("looks good"); ships as notarized v1.2.1.
