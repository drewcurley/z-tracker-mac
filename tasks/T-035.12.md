# T-035.12 — Info overlay toggles sizing

## Description
Aesthetic housekeeping (user request): the Info group's six overlay-toggle
tiles (hide-marks, open-caves, money, zones, coords, progress) were smaller than
the app's other clickable icons. Resized them to match the **item icons**
(`itemGridCellSize`, 34×34) and reflowed the single row of six into a **3×2
grid**.

Glyphs scaled proportionally with the larger cell (SF Symbols 12→18pt, the rupee
atlas image 15→22px, corner radius 4→6). Behavior is unchanged — hover-preview /
click-lock for the five overlays, click-toggle window for Progress.

## Acceptance criteria
- [x] The six toggle tiles render at `itemGridCellSize` (34×34), matching the
      Items group's cells.
- [x] Laid out as two rows of three (`Grid`/`GridRow`) instead of one row of six.
- [x] Glyphs scaled to fit; hover/lock/toggle behavior unchanged.
- [x] Build clean (debug + release); full suite passes; on-device verified.

## Out of scope
- Any change to what the overlays do or their ordering.
