# T-106 — Armos / White-Sword-cave item prompt

## Description
Like the Windows app: selecting **Armos** or the **White Sword Item** cave on the
overworld picker immediately prompts (in place) for which item was there.

- `OverworldMapView.applyMark`: on `.armos` or `.swordCave(2)`, set an
  `itemPrompt` for that tile (dispatched after the context menu dismisses).
- A `.popover` on the tile opens the reusable `BoxItemPicker` for the matching box
  (`armosBox` / `sword2Box`), so the item is set right there.
- Threaded `dungeonTracker` + `iconOptions` into `OverworldMapView`.

## Acceptance criteria
- [x] Marking Armos → item picker popover for the armos box.
- [x] Marking the White Sword Item cave → item picker for the sword2 box.
- [x] Other marks don't prompt; picker sets the box's item.
- [x] Build clean; launches without crash.
