# T-119 — Timeline hover + magical-sword cave

## 1. Timeline hover shows the split (visible label)
macOS `.help` tooltips proved unreliable on the timeline icons (inside a
`ScrollView` + `.position`) — they never appeared. Replaced with an
`onHover`-driven **visible label**: the hovered icon's split, name, and location
(`31:03  Silver Arrow — LEVEL-3 Box 1`) render in a dark pill just above the icon,
clamped on screen and non-interactive.

## 2. Clicking the magical-sword cave takes the sword
The Magical-Sword cave (`swordCave(3)`) dims from whether the player has the magical
sword (T-110), so it wasn't a manual toggle and clicking did nothing. Now clicking it
takes/untakes the magical sword (`playerProgress.hasMagicalSword`), which dims/brightens
the tile — mirroring the wood-sword-cave grant (T-118).

## Acceptance criteria
- [x] Hovering a timeline icon shows a visible split label tracking that icon.
- [x] Clicking the magical-sword cave grants the magical sword and dims the tile;
      clicking again un-takes it.
- [x] Unit-tested where testable; build + full suite clean.
